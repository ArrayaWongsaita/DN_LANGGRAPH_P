# บทที่ 06: อ่าน error และแก้ปัญหา

## เรียนอะไร
error ที่เจอบ่อย: 401 (key ผิด), 404 (baseUrl มี /api), 429 (เรียกถี่), เครือข่ายล่ม และวิธีอ่านมัน

## ผลลัพธ์ที่คาดหวัง
ทั้ง 5 ข้อขึ้นสีเขียว

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ตัวอย่างของบท (ไฟล์ `.ts` ที่ไม่ใช่ `.test.ts`)
2. เปิดไฟล์ `.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/06-read-errors` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
