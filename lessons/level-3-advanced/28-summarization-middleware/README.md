# บทที่ 3-28 summarization middleware (ย่อประวัติให้อัตโนมัติ)

## แนวคิด

ในบท 2-06 คุณสร้างระบบสรุปประวัติเองด้วย node, conditional edge และ `RemoveMessage` งานจริงกับ `createAgent` ใช้ **`summarizationMiddleware`** ทำให้ทั้งหมดในบรรทัดเดียว:

```ts
summarizationMiddleware({
  model: summaryLlm,                // โมเดลที่ใช้สรุป
  trigger: { messages: 4 },         // เริ่มสรุปเมื่อมีข้อความถึง 4
  keep: { messages: 2 },            // เก็บข้อความล่าสุดไว้ 2 ข้อความ
})
```
เมื่อถึงเกณฑ์ มันเรียกโมเดลสรุปข้อความเก่า แล้วแทนที่ด้วยข้อความสรุปหนึ่งข้อความ ต้องคู่กับ checkpointer (ประวัติถึงจะสะสม)

เหตุที่ควรเข้าใจของเดิมก่อน (บท 2-06): คุณรู้ว่าข้างในมันทำอะไร จึงตั้งเกณฑ์และแก้ปัญหาได้

## 1. ลองเติมช่องเดียว

เปิด [`summarize.ts`](./summarize.ts) แล้วเติมข้อ 1: สร้าง `summarizationMiddleware` ที่สรุปเมื่อมี 4 ข้อความและเก็บ 2 ข้อความล่าสุด รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-28
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีการคุยห้ารอบกับ agent และการประกอบ agent พร้อม `MemorySaver` ให้แล้ว ขาดแค่ตัว middleware สรุปประวัติ

โค้ดตามแนวทาง:

```ts
const summarizer = summarizationMiddleware({ model: llm, trigger: { messages: 4 }, keep: { messages: 2 } });
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
จำนวนข้อความใน State หลังแต่ละรอบ: [ 2, 4, 4, 4, 4 ]
คำตอบสุดท้าย: คุณชื่อมาลีค่ะ 😊
✅ ประวัติถูกสรุปและตัดให้สั้นลง (จำนวนข้อความไม่โตเป็น 10 ข้อความ)
✅ หลังสรุป agent ยังจำชื่อ 'มาลี' ได้
```

สิ่งที่ได้: ย่อประวัติสนทนาอัตโนมัติด้วย middleware

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ตัวเลือก | ค่าในบทนี้ | ความหมาย |
|---|---|---|
| `model` | `llm` | โมเดลที่ใช้สรุป |
| `trigger` | `{ messages: 4 }` | สรุปเมื่อมีตั้งแต่ 4 ข้อความ |
| `keep` | `{ messages: 2 }` | เก็บข้อความล่าสุดไว้ 2 ข้อความไม่ถูกสรุป |

## ข้อควรจำ

- การสรุปใช้ token เพิ่มหนึ่งครั้งต่อรอบที่ถึงเกณฑ์
- สรุปแล้วรายละเอียดเล็ก ๆ หายได้ เลือกเกณฑ์ให้เหมาะ
