# บทที่ 3-28: summarization middleware (ย่อประวัติให้อัตโนมัติ)

## แนวคิด
ในบท 2-06 คุณสร้างระบบสรุปประวัติเองด้วย node, conditional edge และ `RemoveMessage` งานจริงกับ `createAgent` ใช้ **`summarizationMiddleware`** ทำให้ทั้งหมดในบรรทัดเดียว:

```ts
summarizationMiddleware({
  model: summaryLlm,                // โมเดลที่ใช้สรุป
  trigger: { messages: 4 },         // เริ่มสรุปเมื่อมีข้อความถึง 4
  keep: { messages: 2 },            // เก็บข้อความล่าสุดไว้ 2 ข้อความ
})
```
เมื่อถึงเกณฑ์ มันเรียกโมเดลสรุปข้อความเก่า แล้วแทนที่ด้วยข้อความสรุปหนึ่งข้อความ ต้องคู่กับ checkpointer (ประวัติถึงจะสะสม)

เหตุที่ควรเข้าใจของเดิมก่อน (บท 2-06): คุณรู้ว่าข้างในมันทำอะไร จึงตั้งเกณฑ์และแก้ปัญหาได้

## ดูตัวอย่าง
`summarize.ts` รับโมเดลสองตัว: `llm` สำหรับคุย และ `summaryLlm` สำหรับสรุป (แยกกันได้ เช่นใช้รุ่นเล็กถูกกว่าสรุป) ขาดการประกอบ agent พร้อม middleware และ checkpointer
