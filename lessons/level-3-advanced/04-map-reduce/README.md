# บทที่ 3-04: map-reduce (แตก ทำขนาน แล้วรวม)

## แนวคิด
รูปแบบยอดนิยมจาก 3-03: **map** แตกงานให้แต่ละชิ้นทำเอง แล้ว **reduce** รวมผลทุกชิ้นเป็นผลเดียว ใช้กับงานอย่าง "สรุปเอกสารทีละฉบับแล้วรวมเป็นรายงานเดียว" (ที่นี่ใช้การนับคำเพื่อให้ผลแน่นอนและทดสอบได้ ของจริงเปลี่ยนเป็นเรียก LLM)

```
START ─Send→ countWords (×N ขนานกัน) → total (รวมผล) → END
```
node `total` ต่อท้าย `countWords` ด้วย edge ปกติ LangGraph จะรอให้ **ทุกงานที่แตกออกไปเสร็จก่อน** แล้วค่อยรัน `total` หนึ่งครั้ง

## ดูตัวอย่าง
`mapreduce.ts` ประกอบ graph ให้แล้ว ขาดใจกลางทั้งสามจุด: ขั้น map (นับคำ), ขั้น reduce (รวม) และการแตกงาน บทนี้ไม่ใช้ LLM

## คุณทำได้แล้ว
- สร้างงาน map-reduce แบบ dynamic

## ข้อควรจำ
- ขั้น reduce เห็นผลของ map ทุกชิ้นใน State เพราะ reducer รวมไว้ให้
- map ต้องไม่ขึ้นต่อกัน ถึงขนานได้
