# บทที่ 3-34 Capstone ตอนที่ 1 ผู้ช่วยค้นคว้า (แกนกลาง)

## แนวคิด

รวมสิ่งที่เรียนใน Level 3 เป็นระบบจริง: **ผู้ช่วยค้นคว้า** ที่รับคำถามแล้ว

```
plan ─(Send ต่อ 1 หัวข้อ)→ researchTask ×N (ขนาน) → write ⇄ review → END
```
1. **plan** (บท 3-18): LLM แตกคำถามเป็นหัวข้อย่อยไม่เกิน 4 หัวข้อ (ข้อมูลมีโครงสร้าง)
2. **researchTask** (บท 3-03/3-04): ทุกหัวข้อค้นคว้าขนานกัน เก็บโน้ตสะสมด้วย reducer
3. **write**: LLM เขียนรายงานจากโน้ตทั้งหมด (รอบแก้จะเห็นข้อติของผู้ตรวจ)
4. **review** (บท 3-19): LLM ตรวจ ถ้าไม่ผ่านกลับไปแก้ แต่ไม่เกิน 3 รอบ

(ในตอนที่ 2 คุณจะห่อระบบแบบนี้ให้พร้อมใช้จริง: ความจำ, การอนุมัติ และการเก็บลงไฟล์)

## 1. ลองเติม 3 ช่อง

เปิด [`research.ts`](./research.ts) แล้วเติมข้อ 1 ถึง 3 (ช่องละหนึ่งส่วนของงานนี้) รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-34
```

ในไฟล์ทุกข้อมี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(N)` ของข้อนั้นได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์ประกอบ graph, node `researchTask`, ขั้นเขียนและขั้นตรวจให้แล้ว

โค้ดตามแนวทางของข้อ 1:

```ts
const structured = llm.withStructuredOutput(z.object({ topics: z.array(z.string()) }), { method: "functionCalling" });
const out = await structured.invoke(`แตกคำถามเป็นหัวข้อย่อยสั้น ๆ: ${state.question}`);
return { topics: out.topics.slice(0, MAX_TOPICS) };
```

โค้ดตามแนวทางของข้อ 2:

```ts
return state.topics.map((topic) => new Send("researchTask", { topic }));
```

โค้ดตามแนวทางของข้อ 3:

```ts
return state.approved || state.round >= MAX_ROUNDS ? END : "write";
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
หัวข้อ: [
  'การนอนหลับกับสุขภาพกายโดยรวม',
  'การนอนหลับกับระบบภูมิคุ้มกัน',
  'การนอนหลับกับสมอง ความจำ และสมาธิ'
]
วน 1 รอบ อนุมัติ=true
**รายงานสั้น: ทำไมการนอนหลับเพียงพอจึงสำคัญต่อสุขภาพ**

การนอนหลับเพียงพอและมีคุณภาพเป็นพื้นฐานสำคัญของสุขภาพ โดยผู้ใหญ่ควรนอน **7–9 ชั่วโมง/คืน** และรักษาเวลาเข้านอน–ตื่นให้สม่ำเสมอ เพราะการนอนช่วยซ่อมแซมร่างกาย ควบคุมฮอร์โมนและเมแทบอลิซึม เสริมภูมิคุ้มกั

**ด้านสุขภาพกาย:** การนอนไม่พอเรื้อรังสัมพันธ์กับน้ำหนักเพิ่ม/อ้วนลงพุง เบาหวาน ความดันสูง โรคหัวใจ และภูมิคุ้มกันลดลง อีกทั้งเพิ่มความเสี่ยงอุบัติเหตุ ปวดเมื่อย การอักเสบ และการฟื้นตัวช้า

**ด้านภูมิคุ้มกัน:** การนอนพอช่วยให้ระบบภูมิคุ้มกันทำงานสมดุล ทั้งการตอบสนองของเซลล์ T และการสร้างไซโตไคน์ที่เกี่ยวข้องกับการต่อสู้เชื้อโรค ส่วนการนอนน้อยเรื้อรังสัมพันธ์กับความเสี่ยงติดเชื้อทางเดินหา

**ด้านสมองและความจำ:** การอดนอนทำให้สมาธิและความตื่นตัวลดลง เวลาตอบสนองช้า และพลาดง่าย แม้รู้สึกว่า “พอไหว” การนอนช่วย consolidate ความจำ โดย slow-wave sleep เกี่ยวข้องกับความจำข้อเท็จจริง/เหตุการณ์ แ

**สรุป:** การนอนพอและเป็นประจำเป็นพื้นฐานสำคัญของสมาธิ การเรียนรู้ ความจำ ภูมิคุ้มกัน และสุขภาพกายโดยรวม ควรหลีกเลี่ยงคาเฟอีนและแสงจ้าก่อนนอน หากนอนไม่หลับต่อเนื่อง ง่วงมากผิดปกติ หรือนอนน้อย/มากเกินไ
✅ แผนมีหัวข้อ 1-3 ข้อ
✅ ค้นคว้าครบทุกหัวข้อ (โน้ตเท่ากับหัวข้อ)
✅ ได้รายงานที่ไม่ว่าง
✅ วนเขียน-ตรวจไม่เกิน 2 รอบ และจบเพราะอนุมัติหรือครบรอบ
```

สิ่งที่ได้: ประกอบ orchestrator-worker + evaluator-optimizer เป็นระบบเดียว

## 3. สรุปแต่ละข้อ

| ข้อ | จุดที่เติม | เทคนิคที่ใช้ (บทที่เรียนมา) |
|---|---|---|
| 1 | ขั้นวางแผน: แตกคำถามเป็นหัวข้อย่อยไม่เกิน `MAX_TOPICS` | `withStructuredOutput` (บท 3-18) |
| 2 | แตกงานหนึ่ง `Send` ต่อหนึ่งหัวข้อ | `Send` (บท 3-03) |
| 3 | ตัวเลือกทาง: จบเมื่ออนุมัติหรือครบรอบ ไม่เช่นนั้นกลับไปเขียน | ลูปเขียน-ตรวจ (บท 3-19) |

## ข้อควรจำ

- ระบบนี้เรียก LLM หลายครั้งต่อรอบ (ขนานด้วย) ถ้ารันกับบริการที่จำกัด token ต่อนาที อาจเจอ 429 ให้รอสักครู่แล้วลองใหม่ หรือลดจำนวนหัวข้อ
- แต่ละชิ้นคุณเคยทำแยกมาแล้ว ที่ท้าทายคือต่อกันให้ถูกและทดสอบทั้งสาย
- จำกัดทุกอย่างที่ LLM ควบคุมได้ (จำนวนหัวข้อ จำนวนรอบ)
