# บทที่ 3-15: prompt chaining (ต่อ prompt เป็นสายพาน)

## แนวคิด
งานที่ซับซ้อนมักทำให้ LLM ถูกต้องกว่าถ้า **แบ่งเป็นขั้นเล็ก ๆ** ให้ LLM ทำทีละขั้น และผลของขั้นหนึ่งเป็น input ของขั้นถัดไป เรียกว่า prompt chaining ใน LangGraph แต่ละขั้นคือ node ที่ต่อกันด้วย edge (บท 14 ของ Level 1) จุดแข็งคือแทรก **ด่านตรวจ (gate)** ระหว่างขั้นเพื่อหยุดเร็วถ้าผลของขั้นก่อนไม่ผ่าน ไม่เสียเงินทำขั้นต่อไปเปล่า ๆ:

```
write (LLM ร่าง) → gate (โค้ดตรวจ: ยาวพอไหม?) ─ผ่าน→ polish (LLM ขัดเกลา) → END
                                              └ไม่ผ่าน→ END (บอกว่าร่างสั้นไป)
```
ด่านตรวจเป็นโค้ดธรรมดา (conditional edge) ไม่ต้องเรียก LLM เพิ่ม

## ดูตัวอย่าง
`chain.ts` ประกอบ graph แล้ว ขาดสามส่วน: ด่านตรวจ (ฟังก์ชัน `gate`) ขั้นร่าง และขั้นขัดเกลา

## โจทย์
เติม 3 ข้อ (ค้นหา `// 👉 ข้อ N` ในไฟล์) แล้วรัน:

    pnpm lesson 3-15

สคริปต์จะพิมพ์ผล แล้วท้ายไฟล์มีส่วนตรวจที่แสดง ✅/❌ (ไม่ต้องแก้และไม่ต้องอ่านก็ได้)

## คุณทำได้แล้ว
- แบ่งงานเป็นสายพานหลายขั้นพร้อมด่านตรวจ

## ข้อควรจำ
- ใช้เมื่องานแบ่งเป็นขั้นที่ชัดเจนได้ ยอมแลกความเร็วเพื่อความแม่น
- ด่านตรวจด้วยโค้ดถูกและเชื่อถือได้กว่าการถาม LLM

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 3-15` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
