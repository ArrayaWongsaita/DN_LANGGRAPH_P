# บทที่ 3-15 prompt chaining (ต่อ prompt เป็นสายพาน)

## แนวคิด

งานที่ซับซ้อนมักทำให้ LLM ถูกต้องกว่าถ้า **แบ่งเป็นขั้นเล็ก ๆ** ให้ LLM ทำทีละขั้น และผลของขั้นหนึ่งเป็น input ของขั้นถัดไป เรียกว่า prompt chaining ใน LangGraph แต่ละขั้นคือ node ที่ต่อกันด้วย edge (บท 14 ของ Level 1) จุดแข็งคือแทรก **ด่านตรวจ (gate)** ระหว่างขั้นเพื่อหยุดเร็วถ้าผลของขั้นก่อนไม่ผ่าน ไม่เสียเงินทำขั้นต่อไปเปล่า ๆ:

```
write (LLM ร่าง) → gate (โค้ดตรวจ: ยาวพอไหม?) ─ผ่าน→ polish (LLM ขัดเกลา) → END
                                              └ไม่ผ่าน→ END (บอกว่าร่างสั้นไป)
```
ด่านตรวจเป็นโค้ดธรรมดา (conditional edge) ไม่ต้องเรียก LLM เพิ่ม

## 1. ลองเติมช่องเดียว

เปิด [`chain.ts`](./chain.ts) แล้วเติมข้อ 1: เขียนด่านตรวจ `gate` ที่เลือก `polish` หรือ `tooShort` จากความยาวร่าง รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-15
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มี graph ที่ต่อขั้นร่าง (เรียกโมเดล) → ด่านตรวจ → ขั้นขัดเกลา (เรียกโมเดล) ให้แล้ว ขาดแค่ฟังก์ชัน `gate` ที่ตัดสินว่าจะไปต่อหรือหยุด

โค้ดตามแนวทาง:

```ts
return state.draft.length >= 10 ? "polish" : "tooShort";
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
--- ร่าง ---
การออกกำลังกายเป็นสิ่งสำคัญต่อสุขภาพทั้งร่างกายและจิตใจ เพราะช่วยเสริมสร้างความแข็งแรงของกล้ามเนื้อและกระดูก ระบบหัวใจและหลอดเลือดทำงานดีขึ้น ช่วยควบคุมน้ำหนักและลดความเสี่ยงของโรคเรื้อรัง เช่น โรคหัว

--- ฉบับขัดเกลา ---
การออกกำลังกายเป็นสิ่งสำคัญต่อสุขภาพทั้งด้านร่างกายและจิตใจ เพราะช่วยเสริมสร้างความแข็งแรงของกล้ามเนื้อและกระดูก ทำให้ระบบหัวใจและหลอดเลือดทำงานได้ดีขึ้น ช่วยควบคุมน้ำหนัก อีกทั้งลดความเสี่ยงของโรคเรื
✅ ด่านตรวจ: ร่างสั้นเกินไปถูกหยุด
✅ ด่านตรวจ: ร่างยาวพอไปขัดเกลา (ขอบเขต 10 ตัวอักษร)
✅ LLM เขียนร่างได้
✅ ผ่านด่านแล้วได้ฉบับขัดเกลาที่ไม่ใช่ข้อความเดียวกับร่าง
```

สิ่งที่ได้: แบ่งงานเป็นสายพานหลายขั้นพร้อมด่านตรวจ

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ขั้น | ทำอะไร | ใช้โมเดลหรือไม่ |
|---|---|---|
| `draft` | เขียนย่อหน้าตามหัวข้อ | ใช้ |
| `gate` | ร่างยาวอย่างน้อย 10 ตัวอักษรหรือไม่ | ไม่ใช้ เป็นโค้ดธรรมดา |
| `polish` | ขัดเกลาร่างให้สละสลวย | ใช้ |

## ข้อควรจำ

- ใช้เมื่องานแบ่งเป็นขั้นที่ชัดเจนได้ ยอมแลกความเร็วเพื่อความแม่น
- ด่านตรวจด้วยโค้ดถูกและเชื่อถือได้กว่าการถาม LLM
