# บทที่ 3-08: defer (รอทุกสายเสร็จก่อนค่อยรัน)

## แนวคิด
เมื่อ graph แตกเป็นสายที่ **ยาวไม่เท่ากัน** แล้วไปรวมที่ node เดียว node รวมนั้นจะรันทันทีที่ "สายใดสายหนึ่ง" ส่งถึง ซึ่งอาจเร็วกว่าที่อยากได้:

```
START → a → b2 → b3 ─┐
START → b1 ──────────┴→ end     (สายสั้น b1 ถึง end ก่อนสายยาว b3)
```
ถ้า `end` ต้อง **รอทุกสายเสร็จจริง ๆ** (เช่น รวมผล) ให้ทำเครื่องหมาย `defer: true` ที่ node นั้น: LangGraph จะเลื่อนมันไปรันเมื่อไม่มีงานอื่นค้างแล้ว

```ts
.addNode("end", fn, { defer: true })
```

## ดูตัวอย่าง
`defer.ts` มี graph สองสายยาวไม่เท่ากันที่ไปรวมที่ `final` ซึ่งต้องรันเป็นลำดับสุดท้ายเสมอ

## คุณทำได้แล้ว
- ทำให้ node รวมผลรอทุกสายด้วย `defer`

## ข้อควรจำ
- ถ้าทุกสายยาวเท่ากัน ไม่ต้องใช้ `defer`
- `defer` ใช้กับ node ที่ต้องเห็นผลครบทุกสายเท่านั้น
