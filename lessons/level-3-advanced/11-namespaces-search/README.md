# บทที่ 3-11 namespace และ search

## แนวคิด

ความจำระยะยาวมักมีหลายชิ้นต่อผู้ใช้ ("ชอบกาแฟ", "แพ้ถั่ว", ...) เรา **จัดกลุ่มด้วย namespace** แล้วค้นทั้งกลุ่มด้วย `search`:

```ts
await store.put(["memories", "u1"], "m1", { text: "ชอบกาแฟ" });
await store.put(["memories", "u1"], "m2", { text: "แพ้ถั่ว" });
await store.put(["memories", "u2"], "m1", { text: "ของคนอื่น" });

const items = await store.search(["memories", "u1"]); // ทุกชิ้นใน namespace นี้ (ของ u1 เท่านั้น)
items.map((i) => i.value.text);
```
- namespace เป็นลำดับชั้น: `["memories", "u1"]` อยู่ใต้ `["memories"]`
- `search(prefix)` คืนรายการที่ namespace ขึ้นต้นด้วย prefix (รวมที่ซ้อนอยู่ข้างใน) ค่าเริ่มต้นคืนสูงสุด 10 รายการ ใส่ `{ limit }` ถ้าต้องการมากกว่านั้น
- ใส่ **รหัสผู้ใช้ใน namespace** คือวิธีกันความจำของคนหนึ่งไปปนอีกคน

## 1. ลองเติมช่องเดียว

เปิด [`memories.ts`](./memories.ts) แล้วเติมข้อ 1: ดึงความจำทั้งหมดของมาลีด้วย `store.search` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ไม่เรียกโมเดลจริง รันได้โดยไม่ต้องมี API key

```sh
pnpm lesson 3-11
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีฟังก์ชันเพิ่มความจำใหม่ (สร้าง key เอง ใส่ใน namespace ของผู้ใช้) และความจำของมาลีกับสมชายให้แล้ว ขาดแค่การค้นความจำของมาลี

โค้ดตามแนวทาง:

```ts
const items = await store.search(["memories", "mali"]);
const mali: string[] = items.map((i) => i.value.text as string);
```

## 2. ผลที่ได้

ผลที่รันจากเฉลย

```text
{ mali: [ 'ชอบกาแฟ', 'แพ้ถั่ว' ], somchai: [ 'ชอบชา' ] }
✅ ดึงความจำของ mali ได้ครบสองข้อ
✅ ความจำของ somchai แยกจากของ mali
```

สิ่งที่ได้: จัดระเบียบความจำด้วย namespace และค้นเป็นกลุ่ม

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ส่วน | ตัวอย่าง | ผล |
|---|---|---|
| namespace | `["memories", "mali"]` | จัดกลุ่มความจำต่อผู้ใช้ ใส่รหัสผู้ใช้ไว้ในอาร์เรย์เสมอ |
| `store.search(namespace)` | `await store.search(["memories", "mali"])` | คืนทุก item ใน namespace นั้น |
| ค่าของ item | `item.value.text` | ข้อความความจำที่บันทึกไว้ |

## ข้อควรจำ

- ออกแบบ namespace ให้รหัสผู้ใช้อยู่ในนั้นเสมอ
- `search` ยังรองรับ filter และการค้นเชิงความหมาย (ถ้าตั้ง index) เกินระดับบทนี้
