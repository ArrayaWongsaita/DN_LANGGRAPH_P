# บทที่ 3-09: วนซ้ำอย่างปลอดภัย (recursion limit ในงานจริง)

## แนวคิด
บท 2-12 กัน agent วน บทนี้ใช้กับ **ลูปที่เราออกแบบเอง** เช่น "ปรับปรุงข้อความจนผ่านเกณฑ์" ลูปมีเงื่อนไขหยุดสองชั้น:

1. **เงื่อนไขของงาน**: หยุดเมื่อได้ผลตามต้องการ (เช่น ปรับครบ `target` รอบ)
2. **เพดานความปลอดภัย**: `recursionLimit` กันกรณีเงื่อนไขแรกไม่เคยเป็นจริง (บั๊ก/ข้อมูลแปลก)

```ts
await graph.invoke(input, { recursionLimit: 20 }); // เกิน = GraphRecursionError
```
งานของคุณคือคำนวณเพดานให้พอดีกับจำนวนรอบที่ตั้งใจ (แต่ละรอบ = 1 step) และจัดการกรณีชนเพดานให้ผู้ใช้ได้ข้อความที่เข้าใจ

## ดูตัวอย่าง
`loop.ts` มี graph ที่นับ `n` ทีละหนึ่งจนถึง `target` ขาดเงื่อนไขหยุด สูตรเพดาน และการจับ error เมื่อวนเกินเพดาน บทนี้ไม่ใช้ LLM

## คุณทำได้แล้ว
- ออกแบบลูปที่หยุดได้แน่นอนทั้งโดยเงื่อนไขงานและเพดานระบบ

## ข้อควรจำ
- เพดานต้อง "เผื่อ" แต่ไม่ใหญ่เกินจนไม่ช่วยอะไร
- เงื่อนไขหยุดผิด = ชนเพดานเสมอ ให้ถือเป็นสัญญาณบั๊ก
