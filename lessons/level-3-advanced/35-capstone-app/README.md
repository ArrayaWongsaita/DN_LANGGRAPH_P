# บทที่ 3-35: Capstone ตอนที่ 2 ทำให้พร้อมใช้งานจริง

## เป้าหมาย
ตอนที่ 1 ได้แกนกลางของระบบ ตอนนี้ห่อมันให้เป็นแอปที่ใช้ได้จริง รวมสิ่งที่เรียนมาทั้งคอร์ส:

```
prepare ─→ draft ─→ approve (หยุดรอคน) ─→ publish
```
- **prepare**: อ่านภาษาที่ผู้ใช้ชอบจาก **Store** (ความจำระยะยาว: บท 3-10..3-12) และส่งความคืบหน้าด้วย `writer` (บท 2-23)
- **draft**: ให้ LLM เขียนรายงานเป็นภาษาที่ผู้ใช้ชอบ (ส่วนนี้ย่อไว้ให้เป็นการเรียก LLM ครั้งเดียว ของจริงใช้ graph ตอนที่ 1)
- **approve**: **ขออนุมัติจากมนุษย์** ก่อนเผยแพร่ (บท 2-18/2-19)
- ทั้งระบบเก็บด้วย **SqliteSaver** (บท 2-07): หยุดรออนุมัติแล้วปิดโปรแกรมเปิดใหม่ก็ทำต่อได้ (บท 3-26)
- ผู้ใช้ระบุตัวตนผ่าน **context** (บท 3-05)

## ดูตัวอย่าง
`app.ts` ต่อ node ทุกตัวไว้แล้ว ขาด 4 จุดที่เป็นระบบจริง: อ่านความจำและส่งความคืบหน้า ขออนุมัติ compile ด้วย checkpointer + store และการอ่าน stream สองโหมดพร้อมกัน สคริปต์จะรันถึงจุดรออนุมัติ แล้วตอบอนุมัติต่อให้อัตโนมัติ

## คุณทำได้แล้ว
- จบคอร์ส! คุณสร้างระบบ LLM ที่มีความจำ ขออนุมัติมนุษย์ ส่งความคืบหน้า และทนต่อการรีสตาร์ตได้

## ข้อควรจำ
- ระบบจริงต้องการสิ่งรอบข้างมากกว่าตัวโมเดล: ความจำ ความปลอดภัย การสังเกตการณ์
- ลบไฟล์ `capstone-memory.db` เมื่ออยากเริ่มใหม่ (ห้าม commit ไฟล์ .db)
