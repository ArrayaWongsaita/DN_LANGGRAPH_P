# บทที่ 3-35 Capstone ตอนที่ 2 ทำให้พร้อมใช้งานจริง

## แนวคิด

ตอนที่ 1 ได้แกนกลางของระบบ ตอนนี้ห่อมันให้เป็นแอปที่ใช้ได้จริง รวมสิ่งที่เรียนมาทั้งคอร์ส:

```
prepare ─→ draft ─→ approve (หยุดรอคน) ─→ publish
```
- **prepare**: อ่านภาษาที่ผู้ใช้ชอบจาก **Store** (ความจำระยะยาว: บท 3-10..3-12) และส่งความคืบหน้าด้วย `writer` (บท 2-23)
- **draft**: ให้ LLM เขียนรายงานเป็นภาษาที่ผู้ใช้ชอบ (ส่วนนี้ย่อไว้ให้เป็นการเรียก LLM ครั้งเดียว ของจริงใช้ graph ตอนที่ 1)
- **approve**: **ขออนุมัติจากมนุษย์** ก่อนเผยแพร่ (บท 2-18/2-19)
- ทั้งระบบเก็บด้วย **SqliteSaver** (บท 2-07): หยุดรออนุมัติแล้วปิดโปรแกรมเปิดใหม่ก็ทำต่อได้ (บท 3-26)
- ผู้ใช้ระบุตัวตนผ่าน **context** (บท 3-05)

## 1. ลองเติม 3 ช่อง

เปิด [`app.ts`](./app.ts) แล้วเติมข้อ 1 ถึง 3 (ช่องละหนึ่งส่วนของงานนี้) รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-35
```

ในไฟล์ทุกข้อมี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(N)` ของข้อนั้นได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์ต่อ node ทุกตัว, การอ่านความจำจาก Store และการส่งความคืบหน้าให้แล้ว

โค้ดตามแนวทางของข้อ 1:

```ts
const ok = interrupt({ report: state.report });
return { approved: ok === true };
```

โค้ดตามแนวทางของข้อ 2:

```ts
const app = builder.compile({ checkpointer: new MemorySaver(), store });
```

โค้ดตามแนวทางของข้อ 3:

```ts
for await (const [mode, data] of await app.stream(
  { question: "ประโยชน์ของการนอนหลับ" },
  { ...config, streamMode: ["custom", "values"] },
)) {
  if (mode === "custom") stages.push((data as { stage: string }).stage);
  if (mode === "values") report = (data as { report?: string }).report || report;
}
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
{ stages: [ 'prepare', 'draft' ], waiting: true }
รายงานที่รออนุมัติ: การนอนหลับอย่างเพียงพอช่วยให้ร่างกายฟื้นฟูซ่อมแซมเซลล์และเสริมระบบภูมิคุ้มกันให้ทำงานได้ดีขึ้น นอกจากนี้ยังช่วยให้สมองจดจำได้ดีขึ้น อารมณ์มั่นคง และลดความเสี่ยงของโรคเรื้อรัง เช่น 
เผยแพร่แล้ว: การนอนหลับอย่างเพียงพอช่วยให้ร่างกายฟื้นฟูซ่อมแซมเซลล์และเสริมระบบภูมิคุ้มกันให้ทำงานได้ดีขึ้น นอกจากนี้ยังช่วยให้สมองจดจำได้ดีขึ้น อารมณ์มั่นคง และลดความเสี่ยงของโรคเรื้อรัง เช่น โรคหัวใ
✅ ส่งความคืบหน้าตามขั้น: prepare แล้ว draft
✅ ได้รายงานจาก LLM และหยุดรออนุมัติ
✅ อนุมัติแล้วเผยแพร่ (ผลขึ้นต้นด้วย 'เผยแพร่แล้ว')
```

สิ่งที่ได้: จบคอร์ส! คุณสร้างระบบ LLM ที่มีความจำ ขออนุมัติมนุษย์ ส่งความคืบหน้า และทนต่อการรีสตาร์ตได้

## 3. สรุปแต่ละข้อ

| ข้อ | จุดที่เติม | เทคนิคที่ใช้ (บทที่เรียนมา) |
|---|---|---|
| 1 | ขออนุมัติ: `interrupt({ report })` | human-in-the-loop (บท 2-18) |
| 2 | `compile({ checkpointer, store })` | checkpointer และ Store (บท 3-12) |
| 3 | `stream` ด้วย `streamMode: ["custom", "values"]` | streaming หลายโหมด |

## ข้อควรจำ

- ระบบจริงต้องการสิ่งรอบข้างมากกว่าตัวโมเดล: ความจำ ความปลอดภัย การสังเกตการณ์
- ลบไฟล์ `capstone-memory.db` เมื่ออยากเริ่มใหม่ (ห้าม commit ไฟล์ .db)
