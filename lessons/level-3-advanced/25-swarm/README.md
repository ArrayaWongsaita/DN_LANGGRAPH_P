# บทที่ 3-25 swarm (agent ส่งต่อหากันเอง ไม่มีหัวหน้า)

## แนวคิด

**swarm** ต่างจาก supervisor (3-24): ไม่มีศูนย์กลาง agent ที่กำลังคุยกับผู้ใช้อยู่ตัดสินใจเองว่า "เรื่องนี้ควรเป็นของเพื่อน" แล้วส่งต่อตรง ๆ (handoff ของบท 3-23) และที่สำคัญ **จำว่าตอนนี้ใครเป็นคนคุยอยู่** (`active`) เพื่อให้ข้อความถัดไปของผู้ใช้ไปหา agent คนเดิม ไม่ต้องเริ่มจากต้น:

```
START → (ตาม state.active) → alice ⇄ bob → END
```
- field `active` ใน State จำ agent ปัจจุบัน
- ตอนเริ่มรอบใหม่ conditional edge จาก `START` ส่งไปที่ `state.active`
- agent ที่ส่งต่อ ใช้ `Command({ goto: เพื่อน, update: { active: เพื่อน } })`

(ใช้ `withStructuredOutput` ให้ agent ตอบเป็น `{ reply, handoffTo }`)

## 1. ลองเติมช่องเดียว

เปิด [`swarm.ts`](./swarm.ts) แล้วเติมข้อ 1: คืน `Command` ที่อัปเดต `reply` กับ `active` แล้ว `goto` ไป agent ที่รับช่วง รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-25
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มี agent สองคน (`alice` เรื่องขาย, `bob` เรื่องซัพพอร์ต) ที่ใช้ตัวช่วยสร้าง, การเริ่มที่ agent ปัจจุบัน และ `MemorySaver` ให้แล้ว ขาดแค่คำสั่งส่งต่อ

โค้ดตามแนวทาง:

```ts
return new Command({ update: { reply: out.reply, active: out.handoffTo }, goto: out.handoffTo });
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
[alice] สวัสดีค่ะ ยินดีช่วยแนะนำค่ะ ขอทราบก่อนนะคะว่าสนใจสินค้าประเภทไหน และงบ
[bob] ขอโทษที่สินค้ามีปัญหานะคะ 🙏 รบกวนแจ้งชื่อสินค้า เลขคำสั่งซื้อ (หรือรู
[bob] ยินดีมากครับ 🙏 หากมีปัญหาสินค้าหรือต้องการให้ช่วยอะไรเพิ่มเติม แจ้งได
✅ เรื่องขายเริ่มที่ alice
✅ เรื่องสินค้าพัง: alice ส่งต่อให้ bob
✅ ข้อความถัดไปเริ่มที่ bob ต่อ (จำข้ามข้อความด้วย checkpointer)
```

สิ่งที่ได้: สร้างทีม agent ที่ส่งต่อกันเองและจำว่าใครกำลังคุย

## 3. ส่วนประกอบที่ใช้ในบทนี้

| field ใน State | ค่า | ใช้ทำอะไร |
|---|---|---|
| `active` | ชื่อ agent ที่กำลังคุยกับผู้ใช้ | เริ่มรอบถัดไปที่ agent คนเดิม |
| `reply` | ข้อความตอบกลับ | ผลที่ส่งกลับผู้ใช้ |
| `goto` | `out.handoffTo` | ส่งต่อให้เพื่อนโดยไม่ต้องผ่านหัวหน้า |

## ข้อควรจำ

- ไม่มีหัวหน้า = ต้องกันวนส่งต่อกันไปมา (ให้ agent ส่งต่อได้ไม่เกินหนึ่งครั้งต่อรอบ)
- ใช้ checkpointer (บท 2-02) เพื่อให้ `active` ข้ามรอบข้อความของผู้ใช้
