# บทที่ 3-16 routing (จัดประเภทแล้วส่งไปผู้เชี่ยวชาญ)

## แนวคิด

คำถามหลายประเภทควรได้ prompt/เครื่องมือต่างกัน (เรื่องบิล, เรื่องเทคนิค, อื่น ๆ) รูปแบบ routing คือ **ขั้นแรกจัดประเภท** แล้วแยกไป node ที่เชี่ยวชาญแต่ละแบบ คุณเคยทำใน Level 1 บท 20 ที่นี่ทำให้เป็นระบบ:

1. node `classify` ให้ LLM ตอบเป็นข้อมูลมีโครงสร้าง (`withStructuredOutput`) ที่ `category` เป็น enum จำกัดค่า ไม่ปล่อยให้ตอบเป็นข้อความอิสระ
2. conditional edge อ่าน `state.category` แล้วส่งต่อ
3. node ผู้เชี่ยวชาญแต่ละตัวมี prompt ของตัวเอง

```ts
const Category = z.enum(["billing", "tech", "other"]);
```

## 1. ลองเติมช่องเดียว

เปิด [`routing.ts`](./routing.ts) แล้วเติมข้อ 1: ให้โมเดลจัดประเภทคำถามเป็นข้อมูลมีโครงสร้างใน node `classify` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-16
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีผู้เชี่ยวชาญสามตัว (`billing`, `tech`, `other`) และฟังก์ชันเลือกทาง `routeOf` ให้แล้ว ขาดแค่ขั้นจัดประเภทด้วย `withStructuredOutput`

โค้ดตามแนวทาง:

```ts
const structured = llm.withStructuredOutput(z.object({ category: Category }), { method: "functionCalling" });
const out = await structured.invoke(`จัดประเภทคำถาม (billing/tech/other): ${state.question}`);
return { category: out.category };
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
[billing] ฉันถูกเก็บเงินซ้ำสองครั้งในใบแจ้งหนี้เดือนนี้
   -> รับทราบค่ะ ขออภัยในความไม่สะดวก กรุณาส่งเลขที่ใบแจ้งหนี้/เลขลูกค้า และรายการที่ถ
[tech] แอปเด้งออกทุกครั้งที่เปิดหน้าตั้งค่า
   -> รับทราบครับ เบื้องต้นลองปิด-เปิดแอปใหม่, อัปเดตแอป/ระบบ, ล้างแคช และตรวจพื้นที่ว
[other] วันนี้วันอะไรของสัปดาห์นะ
   -> วันพฤหัสบดีครับ
✅ router: ไม่มีหมวดใช้ other
✅ router: ใช้หมวดที่ LLM จัดให้
✅ เรื่องเงินถูกจัดเป็น billing
✅ เรื่องแอปเสียถูกจัดเป็น tech
✅ ทุกคำถามได้คำตอบจากผู้เชี่ยวชาญ
```

สิ่งที่ได้: สร้างระบบที่แยกงานไปยังผู้เชี่ยวชาญตามประเภท

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ส่วน | ตัวอย่าง | หน้าที่ |
|---|---|---|
| schema | `z.object({ category: Category })` โดย `Category` เป็น enum | บังคับให้ผลอยู่ในประเภทที่ router รู้จัก |
| `method` | `"functionCalling"` | ขอผลมีโครงสร้างผ่าน tool calling |
| `routeOf(state)` | คืน `state.category` หรือ `"other"` | ตัวเลือกทางใน `addConditionalEdges` |

## ข้อควรจำ

- ใช้ enum บังคับให้ผลจัดประเภทอยู่ในชุดที่ router รู้จัก
- เผื่อประเภท "อื่น ๆ" ไว้เสมอ
