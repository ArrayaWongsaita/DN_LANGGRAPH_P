# บทที่ 3-24 supervisor (หัวหน้าที่มอบงานให้ลูกทีม)

## แนวคิด

อีกโครงสร้าง multi-agent คือมี **supervisor** ศูนย์กลาง: ทุกคำสั่งผ่านหัวหน้า หัวหน้าตัดสินใจว่าจะมอบงานให้ลูกทีมคนไหน เมื่อลูกทีมทำเสร็จก็ **กลับมารายงานหัวหน้าเสมอ** หัวหน้าจึงตัดสินใจรอบต่อไปได้ จนพอใจแล้วสั่ง `FINISH`:

```
          ┌→ researcher ┐
supervisor┤             ├→ (กลับ supervisor ทุกครั้ง)
          └→ writer ────┘
   └ FINISH → END
```
supervisor คือ node ที่ให้ LLM ตัดสินใจ (ผลเป็น enum) แล้วใช้ `Command` + `goto` ตามบท 3-02 (ลูกทีมคนละหน้าที่ ต่างจาก routing บท 3-16 ที่ทำครั้งเดียว: ที่นี่ **วนซ้ำ** ได้หลายรอบ)

## 1. ลองเติมช่องเดียว

เปิด [`supervisor.ts`](./supervisor.ts) แล้วเติมข้อ 1: ให้ supervisor ใช้ `withStructuredOutput` เลือกลูกทีมคนต่อไปแล้วคืน `Command({ goto })` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 3-24
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีลูกทีมสองคน (`researcher`, `writer`) และเส้นที่ลูกทีมกลับมาหา supervisor ให้แล้ว ขาดแค่ตัวหัวหน้าที่ถามโมเดลว่าใครทำต่อ

โค้ดตามแนวทาง:

```ts
const structured = llm.withStructuredOutput(z.object({ next: Next }), { method: "functionCalling" });
const out = await structured.invoke(
  `งาน: ${state.task}\nผลงานตอนนี้: ${state.work || "(ยังไม่มี)"}\nลูกทีม: researcher (ค้นข้อมูล) ต้องทำก่อน แล้ว writer (เขียนสรุป) ตามหลัง เมื่อมีทั้ง [ค้นข้อมูล] และ [เขียนสรุป] ในผลงานแล้วให้ FINISH ใครทำต่อ (researcher/writer/FINISH)?`,
);
return new Command({ goto: out.next === "FINISH" ? END : out.next });
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
ผลงาน: [ค้นข้อมูล][เขียนสรุป]
✅ ลูกทีมทั้งสองทำงาน
✅ researcher ทำก่อน writer
```

สิ่งที่ได้: สร้างทีมที่มีหัวหน้ามอบงานเป็นรอบ

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ส่วน | ตัวอย่าง | หน้าที่ |
|---|---|---|
| schema | `z.object({ next: Next })` โดย `Next` รวม `FINISH` | บังคับให้ผลเป็นชื่อลูกทีมหรือจบงาน |
| `goto` | `out.next === "FINISH" ? END : out.next` | ส่งงานต่อหรือจบ |
| เส้นกลับ | `researcher → supervisor`, `writer → supervisor` | ให้หัวหน้าเห็นผลงานสะสมก่อนตัดสินรอบถัดไป |

## ข้อควรจำ

- ใส่เพดานจำนวนรอบ (`recursionLimit` หรือตัวนับ) กันหัวหน้าวนไม่จบ
- หัวหน้าเห็นผลงานสะสมใน State เพื่อใช้ตัดสินใจ
