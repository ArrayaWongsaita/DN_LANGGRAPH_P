# บทที่ 3-24: supervisor (หัวหน้าที่มอบงานให้ลูกทีม)

## แนวคิด
อีกโครงสร้าง multi-agent คือมี **supervisor** ศูนย์กลาง: ทุกคำสั่งผ่านหัวหน้า หัวหน้าตัดสินใจว่าจะมอบงานให้ลูกทีมคนไหน เมื่อลูกทีมทำเสร็จก็ **กลับมารายงานหัวหน้าเสมอ** หัวหน้าจึงตัดสินใจรอบต่อไปได้ จนพอใจแล้วสั่ง `FINISH`:

```
          ┌→ researcher ┐
supervisor┤             ├→ (กลับ supervisor ทุกครั้ง)
          └→ writer ────┘
   └ FINISH → END
```
supervisor คือ node ที่ให้ LLM ตัดสินใจ (ผลเป็น enum) แล้วใช้ `Command` + `goto` ตามบท 3-02 (ลูกทีมคนละหน้าที่ ต่างจาก routing บท 3-16 ที่ทำครั้งเดียว: ที่นี่ **วนซ้ำ** ได้หลายรอบ)

## ดูตัวอย่าง
`supervisor.ts` มีลูกทีม 2 คน (ฟังก์ชันธรรมดา) ขาดตัวหัวหน้า (LLM ที่เลือกว่าใครทำต่อ) และเส้นกลับ

## คุณทำได้แล้ว
- สร้างทีมที่มีหัวหน้ามอบงานเป็นรอบ

## ข้อควรจำ
- ใส่เพดานจำนวนรอบ (`recursionLimit` หรือตัวนับ) กันหัวหน้าวนไม่จบ
- หัวหน้าเห็นผลงานสะสมใน State เพื่อใช้ตัดสินใจ
