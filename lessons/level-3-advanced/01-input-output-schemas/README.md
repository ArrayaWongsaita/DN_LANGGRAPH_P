# บทที่ 3-01: schema ของ input/output และ state ส่วนตัว

## แนวคิด
ปกติ graph รับและคืน State ทั้งก้อน แต่ในงานจริงเรามักอยาก:
- จำกัดว่า **ผู้เรียกส่งอะไรเข้ามาได้** (input)
- จำกัดว่า **ผู้เรียกได้อะไรกลับไป** (output) ไม่รั่วข้อมูลภายใน
- มี field **ส่วนตัว** ที่ใช้ระหว่าง node เท่านั้น (เช่น ร่างความคิด) ไม่โผล่ออกไป

ทำได้โดยแยก 3 schema แล้วส่งให้ `StateGraph`:

```ts
new StateGraph({ state: Full, input: In, output: Out })
```
- `Full`: field ทั้งหมดที่ node อ่าน/เขียนได้
- `In`: field ที่รับตอน `invoke`
- `Out`: field ที่คืนตอนจบ (field ที่ไม่อยู่ใน `Out` เช่น `scratch` จะไม่ถูกคืน)

## ดูตัวอย่าง
`schemas.ts` ประกาศ 3 schema ให้แล้ว ขาดการประกอบเข้า `StateGraph` และ node ที่ใช้ field ส่วนตัว

## คุณทำได้แล้ว
- กำหนดหน้าตา input/output ของ graph และซ่อน state ภายใน

## ข้อควรจำ
- node ยังอ่าน/เขียน field ใดก็ได้ใน `Full`
- `Out` คือสัญญากับผู้เรียก เปลี่ยนแล้วกระทบผู้ใช้
