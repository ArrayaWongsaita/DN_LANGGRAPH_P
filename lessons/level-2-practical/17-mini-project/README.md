# บทที่ 2-17: โปรเจกต์เล็ก ผู้ช่วยจดโน้ตที่จำข้ามการรีสตาร์ต

## เป้าหมาย
รวมสิ่งที่เรียนใน Level 2 เป็นแอปจริงชิ้นแรก **ผู้ช่วยจดโน้ต**:
- คุยได้ต่อเนื่อง (ความจำ: บท 2-02 ถึง 2-04)
- มี tool สองตัว: `addNote` จดโน้ต และ `listNotes` ดูโน้ตทั้งหมด (บท 2-08 ถึง 2-11)
- สร้างด้วย `createAgent` (บท 2-16)
- ความจำเก็บลงไฟล์ ปิดโปรแกรมแล้วเปิดใหม่ยังจำที่คุยกันได้ (บท 2-07)

```
คุณ: จดไว้ว่าพรุ่งนี้ประชุมสิบโมง      → agent เรียก addNote
คุณ: ฉันจดอะไรไว้บ้าง                → agent เรียก listNotes แล้วตอบ
(ปิดโปรแกรม เปิดใหม่)
คุณ: เมื่อกี้เราคุยอะไรกัน             → ยังจำได้เพราะ SqliteSaver
```

## ดูตัวอย่าง
`notes.ts` มี `makeNoteTools(store)` ที่ tool ใช้ array `store` เป็นที่เก็บโน้ต และ `buildNoteAssistant` ที่ประกอบ agent ขาดตัวฟังก์ชันของ tool สองตัวและการประกอบ agent

## โจทย์
เติม 3 ข้อ แล้วรัน:

    pnpm test:lesson 2-17

จากนั้นลองกับ LLM จริง (พิมพ์ `exit` เพื่อออก แล้วรันซ้ำเพื่อดูว่ายังจำได้):

    pnpm lesson 2-17

โปรแกรมเก็บความจำไว้ที่ไฟล์ `notes-memory.db` ลบไฟล์นี้เมื่ออยากเริ่มคุยใหม่

## คุณทำได้แล้ว
- ประกอบความจำ, tool, agent และการเก็บลงไฟล์เป็นแอปเดียว

## ข้อควรจำ
- โน้ตในบทนี้อยู่ใน array ในหน่วยความจำ รีสตาร์ตแล้วหาย แต่ประวัติแชตยังอยู่ เลยยังเห็นว่าเคยจดอะไรผ่านบทสนทนา (ถ้าอยากเก็บโน้ตจริงต้องมีที่เก็บของมันเอง ซึ่งจะเจอใน Level 3)
- ไฟล์ `.db` เก็บบทสนทนาจริง ห้าม commit (ถูกใส่ใน `.gitignore` แล้ว)
