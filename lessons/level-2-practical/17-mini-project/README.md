# บทที่ 2-17 สร้างผู้ช่วยจดโน้ตที่จำบทสนทนาข้ามการเปิดใหม่

ผู้ใช้ขอให้จดว่าต้องซื้อนมและโทรหาแม่ แล้วขอดูรายการ ผู้ช่วยใช้ `addNote` และ `listNotes` ทำสองงานนี้ หลังเปิดโปรแกรมใหม่ ผู้ช่วยโหลดบทสนทนาเดิมจาก SQLite สคริปต์ใช้โมเดลจริงจาก [บท 1-02](../../level-1-basics/02-llm-config/README.md) จึงต้องตั้ง API key ใน `.env` และทำ [บท 1-01](../../level-1-basics/01-env-schema/README.md) กับบท 1-02 ก่อน

## 1. จดสองรายการแล้วเปิดผู้ช่วยใหม่

เติมสามข้อใน [`notes.ts`](./notes.ts) ให้ `addNote` เพิ่มข้อมูล ให้ `listNotes` คืนรายการ และให้ `buildAssistant` ใช้เครื่องมือทั้งสองกับ saver ที่รับเข้ามา จากนั้นรันจากโฟลเดอร์หลักและดูทั้งผล tool กับประวัติหลังเปิดไฟล์เดิม

```sh
pnpm lesson 2-17
```

[`notes.ts`](./notes.ts) ประกอบ `tool` จาก [บท 2-08](../08-define-tool/README.md), `createAgent` จาก [บท 2-16](../16-create-agent/README.md) และ `SqliteSaver` จาก [บท 2-07](../07-sqlite-saver/README.md) ส่วนที่เชื่อมทั้งสามอย่างอยู่ในฟังก์ชันนี้

```ts
function buildAssistant(saver: SqliteSaver) {
  return createAgent({
    model: llm,
    tools: [addNote, listNotes],
    checkpointer: saver,
    systemPrompt: "คุณคือผู้ช่วยจดโน้ต ตอบสั้น ใช้ addNote เมื่อผู้ใช้ขอจด ใช้ listNotes เมื่อขอดูรายการโน้ต สำหรับคำถามเกี่ยวกับแชตก่อนหน้าให้ดูข้อความในบทสนทนา",
  });
}
```

สคริปต์ใช้ thread `"mali"` เพื่อจดสองรายการและขอดูรายการ ผล `listing` มาจากข้อความชนิด `tool` จากนั้นสคริปต์ปิดการเชื่อมต่อ SQLite ล้าง array `store` เพื่อจำลองการเริ่มโปรเซสใหม่ แล้วสร้างผู้ช่วยจากไฟล์เดิมและถามต่อด้วย thread เดิม

```text
{"notes":["ซื้อนม","โทรหาแม่"],"listing":"1. ซื้อนม\n2. โทรหาแม่"}
{"notes":[],"history":["จดโน้ตว่า ซื้อนม","จดโน้ตว่า โทรหาแม่","ขอดูรายการโน้ต","ในแชตก่อนหน้าฉันขอให้จดอะไร"],"reply":"คุณขอให้จดซื้อนมและโทรหาแม่"}
```

นี่คือผลตัวอย่างเมื่อโมเดลเรียกเครื่องมือตามที่ขอ ข้อความ `reply` เปลี่ยนตามโมเดลได้ หลังเปิดใหม่ `notes` เป็น `[]` เพราะรายการอยู่ใน array ส่วน `history` มีแชตเดิมเพราะ SQLite เก็บ State ของ agent

## 2. ค่าที่เชื่อมแต่ละส่วน

| จุด | ชนิดหรือรูปแบบ | ผล |
|---|---|---|
| อินพุต `addNote` | `{ text: string }` | เพิ่มข้อความใน `store` แล้วคืนข้อความยืนยัน |
| อินพุต `listNotes` | `{}` | อ่าน `store` แล้วคืนรายการทีละบรรทัด หรือคืน `"ยังไม่มีโน้ต"` เมื่อว่าง |
| `checkpointer` | `SqliteSaver.fromConnString(file)` | อ่านและเขียน checkpoint ที่ไฟล์ SQLite ตามพาธ `file` |
| `configurable.thread_id` | `string` เช่น `"mali"` | เลือกประวัติในไฟล์ตาม thread |
| `store` | `string[]` | เก็บรายการโน้ตระหว่างที่โปรแกรมทำงาน |

บทนี้สร้างไฟล์ SQLite ในโฟลเดอร์ชั่วคราวและล้างไฟล์เมื่อจบการทดลอง หากเก็บโน้ตข้ามการเปิดโปรแกรม ให้จัดที่เก็บถาวรสำหรับข้อมูลที่เครื่องมืออ่านและเขียนด้วย

## 3. เปลี่ยน thread ตอนเปิดใหม่

คัดลอกส่วนหลัง import จากเฉลยลง [`playground.ts`](./playground.ts) แล้วเอาเฉพาะบรรทัดตรวจด้วย `check` ออก รัน `pnpm play 2-17` คง thread `"mali"` ตอนจดไว้ แล้วเปลี่ยนเฉพาะ config ที่ส่งให้ `restarted.invoke` เป็น `{ configurable: { thread_id: "other" } }` เทียบ `history` ที่พิมพ์ออกมาในบรรทัดสุดท้าย

| `thread_id` ที่ใช้กับผู้ช่วยตัวใหม่ | `notes` | `history` |
|---|---|---|
| `"mali"` | `[]` | `["จดโน้ตว่า ซื้อนม","จดโน้ตว่า โทรหาแม่","ขอดูรายการโน้ต","ในแชตก่อนหน้าฉันขอให้จดอะไร"]` |
| `"other"` | `[]` | `["ในแชตก่อนหน้าฉันขอให้จดอะไร"]` |
