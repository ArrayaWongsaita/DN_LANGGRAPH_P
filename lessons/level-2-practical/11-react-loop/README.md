# บทที่ 2-11: วงวน ReAct สร้างเอง

## แนวคิด
**Agent** คือ LLM ที่ "คิด → ลงมือ → ดูผล → คิดต่อ" วนไปจนพอใจ รูปแบบนี้เรียกว่า **ReAct** ใน LangGraph ประกอบจากชิ้นที่เรารู้จักแล้วทั้งหมด:

```
START → agent ──(มี tool_calls?)── ใช่ → tools → agent (วนกลับ)
                    └─ ไม่ → END
```
- `agent`: เรียก LLM ที่ผูก tool แล้ว (บท 2-09) ด้วยประวัติข้อความทั้งหมด
- `tools`: `ToolNode` (บท 2-10) รัน tool call
- edge แบบมีเงื่อนไข (บท 14): ถ้าข้อความล่าสุดมี tool_calls ไปที่ `tools` ไม่งั้นจบ ใช้ `toolsCondition` ที่ LangGraph เตรียมไว้ให้ (คืน `"tools"` หรือ `END`)
- edge `tools → agent` ปิดวง ทำให้ LLM เห็นผลของ tool แล้วตัดสินใจต่อ

## ดูตัวอย่าง
`agent.ts` ประกอบ graph ไว้เกือบหมดแล้ว ขาด 3 จุดที่เป็นหัวใจของวง

## คุณทำได้แล้ว
- สร้าง agent แบบ ReAct ด้วยมือ ซึ่งคือสิ่งที่ `createAgent` (บท 2-16) ซ่อนไว้

## ข้อควรจำ
- LLM ตัดสินเองว่าจะเรียก tool กี่รอบ จึงต้องมีตัวกันวนไม่จบ (บท 2-12)
- ข้อความ tool ต้องอยู่ในประวัติ LLM ถึงจะรู้ผล
