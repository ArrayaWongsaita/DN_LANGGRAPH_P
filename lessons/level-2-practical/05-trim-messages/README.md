# บทที่ 2-05: ตัดประวัติให้สั้นก่อนส่งให้ LLM

## แนวคิด
ยิ่งคุยนาน ประวัติยิ่งยาว: ช้าลง แพงขึ้น และอาจเกินความจุของโมเดล วิธีง่ายที่สุดคือส่งให้ LLM แค่ **ข้อความล่าสุดบางส่วน** โดยที่ State ยังเก็บครบทั้งหมด

`trimMessages` ตัดรายการข้อความให้อยู่ในงบที่กำหนด:

```ts
const recent = await trimMessages(state.messages, {
  maxTokens: 4,            // งบ (หน่วยตาม tokenCounter)
  strategy: "last",        // เก็บ "ท้าย" ไว้ (ข้อความล่าสุด)
  tokenCounter: (msgs) => msgs.length, // นับ 1 ข้อความ = 1 หน่วย (ง่าย ๆ ในบทนี้)
  startOn: "human",        // ผลลัพธ์ต้องขึ้นต้นด้วยข้อความของผู้ใช้
});
```
`tokenCounter` ตัวจริงมักนับ token ด้วยโมเดล ในบทนี้นับเป็น "จำนวนข้อความ" เพื่อให้เห็นชัด

## ดูตัวอย่าง
`trim.ts` เป็น graph แชตที่มีความจำ node `chat` ต้องตัดประวัติก่อนส่งให้ LLM แต่ **ไม่แตะ State** (State ต้องยังเก็บครบ)
