# บทที่ 2-20 ให้คนแก้ร่างก่อนใช้ต่อ

ก่อนส่งอีเมลนัดประชุม ระบบแสดงข้อความร่างให้คนตรวจ คนส่งฉบับที่แก้กลับมาหรือเลือกใช้ร่างเดิมได้ บทนี้ส่งร่างออกด้วย `interrupt({ draft })` แล้วให้ node `review` เก็บฉบับที่เลือกในช่อง `final`

## 1. ส่งร่างให้ตรวจแล้วเลือกฉบับสุดท้าย

เติมข้อ 1 ใน [`review.ts`](./review.ts) ให้ `final` ใช้ข้อความที่แก้เมื่อเป็นสตริงความยาวมากกว่าศูนย์ และใช้ `draft` ในกรณีอื่น แล้วรันจากโฟลเดอร์หลัก ดูให้ครบทั้งฉบับแก้และกรณีใช้ร่าง

```sh
pnpm lesson 2-20
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

[`review.ts`](./review.ts) ใช้ข้อความร่างจาก node `write` ที่ประกอบจากหัวข้อประชุม จึงทดลองได้โดยไม่ต้องตั้ง API key หลังเติมข้อ 1 node `review` จะใช้ข้อความที่คนส่งกลับมาเมื่อเป็นสตริงที่มีความยาวมากกว่าศูนย์

```ts
.addNode("review", (state) => {
  const edited: unknown = interrupt({ draft: state.draft });
  return { final: typeof edited === "string" && edited.length > 0 ? edited : state.draft };
})
```

สคริปต์ใช้แนวทางทำต่อจาก [บท 2-18](../18-interrupt-resume/README.md) และส่งคำตอบสองแบบในคนละ thread ผลที่พิมพ์แสดงว่าคนเห็นร่างเดียวกันและตัดสินใจต่างกัน

```text
{"answer":"เรียนทุกท่าน ขอเลื่อนประชุมเป็นวันอังคาร","request":{"draft":"เรียนทุกท่าน ขอแจ้งนัดประชุมวันจันทร์"},"final":"เรียนทุกท่าน ขอเลื่อนประชุมเป็นวันอังคาร"}
{"answer":"","request":{"draft":"เรียนทุกท่าน ขอแจ้งนัดประชุมวันจันทร์"},"final":"เรียนทุกท่าน ขอแจ้งนัดประชุมวันจันทร์"}
```

หากใช้โมเดลสร้างร่าง ให้ `write` คืน `{ draft: reply.text }` จากผลของโมเดล เมื่อเพิ่ม node สำหรับส่งอีเมลต่อจาก `review` ให้ node นั้นอ่าน `state.final` ซึ่งเก็บข้อความหลังคนตัดสินใจแล้ว

## 2. ค่าที่แอปส่งตอนตรวจร่าง

| ค่า | ชนิดหรือรูปแบบ | ผล |
|---|---|---|
| `state.draft` | `string` | ข้อความที่ `write` เตรียมไว้ |
| `interrupt({ draft: state.draft })` | ออบเจ็กต์ที่มี `draft` | แอปอ่านได้จาก `__interrupt__[0].value` ตอนพัก |
| `resume` | สตริงฉบับแก้ หรือ `""` สำหรับปุ่มใช้ร่าง | ค่าที่ `interrupt` ส่งกลับเข้า node `review` |
| `state.final` | `string` | เก็บฉบับที่จะใช้ต่อ |

บทนี้กำหนดให้สตริงว่างหมายถึงใช้ร่าง ถ้าต้องการให้ข้อความที่มีแต่ช่องว่างใช้ร่างด้วย ให้ตรวจความยาวหลัง `trim()`

## 3. เปลี่ยนข้อความที่ส่งกลับ

คัดลอกโค้ดส่วนหลัง import จากเฉลยลง [`playground.ts`](./playground.ts) ตัดส่วนตรวจออก แล้วใช้ `pnpm play 2-20` แทนค่าว่างใน `["keep", ""]` ด้วยข้อความอื่น แล้วดูช่อง `final` ของ thread `keep`

| `resume` | `final` |
|---|---|
| `""` | `"เรียนทุกท่าน ขอแจ้งนัดประชุมวันจันทร์"` |
| `"เรียนทุกท่าน ขอเลื่อนประชุมเป็นวันอังคาร"` | `"เรียนทุกท่าน ขอเลื่อนประชุมเป็นวันอังคาร"` |
| `" "` (ช่องว่างหนึ่งตัว) | `" "` |
