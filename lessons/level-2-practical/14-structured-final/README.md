# บทที่ 2-14: คำตอบสุดท้ายเป็นข้อมูลมีโครงสร้าง

## แนวคิด
agent ตอบเป็นข้อความอิสระ แต่โปรแกรมของเรามักต้องการ **ข้อมูลที่แน่นอน** (เช่น `{ city, tempC }`) เพื่อไปแสดงผลหรือเก็บลงฐานข้อมูล วิธีที่ตรงไปตรงมาคือเพิ่ม node สุดท้ายหลังวงวน agent ที่ใช้ `withStructuredOutput` (บท 08) แปลงข้อความตอบเป็นข้อมูลตาม schema:

```
START → agent ⇄ tools → format → END
                        └ llm.withStructuredOutput(schema) อ่านประวัติแล้วคืนอ็อบเจ็กต์
```
ผลลัพธ์เก็บใน field `answer` ของ State แยกจาก `messages`

(ใน `createAgent` มี `responseFormat` ทำเรื่องนี้ให้ แต่การทำเองด้วยโหนดเดียวทำให้เห็นว่ามันคืออะไร)

## ดูตัวอย่าง
`final.ts` ต่อ graph ไว้แล้ว (agent วนใช้ tool จนเสร็จ แล้วไปที่ `format`) ขาด schema และตัว node `format`

## โจทย์
เติม 2 ข้อ (ค้นหา `// 👉 ข้อ N` ในไฟล์) แล้วรัน:

    pnpm lesson 2-14

สคริปต์จะพิมพ์ผล แล้วท้ายไฟล์มีส่วนตรวจที่แสดง ✅/❌ (ไม่ต้องแก้และไม่ต้องอ่านก็ได้)

## คุณทำได้แล้ว
- แปลงคำตอบของ agent เป็นข้อมูลที่ตรวจชนิดได้

## ข้อควรจำ
- LLM ยังตอบผิดโครงสร้างได้ ตัวจริงจะตรวจกับ schema ให้และ error ถ้าไม่ตรง
- แยกข้อความ (`messages`) ออกจากผลลัพธ์ (`answer`) ทำให้ใช้งานต่อได้ง่าย

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 2-14` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
