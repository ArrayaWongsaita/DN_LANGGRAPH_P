# บทที่ 2-06 เก็บใจความเก่าด้วยสรุป

หลังตัดประวัติแบบ [บท 2-05](../05-trim-messages/README.md) โมเดลอาจขาดเรื่องสำคัญที่อยู่ต้นบทสนทนา บทนี้เก็บสรุปไว้ใน State พร้อมข้อความล่าสุด เมื่อคุยต่อ graph จะส่งสรุปนำหน้าประวัติที่ยังเหลือ

## 1. ลองสรุปเมื่อประวัติเกิน 4 ข้อความ

เปิด [`summarize.ts`](./summarize.ts) แล้วเติมข้อ 1 ให้สร้าง `RemoveMessage` สำหรับข้อความเก่า ตัวอย่างใช้โมเดลจำลองที่ตอบตามข้อความที่เตรียมไว้ จึงรันได้โดยไม่ใช้ API key

```sh
pnpm lesson 2-06
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

หลัง node `chat` ตอบจบ ถ้ามีข้อความเกิน `MAX_MESSAGES` graph จะเข้าสู่ node `summarize` เมื่อได้ข้อความสรุปแล้ว ให้คืนสรุปพร้อมรายการที่จะลบ

```ts
const oldCount = Math.max(0, state.messages.length - KEEP_LAST);
const removals = state.messages.slice(0, oldCount).map((m) => new RemoveMessage({ id: m.id! }));
return { summary: result.text, messages: removals };
```

เมื่อ `MAX_MESSAGES = 4` และ `KEEP_LAST = 2` ไฟล์จะพิมพ์ผลของแต่ละรอบในรูป JSON

```json
[
  { "messages": 2, "summary": "" },
  { "messages": 4, "summary": "" },
  { "messages": 2, "summary": "ผู้ใช้ชื่อมาลีและชอบแมว" },
  { "messages": 4, "summary": "ผู้ใช้ชื่อมาลีและชอบแมว" }
]
```

รอบ 3 มี 6 ข้อความหลังตอบ จึงสร้างสรุปและลบ 4 ข้อความเก่าสุด รอบ 4 ส่ง `SystemMessage("ผู้ใช้ชื่อมาลีและชอบแมว")` เป็นข้อความแรกให้โมเดลจำลอง แล้วจึงส่งประวัติที่ยังเหลือตามไป

## 2. ค่าที่กำหนดพฤติกรรม

| ค่า | ตัวอย่าง | ผล |
|---|---|---|
| `MAX_MESSAGES` | จำนวนข้อความ เช่น `2`, `4`, `6` | เรียก node สรุปเมื่อจำนวนข้อความหลังตอบมากกว่าค่านี้ |
| `KEEP_LAST` | จำนวนข้อความล่าสุด เช่น `2` หรือ `4` | เลือกจำนวนที่จะเก็บหลังสรุป |
| `state.summary` | สตริงว่างตอนเริ่ม หรือข้อความสรุป | เก็บใจความข้ามรอบและใส่ไว้ใน `SystemMessage` เมื่อมีค่า |
| `RemoveMessage({ id })` | ID ของแต่ละข้อความเก่า | ลบข้อความนั้นผ่าน `MessagesValue` เมื่อ node คืน update |

## 3. เปลี่ยนเกณฑ์แล้วดูว่ารอบไหนเริ่มสรุป

| `MAX_MESSAGES` | `KEEP_LAST` | จำนวนข้อความหลังจบรอบ 1 ถึง 4 | สรุปครั้งแรก |
|---:|---:|---|---|
| 2 | 2 | `[2, 2, 2, 2]` | รอบ 2 |
| 4 | 2 | `[2, 4, 2, 4]` | รอบ 3 |
| 6 | 2 | `[2, 4, 6, 2]` | รอบ 4 |
| 4 | 4 | `[2, 4, 4, 4]` | รอบ 3 |

คัดลอกโค้ดหลัง import จาก [เฉลย](./solution/summarize.ts) จนถึงก่อนส่วนตรวจ ลงใน [`playground.ts`](./playground.ts) แล้วเปลี่ยนค่าและรัน `pnpm play 2-06` สรุปตัวอย่างมีข้อความกำหนดไว้แล้ว จำนวนรอบที่เรียก node สรุปและข้อมูลที่ส่งต่อมาจาก graph ที่รันจริง
