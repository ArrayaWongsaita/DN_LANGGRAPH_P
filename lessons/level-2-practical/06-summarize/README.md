# บทที่ 2-06: สรุปข้อความเก่าแทนการทิ้ง

## แนวคิด
บท 2-05 ตัดของเก่าทิ้ง แต่บางครั้งเรื่องที่คุยไปแล้วยังสำคัญ ทางออกคือ **สรุป** ข้อความเก่าเป็นย่อหน้าสั้น ๆ แล้วเก็บไว้ใน State อีก field หนึ่ง จากนั้นลบข้อความเก่าออก:

```
ก่อน:  [h1, a1, h2, a2, h3, a3]              (ยาวเกิน)
หลัง:  summary="ผู้ใช้ชื่อมาลี ..."  +  [h3, a3]  (ข้อความล่าสุดสองข้อความ)
```
รอบต่อไปตอนเรียก LLM ให้แปะสรุปไว้หน้าสุดเป็น `SystemMessage` กราฟนี้มีสองส่วน:

1. `chat` ตอบตามปกติ (แปะสรุปไว้หน้าถ้ามี)
2. หลังตอบ ถ้าข้อความยาวเกินเกณฑ์ ไปที่ `summarize` เพื่อสรุปและลบของเก่า (เป็น conditional edge เหมือนบท 14)

## ดูตัวอย่าง
`summarize.ts` ต่อ node และ edge ให้แล้ว (เกณฑ์ที่ยาวเกิน = มากกว่า 4 ข้อความ) ที่ขาดคือ 3 จุดข้างใน

## โจทย์
เติม 3 ข้อ (ค้นหา `// 👉 ข้อ N` ในไฟล์) แล้วรัน:

    pnpm lesson 2-06

สคริปต์จะพิมพ์ผล แล้วท้ายไฟล์มีส่วนตรวจที่แสดง ✅/❌ (ไม่ต้องแก้และไม่ต้องอ่านก็ได้)

## คุณทำได้แล้ว
- ย่อประวัติยาวเป็นสรุปโดยไม่ทิ้งเนื้อหาสำคัญ

## ข้อควรจำ
- การสรุปเสียเงินเพิ่มหนึ่งการเรียก LLM ต่อครั้ง จึงสรุปเป็นระยะ ไม่ใช่ทุกรอบ
- ต้องเก็บข้อความล่าสุดไว้ (ในบทนี้ 2 ข้อความ) เพื่อไม่ให้บทสนทนากระโดด

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 2-06` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
