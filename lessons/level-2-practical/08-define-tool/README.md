# บทที่ 2-08: สร้างเครื่องมือ (tool) ให้ LLM

## แนวคิด
LLM เก่งเรื่องภาษา แต่คิดเลขแม่น ๆ หรือรู้อากาศวันนี้ไม่ได้ เราจึงให้ **เครื่องมือ (tool)** ซึ่งเป็นฟังก์ชันธรรมดาที่ห่อด้วย `tool(...)` ให้ LLM "ขอเรียก" ได้ tool ต้องบอก 3 อย่างให้ LLM รู้ว่ามันคืออะไร:

```ts
const add = tool(
  ({ a, b }) => String(a + b),          // ตัวฟังก์ชัน (คืนสตริง)
  {
    name: "add",                         // ชื่อ ที่ LLM ใช้ขอเรียก
    description: "บวกเลขสองจำนวน",      // คำอธิบาย LLM อ่านเพื่อตัดสินใจว่าจะใช้เมื่อไร
    schema: z.object({ a: z.number(), b: z.number() }), // หน้าตาของ argument
  },
);
await add.invoke({ a: 2, b: 3 }); // "5"
```
`description` สำคัญมาก: เขียนไม่ชัด LLM ก็ไม่รู้ว่าควรใช้เมื่อไร `schema` (zod) ทำให้ argument ที่ผิดชนิดถูกปฏิเสธก่อนถึงฟังก์ชันของเรา

## ดูตัวอย่าง
`tools.ts` มี 2 tool ที่ยังไม่สมบูรณ์: `add` (ขาด schema และตัวฟังก์ชัน) และ `getWeather` (ขาดตัวฟังก์ชันที่ค้นจากตาราง)

## คุณทำได้แล้ว
- นิยาม tool ด้วย `tool()` พร้อมชื่อ คำอธิบาย และ schema

## ข้อควรจำ
- tool คืนสตริง (หรือค่าที่แปลงเป็นข้อความได้) เพราะผลจะถูกส่งกลับเป็นข้อความให้ LLM อ่าน
- ชื่อ tool ใช้ตัวอักษรอังกฤษ ไม่มีช่องว่าง
- tool ยังไม่ถูกเรียกโดย LLM ในบทนี้ แค่ทดสอบเรียกเองตรง ๆ ด้วย `.invoke`
