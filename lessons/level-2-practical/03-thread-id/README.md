# บทที่ 2-03: thread_id แยกบทสนทนา

## แนวคิด
`thread_id` คือ "ชื่อช่องเก็บ" ของ checkpointer แต่ละ thread มีประวัติของตัวเอง ไม่ปนกัน:

```ts
graph.invoke(input, { configurable: { thread_id: "mali" } });   // ช่องของมาลี
graph.invoke(input, { configurable: { thread_id: "somchai" } }); // ช่องของสมชาย
```
ในแอปจริง `thread_id` มักมาจากรหัสผู้ใช้หรือรหัสห้องแชต ถ้าอยากให้ผู้ใช้คนเดียวมีหลายบทสนทนา ก็ประกอบรหัสจากหลายส่วน เช่น `"mali:เรื่องงาน"`

## ดูตัวอย่าง
`threads.ts` มี graph ที่มีความจำอยู่แล้ว สิ่งที่ขาดคือ (1) ส่ง `thread_id` ที่รับเข้ามาให้ graph และ (2) ฟังก์ชันประกอบ `thread_id`

## คุณทำได้แล้ว
- แยกบทสนทนาของหลายคนด้วย `thread_id`

## ข้อควรจำ
- `thread_id` เดียวกัน = ประวัติเดียวกัน, คนละค่า = เริ่มใหม่
- `thread_id` เป็นสตริง ออกแบบรูปแบบให้ชัด (เช่น `ผู้ใช้:หัวข้อ`)
