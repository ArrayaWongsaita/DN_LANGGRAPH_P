# บทที่ 2-25: สอนด้วยตัวอย่าง (few-shot)

## แนวคิด
อยากให้ LLM ตอบ **รูปแบบเฉพาะ** (น้ำเสียง โครงสร้าง ป้ายกำกับ) การอธิบายด้วยคำพูดอาจไม่พอ ใส่ **ตัวอย่างคู่ ถาม-ตอบ** ไว้ในประวัติให้เห็นเลยได้ผลกว่ามาก เรียกว่า few-shot ตัวอย่างใส่เป็นข้อความ `human` / `ai` สลับกัน ก่อนคำถามจริง:

```
system: จัดประเภทความรู้สึกของข้อความ ตอบคำเดียว
human:  อาหารอร่อยมาก        ← ตัวอย่าง 1
ai:     บวก
human:  รอนานเกินไป          ← ตัวอย่าง 2
ai:     ลบ
human:  <คำถามจริง>
```
LLM จะเลียนรูปแบบของตัวอย่างต่อ

## ดูตัวอย่าง
`fewshot.ts` ขาดตัวสร้างรายการข้อความจากตัวอย่าง และฟังก์ชันที่ส่งให้ LLM

## ข้อควรจำ

- ตัวอย่างกินจำนวน token ทุกครั้งที่เรียก
