# บทที่ 2-25: สอนด้วยตัวอย่าง (few-shot)

## แนวคิด
อยากให้ LLM ตอบ **รูปแบบเฉพาะ** (น้ำเสียง โครงสร้าง ป้ายกำกับ) การอธิบายด้วยคำพูดอาจไม่พอ ใส่ **ตัวอย่างคู่ ถาม-ตอบ** ไว้ในประวัติให้เห็นเลยได้ผลกว่ามาก เรียกว่า few-shot ตัวอย่างใส่เป็นข้อความ `human` / `ai` สลับกัน ก่อนคำถามจริง:

```
system: จัดประเภทความรู้สึกของข้อความ ตอบคำเดียว
human:  อาหารอร่อยมาก        ← ตัวอย่าง 1
ai:     บวก
human:  รอนานเกินไป          ← ตัวอย่าง 2
ai:     ลบ
human:  <คำถามจริง>
```
LLM จะเลียนรูปแบบของตัวอย่างต่อ

## ดูตัวอย่าง
`fewshot.ts` มีรายการตัวอย่างและชุดคำถามทดสอบ ขาดการสร้างรายการข้อความจากตัวอย่าง และการส่งให้ LLM

## โจทย์
เติม 2 ข้อ (ค้นหา `// 👉 ข้อ N` ในไฟล์) แล้วรัน:

    pnpm lesson 2-25

สคริปต์จะพิมพ์ผล แล้วท้ายไฟล์มีส่วนตรวจที่แสดง ✅/❌ (ไม่ต้องแก้และไม่ต้องอ่านก็ได้)

## คุณทำได้แล้ว
- ใส่ตัวอย่างให้ LLM เลียนแบบรูปแบบคำตอบ

## ข้อควรจำ
- ตัวอย่างน้อยแต่ตรงประเด็น 2-5 ตัวมักพอ ครอบคลุมกรณีที่ต่างกัน
- ตัวอย่างกินจำนวน token ทุกครั้งที่เรียก

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 2-25` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
