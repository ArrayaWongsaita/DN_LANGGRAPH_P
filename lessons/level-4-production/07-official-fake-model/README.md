# บทที่ 4-07: fake model ทางการและการทดสอบ agent

## แนวคิด
บทก่อนใช้ `fakeToolLLM` ที่คอร์สนี้เขียนเอง (`src/fakeToolLLM.ts`) เพื่อให้คุณเห็นว่าโมเดลปลอมคืออะไร งานจริงใช้ของทางการได้เลย: `fakeModel` จาก `langchain` เขียนสคริปต์คำตอบเป็นสายต่อกัน:

```ts
import { fakeModel } from "langchain";
const model = fakeModel()
  .respondWithTools([{ name: "add", args: { a: 2, b: 3 }, id: "c1" }]) // ครั้งที่ 1: ขอเรียก tool
  .respond(new AIMessage("ได้ 5"));                                     // ครั้งที่ 2: ตอบสุดท้าย
model.callCount; model.calls;   // จำนวนครั้งและสิ่งที่โมเดลได้รับ
```
- `respond(...)` รับ `AIMessage` หรือ `Error` (ใส่ `new Error(...)` เพื่อจำลองโมเดลล้ม) **อย่าส่งสตริงเปล่า** ในเวอร์ชันที่ใช้อยู่สตริงถูกโยนเป็น error
- `alwaysThrow(error)`: ล้มทุกครั้ง
- `bindTools` ใช้ร่วมสคริปต์เดียวกัน จึงใช้กับ `createAgent` ได้ตรง ๆ

ทดสอบ agent จึงเป็นการ **กำหนดว่าโมเดลจะ "คิด" อะไรในแต่ละรอบ** แล้วตรวจว่า tool ถูกเรียก ผลลัพธ์ถูก และโค้ดรอบ ๆ รับมือเมื่อโมเดลล้มได้

## ดูตัวอย่าง
`agenttest.ts` ขาดการสร้าง agent จากโมเดลที่ส่งเข้ามา และฟังก์ชันที่จับ error แล้วตอบแบบสุภาพ

- fake model เหมาะกับการทดสอบ "พฤติกรรมรอบ ๆ โมเดล" ไม่ได้วัดว่าโมเดลจริงฉลาดแค่ไหน (ดูบท 4-08)
- ตรวจ `calls` เพื่อรู้ว่าโมเดลได้ prompt/ประวัติอะไร
