# บทที่ 4-07 fake model ทางการและการทดสอบ agent

## แนวคิด

บทก่อนใช้ `fakeToolLLM` ที่คอร์สนี้เขียนเอง (`src/fakeToolLLM.ts`) เพื่อให้คุณเห็นว่าโมเดลปลอมคืออะไร งานจริงใช้ของทางการได้เลย: `fakeModel` จาก `langchain` เขียนสคริปต์คำตอบเป็นสายต่อกัน:

```ts
import { fakeModel } from "langchain";
const model = fakeModel()
  .respondWithTools([{ name: "add", args: { a: 2, b: 3 }, id: "c1" }]) // ครั้งที่ 1: ขอเรียก tool
  .respond(new AIMessage("ได้ 5"));                                     // ครั้งที่ 2: ตอบสุดท้าย
model.callCount; model.calls;   // จำนวนครั้งและสิ่งที่โมเดลได้รับ
```
- `respond(...)` รับ `AIMessage` หรือ `Error` (ใส่ `new Error(...)` เพื่อจำลองโมเดลล้ม) **อย่าส่งสตริงเปล่า** ในเวอร์ชันที่ใช้อยู่สตริงถูกโยนเป็น error
- `alwaysThrow(error)`: ล้มทุกครั้ง
- `bindTools` ใช้ร่วมสคริปต์เดียวกัน จึงใช้กับ `createAgent` ได้ตรง ๆ

ทดสอบ agent จึงเป็นการ **กำหนดว่าโมเดลจะ "คิด" อะไรในแต่ละรอบ** แล้วตรวจว่า tool ถูกเรียก ผลลัพธ์ถูก และโค้ดรอบ ๆ รับมือเมื่อโมเดลล้มได้

## 1. ลองเติมช่องเดียว

เปิด [`agenttest.ts`](./agenttest.ts) แล้วเติมข้อ 1: สร้าง agent จากโมเดลที่ส่งเข้ามาด้วย `createAgent` และ tool บวก รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-07
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มี `makeAddTool()`, โมเดลปลอมจาก `fakeModel` ที่เขียนสคริปต์คำตอบไว้ และฟังก์ชันที่จับ error แล้วตอบสุภาพให้แล้ว ขาดแค่การสร้าง agent

โค้ดตามแนวทาง:

```ts
return createAgent({ model, tools: [makeAddTool()] });
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
  answer: 'ผลคือ 5',
  apology: 'ขออภัย ระบบขัดข้อง',
  real: 'ผลลัพธ์คือ **5** ครับ (2 + 3 = 5)'
✅ โมเดลขอเรียก tool แล้วตอบสุดท้าย: agent ทำครบและได้คำตอบ
✅ รอบที่สองโมเดลเห็นผลลัพธ์ของ tool (5) ในประวัติ
✅ โมเดลล้ม: ได้ข้อความสุภาพ ไม่ใช่ exception
✅ agent เดียวกันกับโมเดลจริงได้คำตอบที่มี 5
```

สิ่งที่ได้: ทดสอบ agent ที่ใช้ tool และกรณีโมเดลล้มด้วย fake model ทางการ

## 3. ส่วนประกอบที่ใช้ในบทนี้

| เมธอดของ `fakeModel` | หน้าที่ |
|---|---|
| `.respondWithTools([...])` | สคริปต์ให้โมเดลเรียก tool ตามที่กำหนด |
| `.respond(...)` | สคริปต์คำตอบข้อความ |
| `calls` | รายการสิ่งที่โมเดลได้รับ ใช้ตรวจ prompt และประวัติ |

## ข้อควรจำ

- fake model เหมาะกับการทดสอบ "พฤติกรรมรอบ ๆ โมเดล" ไม่ได้วัดว่าโมเดลจริงฉลาดแค่ไหน (ดูบท 4-08)
- ตรวจ `calls` เพื่อรู้ว่าโมเดลได้ prompt/ประวัติอะไร
