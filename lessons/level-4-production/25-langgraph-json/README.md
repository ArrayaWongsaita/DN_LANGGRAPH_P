# บทที่ 4-25 โครงสร้างโปรเจกต์และการรันด้วย `langgraph dev`

## แนวคิด

เมื่อ graph พร้อมแล้ว ขั้นต่อไปคือรันเป็น **เซิร์ฟเวอร์** ที่มี API ให้เว็บหรือแอปอื่นเรียก (รองรับ thread, streaming, interrupt) LangGraph มีเครื่องมือ CLI ที่อ่านไฟล์ตั้งค่า `langgraph.json` ที่รากโปรเจกต์:

```json
{
  "dependencies": ["."],
  "graphs": { "my_agent": "./src/agent.ts:agent" },
  "env": ".env"
}
```
- `dependencies`: `["."]` = ใช้ `package.json` ของโปรเจกต์
- `graphs`: ชื่อ graph → `พาธไฟล์:ชื่อที่ export` (ชี้ไปที่ graph ที่ compile แล้ว หรือฟังก์ชันที่สร้างมัน)
- `env`: ไฟล์ตัวแปรสภาพแวดล้อมสำหรับการรันในเครื่อง ส่วนของจริงให้ตั้งในระบบที่ deploy

โครงสร้างโปรเจกต์ที่เอกสารแนะนำ: โค้ดทั้งหมดใน `src/` (`agent.ts` สร้าง graph, `utils/` เก็บ tools/nodes/state), `package.json`, `.env`, `langgraph.json`

การใช้งานจริง (นอกเหนือบทนี้ ทำตามเมื่อพร้อม):
1. รันเซิร์ฟเวอร์พัฒนาในเครื่อง: `npx @langchain/langgraph-cli dev` (เปิด API ในเครื่อง)
2. **LangSmith Studio** เปิดดูกราฟ รัน และดีบักผ่านเบราว์เซอร์ ต้องมีบัญชี LangSmith (ส่งข้อมูล trace ออกไปที่บริการนั้น จึงเป็นทางเลือกและควรอ่านเรื่องความเป็นส่วนตัวก่อนเปิด ตามบท 3-33)
3. Deploy ดูหัวข้อ deployment ในเอกสารทางการ

(ส่วนตรวจของบทนี้ใช้รูปแบบ `./ไฟล์.ts|js:ชื่อ` ตามธรรมเนียมที่เอกสารใช้ เป็นกฎของคอร์ส ไม่ใช่ทุกกรณีที่ CLI รองรับ)

ในบทนี้คุณเขียนฟังก์ชันที่สร้างและตรวจ `langgraph.json` ซึ่งผิดพลาดง่ายเพราะเป็นสตริงพาธ

## 1. ลองเติมช่องเดียว

เปิด [`project.ts`](./project.ts) แล้วเติมข้อ 1: สร้างออบเจ็กต์ config ของ `langgraph.json` ให้มี `dependencies`, `graphs` และ `env` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เปิดเซิร์ฟเวอร์ `langgraph dev` ชั่วคราวเอง (ต้องติดตั้งตามที่ README เดิมของ Level 4-5 อธิบายไว้) บทนี้ไม่เรียกโมเดลจริง

```sh
pnpm lesson 4-25
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีฟังก์ชันตรวจรูปแบบพาธของ graph (`./ไฟล์.ts:ชื่อ export`) ให้แล้ว ขาดแค่การสร้าง config

โค้ดตามแนวทาง:

```ts
return { dependencies: ["."], graphs, env: ".env" };
```

## 2. ผลที่ได้

ผลที่รันจากเฉลย

```text
  "dependencies": [
    "."
  ],
  "graphs": {
    "agent": "./src/agent.ts:agent"
  "env": ".env"
✅ config มีโครงตามที่ CLI ต้องการ
✅ config ไม่มี key จริงหลุดอยู่ข้างใน
✅ พาธที่ถูกต้องผ่าน
✅ พาธผิดรูปแบบถูกจับ พร้อมข้อความบอกรูปแบบที่ถูก
```

สิ่งที่ได้: รู้โครงสร้างที่ LangGraph CLI ต้องการ และตรวจไฟล์ตั้งค่าก่อนรันจริง

## 3. ส่วนประกอบที่ใช้ในบทนี้

| คีย์ | ค่า | หน้าที่ |
|---|---|---|
| `dependencies` | `["."]` | โฟลเดอร์ที่ใช้ติดตั้งและโหลดโค้ด |
| `graphs` | `{ ชื่อ: "./ไฟล์.ts:export" }` | graph ที่เปิดเป็น API |
| `env` | `".env"` | ไฟล์ตัวแปรที่ไม่ commit |

## ข้อควรจำ

- export ต้องเป็น graph ที่ `compile()` แล้ว (หรือฟังก์ชันสร้าง) ถ้า export ผิดชื่อ CLI จะหาไม่เจอ
- ห้ามใส่ key จริงลงใน `langgraph.json` ที่ commit ใช้ไฟล์ `.env` ที่ไม่ commit
