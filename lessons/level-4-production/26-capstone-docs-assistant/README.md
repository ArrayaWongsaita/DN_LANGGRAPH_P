# บทที่ 4-26 Capstone ผู้ช่วยค้นเอกสารที่ปลอดภัย

## แนวคิด

บทสุดท้ายของระดับ 4: รวมสิ่งที่เรียนมาเป็นผู้ช่วยตอบคำถามจากเอกสารเดียว

```
START → guard ─ ต้องห้าม ──────────────→ END (ปฏิเสธ)      [บท 4-13]
          └ ผ่าน → retrieve ─ ไม่เจอ → notFound → END       [บท 4-19, 4-20]
                      └ เจอ → respond (อ้างอิง+ตรวจแหล่ง) → END  [บท 4-21]
ทั้งหมดผูกกับ checkpointer เพื่อจำตาม thread                  [บท 4-24]
```
หลักการที่ใช้ซ้ำทั้งบท:
- **กั้นก่อนจ่ายเงิน:** คำขอต้องห้ามและคำถามที่ค้นไม่เจอ ไม่ควรเรียกโมเดลเลย
- **ไม่เชื่อโมเดลเรื่องแหล่งที่มา:** อ้างไฟล์ที่ไม่เคยค้นเจอ = ไม่มีหลักฐาน ตอบว่าไม่พบ
- **สถานะต่อรอบ:** ค่าอย่าง `blocked` ถูกเขียนใหม่ทุกรอบใน node `guard` เพราะ checkpointer จะจำค่าของรอบก่อนไว้ ถ้าไม่รีเซ็ต การถามต่อใน thread เดิมจะติดสถานะเก่า (รวม `hits`/`sources` ที่ต้องล้างด้วย ไม่งั้นคำตอบปฏิเสธจะมีแหล่งอ้างอิงของคำถามก่อนหน้าติดมา) (ตัวตรวจข้อสุดท้ายจับเรื่องนี้)

## 1. ลองเติม 3 ช่อง

เปิด [`assistant.ts`](./assistant.ts) แล้วเติมข้อ 1 ถึง 3 (ช่องละหนึ่งส่วนของงานนี้) รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-26
```

ในไฟล์ทุกข้อมี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(N)` ของข้อนั้นได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์ต่อ node `retrieve`, `notFound` และ graph ส่วนที่เหลือให้แล้ว

โค้ดตามแนวทางของข้อ 1:

```ts
if (BANNED.some((word) => state.question.includes(word))) return { blocked: true, answer: REFUSAL, hits: [], sources: [] };
return { blocked: false, hits: [], sources: [] };
```

โค้ดตามแนวทางของข้อ 2:

```ts
return state.blocked ? "end" : "retrieve";
```

โค้ดตามแนวทางของข้อ 3:

```ts
const real = new Set(state.hits.map((h) => h.source));
const sources = result.sources.filter((s) => real.has(s));
return sources.length > 0 ? { answer: result.answer, sources } : { answer: NOT_FOUND, sources: [] };
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
  realAnswer: 'ให้รีเซ็ตรหัสผ่านได้ที่พอร์ทัล IT (และหากทำงานนอกออฟฟิศต้องเปิด VPN)',
  sources: [ 'it.md' ]
✅ คำถามปกติ: ค้น ตอบ และอ้างอิงแหล่งที่มา
✅ คำขอต้องห้าม: ปฏิเสธทันที ไม่ค้นและไม่เรียกโมเดล
✅ ค้นไม่เจออะไรเลย: ตอบว่าไม่พบ โดยไม่เรียกโมเดล
✅ โมเดลอ้างไฟล์ที่ไม่เคยได้รับ: ไม่เชื่อ ตอบว่าไม่พบ
✅ อ้างไฟล์ที่มีในระบบแต่ไม่ได้ถูกค้นมารอบนี้: ไม่นับเป็นหลักฐาน
✅ ถามต่อ thread เดิมหลังถูกปฏิเสธ: ไม่ติดสถานะ blocked ของรอบก่อน
✅ ถูกปฏิเสธใน thread เดิม: แหล่งอ้างอิงรอบก่อนไม่ค้างมา
✅ โมเดลจริง: ตอบพร้อมแหล่งอ้างอิง it.md และปฏิเสธคำขอต้องห้าม
```

สิ่งที่ได้: จบระดับ 4: ทนทาน ทดสอบได้ ปลอดภัย ค้นเอกสารได้ และพร้อมต่อกับเซิร์ฟเวอร์จริง

## 3. สรุปแต่ละข้อ

| ข้อ | จุดที่เติม | เทคนิคที่ใช้ (บทที่เรียนมา) |
|---|---|---|
| 1 | `guard`: ปฏิเสธคำถามที่มีคำต้องห้าม และล้าง `hits`/`sources` ทุกรอบ | guardrails (บท 4-13) |
| 2 | เลือกทางหลัง guard: `end` หรือ `retrieve` | conditional edge |
| 3 | กรอง `sources` ให้เหลือเฉพาะที่อยู่ใน `hits` จริง | citations (บท 4-21) |

## ข้อควรจำ

- ก่อนปล่อยใช้จริง: วัดคุณภาพด้วย eval (4-08), เปลี่ยน embedding ปลอมเป็นของจริง, ใช้ Postgres (4-24) และเพิ่มการอนุมัติโดยมนุษย์สำหรับการกระทำที่ย้อนกลับไม่ได้ (3-29)
