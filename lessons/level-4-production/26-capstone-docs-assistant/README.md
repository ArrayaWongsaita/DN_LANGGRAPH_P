# บทที่ 4-26: Capstone ผู้ช่วยค้นเอกสารที่ปลอดภัย

## แนวคิด
บทสุดท้ายของระดับ 4: รวมสิ่งที่เรียนมาเป็นผู้ช่วยตอบคำถามจากเอกสารเดียว

```
START → guard ─ ต้องห้าม ──────────────→ END (ปฏิเสธ)      [บท 4-13]
          └ ผ่าน → retrieve ─ ไม่เจอ → notFound → END       [บท 4-19, 4-20]
                      └ เจอ → respond (อ้างอิง+ตรวจแหล่ง) → END  [บท 4-21]
ทั้งหมดผูกกับ checkpointer เพื่อจำตาม thread                  [บท 4-24]
```
หลักการที่ใช้ซ้ำทั้งบท:
- **กั้นก่อนจ่ายเงิน:** คำขอต้องห้ามและคำถามที่ค้นไม่เจอ ไม่ควรเรียกโมเดลเลย
- **ไม่เชื่อโมเดลเรื่องแหล่งที่มา:** อ้างไฟล์ที่ไม่เคยค้นเจอ = ไม่มีหลักฐาน ตอบว่าไม่พบ
- **สถานะต่อรอบ:** ค่าอย่าง `blocked` ถูกเขียนใหม่ทุกรอบใน node `guard` เพราะ checkpointer จะจำค่าของรอบก่อนไว้ ถ้าไม่รีเซ็ต การถามต่อใน thread เดิมจะติดสถานะเก่า (ตัวตรวจข้อสุดท้ายจับเรื่องนี้)

## ดูตัวอย่าง
`assistant.ts` ต่อ node และเส้นทางไว้เกือบครบ ขาด 3 จุด: node `guard`, ฟังก์ชันเลือกเส้นทางหลัง guard และการตรวจแหล่งอ้างอิงใน node `respond`
