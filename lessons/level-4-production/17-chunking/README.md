# บทที่ 4-17 แบ่งเอกสารยาว ๆ เป็นชิ้นเล็ก (chunking)

## แนวคิด

เอกสารทั้งฉบับยาวเกินกว่าจะใส่เข้า embedding หรือ prompt ทีเดียว และถ้า embed ทั้งฉบับ เวกเตอร์จะเป็นค่าเฉลี่ยของหลายเรื่องจนค้นหาไม่แม่น จึงต้อง **แบ่งเป็นชิ้น (chunk)** ก่อน โดยใช้ `RecursiveCharacterTextSplitter` จาก `@langchain/textsplitters`:

```ts
const splitter = new RecursiveCharacterTextSplitter({ chunkSize: 60, chunkOverlap: 10 });
const pieces = await splitter.splitText(longText);   // string[]
```
- `chunkSize`: ขนาดสูงสุดต่อชิ้น (นับตัวอักษร)
- `chunkOverlap`: ส่วนที่ซ้อนกันระหว่างชิ้นติดกัน กันประโยคสำคัญถูกตัดขาดตรงรอยต่อ
- มันพยายามตัดที่ย่อหน้า → บรรทัด → ช่องว่าง → ตัวอักษร ตามลำดับ **ภาษาไทยไม่มีช่องว่างระหว่างคำ** จึงอาจถูกตัดกลางคำ ถ้าเนื้อหาไทยเยอะให้ตัดตามประโยค/ย่อหน้า (ใส่ตัวคั่นเอง) หรือใช้ตัวตัดคำภาษาไทย
- ทุกชิ้นต้องพกข้อมูล **ที่มา (source)** ติดไปด้วย เพื่อใช้อ้างอิงทีหลัง (บท 4-21)

## 1. ลองเติมช่องเดียว

เปิด [`chunk.ts`](./chunk.ts) แล้วเติมข้อ 1: สร้าง `RecursiveCharacterTextSplitter` ด้วย `chunkSize` และ `chunkOverlap` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ไม่เรียกโมเดลจริง รันได้โดยไม่ต้องมี API key

```sh
pnpm lesson 4-17
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีค่า `CHUNK_SIZE`, `CHUNK_OVERLAP` และฟังก์ชันที่แปลงเอกสารเป็น chunk พร้อมที่มาให้แล้ว ขาดแค่ตัวหั่น

โค้ดตามแนวทาง:

```ts
const splitter = new RecursiveCharacterTextSplitter({ chunkSize: CHUNK_SIZE, chunkOverlap: CHUNK_OVERLAP });
```

## 2. ผลที่ได้

ผลที่รันจากเฉลย

```text
[
  'alpha beta gamma delta epsilon zeta eta theta iota kappa',
  'kappa lambda mu nu xi omicron pi rho sigma tau upsilon phi',
  'phi chi psi omega'
]
✅ เอกสารสั้น: ได้ชิ้นเดียวและพก source
✅ เอกสารยาว: แบ่งเป็นหลายชิ้น แต่ละชิ้นไม่เกิน chunkSize
✅ ทุกชิ้นพก source ของเอกสารตัวเอง (หลายเอกสารไม่ปนกัน)
✅ ไม่มีเนื้อหาหาย และชิ้นติดกันซ้อนกัน (overlap)
```

สิ่งที่ได้: เตรียมเอกสารให้พร้อมสำหรับ index

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ตัวเลือก | ความหมาย | ข้อควรระวัง |
|---|---|---|
| `chunkSize` | ความยาวสูงสุดของชิ้น | เล็กเกินขาดบริบท ใหญ่เกินค้นไม่แม่น |
| `chunkOverlap` | ส่วนที่ซ้อนกันระหว่างชิ้น | ประมาณ 10-20% ของ `chunkSize` เป็นจุดเริ่มต้นที่นิยม |

## ข้อควรจำ

- ชิ้นเล็กเกิน = ขาดบริบท ชิ้นใหญ่เกิน = ค้นไม่แม่น ปรับตามเนื้อหาจริงและวัดด้วย eval (บท 4-08)
- overlap ประมาณ 10-20% ของ chunkSize เป็นจุดเริ่มต้นที่นิยม
