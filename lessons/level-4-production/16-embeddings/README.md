# บทที่ 4-16 embeddings และความคล้าย (cosine)

## แนวคิด

**RAG** (Retrieval-Augmented Generation) คือการให้โมเดลตอบจาก **เอกสารของเรา** โดยค้นหาส่วนที่เกี่ยวข้องมาแนบกับคำถามก่อน ขั้นแรกคือทำให้ข้อความ "เทียบกันได้" ด้วย **embedding**: แปลงข้อความเป็นเวกเตอร์ (ชุดตัวเลข) ที่ข้อความความหมายใกล้กันจะได้เวกเตอร์ชี้ไปทิศใกล้กัน

วัดความใกล้ด้วย **cosine similarity** (ค่า -1..1 ยิ่งใกล้ 1 ยิ่งคล้าย):

    cosine(a, b) = (a · b) / (|a| × |b|)      เมื่อเวกเตอร์ใดเป็นศูนย์ ให้คืน 0

ในบทนี้ใช้ `KeywordEmbeddings` (ใน `src/rag.ts`) เป็น embedding ปลอมที่แค่ **นับคำสำคัญ 6 คำ** เพื่อให้ผลแน่นอนและอธิบายได้ ของจริงใช้โมเดล embedding ซึ่งจับ "ความหมาย" ได้ (เช่น "ลืมพาสเวิร์ด" ใกล้ "รหัสผ่าน") ส่วนวิธีเปรียบเทียบเหมือนกันทุกประการ

อินเทอร์เฟซมาตรฐานของ LangChain: `embeddings.embedQuery(text)` (หนึ่งข้อความ) และ `embeddings.embedDocuments(texts)` (หลายข้อความ)

## 1. ลองเติมช่องเดียว

เปิด [`embed.ts`](./embed.ts) แล้วเติมข้อ 1: เขียนสูตร cosine similarity ระหว่างเวกเตอร์สองตัว รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-16
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีฟังก์ชันจัดอันดับเอกสารตามความคล้ายกับคำถามและ embedding จำลองที่ผลคงที่ให้แล้ว ขาดแค่สูตร cosine

โค้ดตามแนวทาง:

```ts
let dot = 0;
let na = 0;
let nb = 0;
for (let i = 0; i < a.length; i++) {
  dot += a[i] * b[i];
  na += a[i] * a[i];
  nb += b[i] * b[i];
}
return na === 0 || nb === 0 ? 0 : dot / (Math.sqrt(na) * Math.sqrt(nb));
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
embedding จริง: [
  '0.85 ลืมรหัสผ่านให้รีเซ็ต',
  '0.61 คืนเงินได้ใน 7 วัน',
  '0.59 ลาป่วยได้ 30 วัน'
]
✅ cosine: ทิศเดียวกัน 1, ตั้งฉาก 0, ตรงข้าม -1
✅ cosine: เวกเตอร์ศูนย์คืน 0 ไม่ใช่ NaN
✅ rank: เอกสารที่ตรงกับคำถามที่สุดมาก่อน
✅ rank: จำกัดจำนวนตาม k และไม่แก้อาร์เรย์เดิม
✅ embedding จริง: จับความหมายได้ ลืมพาสเวิร์ด = เอกสารรหัสผ่าน
```

สิ่งที่ได้: เข้าใจแกนของการค้นหาแบบ vector: แปลงเป็นเวกเตอร์แล้วเรียงตามความคล้าย

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ค่า cosine | ความหมาย |
|---|---|
| ใกล้ 1 | ทิศทางเวกเตอร์ใกล้กัน ความหมายคล้ายกัน |
| ใกล้ 0 | ไม่เกี่ยวกัน |
| เวกเตอร์ศูนย์ | คืน 0 เพื่อกันการหารด้วยศูนย์ |

## ข้อควรจำ

- ต้องใช้ embedding ตัวเดียวกันทั้งตอนเก็บเอกสารและตอนค้นหา
- คะแนนสูงไม่ได้แปลว่า "ตอบคำถามได้" แค่ "คล้าย" บทต่อ ๆ ไปจะเพิ่มการตรวจสอบ
