# บทที่ 4-16: embeddings และความคล้าย (cosine)

## แนวคิด
**RAG** (Retrieval-Augmented Generation) คือการให้โมเดลตอบจาก **เอกสารของเรา** โดยค้นหาส่วนที่เกี่ยวข้องมาแนบกับคำถามก่อน ขั้นแรกคือทำให้ข้อความ "เทียบกันได้" ด้วย **embedding**: แปลงข้อความเป็นเวกเตอร์ (ชุดตัวเลข) ที่ข้อความความหมายใกล้กันจะได้เวกเตอร์ชี้ไปทิศใกล้กัน

วัดความใกล้ด้วย **cosine similarity** (ค่า -1..1 ยิ่งใกล้ 1 ยิ่งคล้าย):

    cosine(a, b) = (a · b) / (|a| × |b|)      เมื่อเวกเตอร์ใดเป็นศูนย์ ให้คืน 0

ในบทนี้ใช้ `KeywordEmbeddings` (ใน `src/rag.ts`) เป็น embedding ปลอมที่แค่ **นับคำสำคัญ 6 คำ** เพื่อให้ผลแน่นอนและอธิบายได้ ของจริงใช้โมเดล embedding ซึ่งจับ "ความหมาย" ได้ (เช่น "ลืมพาสเวิร์ด" ใกล้ "รหัสผ่าน") ส่วนวิธีเปรียบเทียบเหมือนกันทุกประการ

อินเทอร์เฟซมาตรฐานของ LangChain: `embeddings.embedQuery(text)` (หนึ่งข้อความ) และ `embeddings.embedDocuments(texts)` (หลายข้อความ)

## ดูตัวอย่าง
`embed.ts` ขาดสูตร cosine และฟังก์ชันจัดอันดับเอกสารตามความคล้ายกับคำถาม
