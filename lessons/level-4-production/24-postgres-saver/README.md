# บทที่ 4-24 เก็บความจำถาวรด้วย Postgres

## แนวคิด

`MemorySaver` หายเมื่อรีสตาร์ต และ `SqliteSaver` (บท 2-07) เหมาะกับเครื่องเดียว งานจริงที่มีหลายเซิร์ฟเวอร์ใช้ **Postgres** ผ่าน `@langchain/langgraph-checkpoint-postgres`:

```ts
const saver = PostgresSaver.fromConnString("postgresql://user:pass@localhost:5432/mydb");
await saver.setup();                         // สร้างตารางของ checkpoint (ทำครั้งเดียวต่อฐานข้อมูล)
const graph = builder.compile({ checkpointer: saver });
```
- สลับ checkpointer ได้โดยไม่แก้ตัว graph เพราะทุกตัวใช้อินเทอร์เฟซเดียวกัน จึงเขียนฟังก์ชันสร้าง graph ให้ **รับ checkpointer เป็นพารามิเตอร์** แล้วตอนทดสอบส่ง `MemorySaver` ตอนใช้จริงส่ง `PostgresSaver`
- `thread_id` ไม่ควรยาวเกินไป (ที่ตั้งไว้ในบทนี้คือเพดาน 255 ตัวอักษรตามธรรมเนียมของคอร์ส ไม่ใช่ข้อจำกัดของ Postgres) ถ้าอาจยาวกว่านั้น (เช่นต่อจากหลายส่วน) ให้ย่อด้วย hash
- เปิดการเชื่อมต่อแล้วต้องปิดเมื่อจบโปรแกรม (`await saver.end()`)
- สร้าง `PostgresSaver` ยัง **ไม่เชื่อมต่อ** จนกว่าจะใช้งานจริง ส่วนตรวจท้ายไฟล์จึงรันได้โดยไม่ต้องมีฐานข้อมูล ส่วนสคริปต์ของบทนี้ใช้ฐานข้อมูลจริงจาก `DATABASE_URL` ใน `.env` ซึ่งชี้ไปที่ Postgres ใน Docker ของคอร์ส (ไฟล์ `docker-compose.yml` ที่รากโปรเจกต์ มี pgvector ติดมาด้วยสำหรับบทต่อ ๆ ไป)

## 1. ลองเติมช่องเดียว

เปิด [`persist.ts`](./persist.ts) แล้วเติมข้อ 1: สร้าง `PostgresSaver` จากลิงก์เชื่อมต่อ รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ไม่ต่อฐานข้อมูลจริงในการตรวจ รันได้โดยไม่ต้องมี Postgres

```sh
pnpm lesson 4-24
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีแอปแชตง่าย ๆ ที่รับ checkpointer เข้า graph และย่อ `thread_id` ที่ยาวเกินให้แล้ว ขาดแค่การสร้าง saver บทนี้ไม่ต่อ Postgres จริงในการตรวจ

โค้ดตามแนวทาง:

```ts
return PostgresSaver.fromConnString(connectionString);
```

## 2. ผลที่ได้

ผลที่รันจากเฉลย

```text
  texts: [ 'ฉันจำได้ 1 ข้อความ', 'ฉันจำได้ 3 ข้อความ', 'ฉันจำได้ 5 ข้อความ' ],
  other: 'ฉันจำได้ 1 ข้อความ'
✅ แอปจำประวัติข้ามการเรียก (สองข้อความผู้ใช้ รวม 3 ข้อความ)
✅ thread แยกกัน
✅ ปิดแล้วเปิดใหม่ ความจำยังอยู่ในฐานข้อมูล (5 ข้อความ)
✅ safeThreadId: สั้นพอคงเดิม
✅ safeThreadId: ยาวเกินย่อด้วย hash ที่คงที่ ไม่เกินขีดจำกัด
```

สิ่งที่ได้: ทำให้ความจำของ agent รอดจากการรีสตาร์ตและใช้ร่วมกันหลายเซิร์ฟเวอร์ได้

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ชนิด checkpointer | เหมาะกับ |
|---|---|
| `MemorySaver` | ทดลอง หายเมื่อรีสตาร์ต |
| `SqliteSaver` | เครื่องเดียว (บท 2-07) |
| `PostgresSaver` | หลายเซิร์ฟเวอร์ ข้อมูลอยู่ถาวร |

## ข้อควรจำ

- ตั้งนโยบายลบ checkpoint เก่า ฐานข้อมูลจะโตตามจำนวนรอบสนทนา
- ห้าม commit ลิงก์เชื่อมต่อที่มีรหัสผ่าน (เก็บใน `.env` เท่านั้น)
