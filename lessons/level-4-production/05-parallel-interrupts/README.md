# บทที่ 4-05 หลาย interrupt พร้อมกัน

## แนวคิด

เมื่อ node สองตัวที่ทำงานขนานกัน **ต่างก็เรียก `interrupt()`** graph จะหยุดพร้อมกับ **หลายคำถามค้างอยู่** แต่ละคำถามมี `id` ของตัวเอง เมื่อ resume ให้ส่ง **map จาก id ไปเป็นคำตอบ** ทีเดียว:

```ts
const result = await app.invoke(input, cfg);
if (isInterrupted(result)) {
  const answers: Record<string, string> = {};
  for (const i of result[INTERRUPT]) answers[i.id!] = ตอบ(i.value);
  await app.invoke(new Command({ resume: answers }), cfg);
}
```
- `result[INTERRUPT]` (หรือ `result.__interrupt__`) คืนรายการ interrupt ที่ค้าง แต่ละอันมี `value` (คำถาม) และ `id`
- ต้อง resume ครบทุกอันในครั้งเดียว
- ถ้าตอบทีละอันโดยไม่ใช้ map ผลจะไม่เป็นไปตามคาด ให้ใช้ map เสมอเมื่อมีหลายคำถาม

## 1. ลองเติมช่องเดียว

เปิด [`parallel.ts`](./parallel.ts) แล้วเติมข้อ 1: ตอบทุกคำถามที่ค้างพร้อมกันด้วย `Command({ resume: answers })` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ไม่เรียกโมเดลจริง รันได้โดยไม่ต้องมี API key

```sh

```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มี node `askName` กับ `askCity` ที่รันขนานและโค้ดรวบรวมคำถามเป็น map จาก id ไปคำตอบให้แล้ว ขาดแค่การ resume

โค้ดตามแนวทาง:

```ts
const done = await form.invoke(new Command({ resume: answers }), cfg);
```

## 2. ผลที่ได้

ผลที่รันจากเฉลย

```text
  pendingCount: 2,
  answers: {
    '1abfc52a2b524b249133f70fe21d8f79': 'เชียงใหม่',
    f729a1c1017097d570549e91e8ea8384: 'มาลี'
  done: { name: 'มาลี', city: 'เชียงใหม่' }
✅ ได้ interrupt ค้างสองอันพร้อมกัน
✅ ฟังก์ชันตอบถูกเรียกครั้งเดียวต่อคำถาม และเห็นคำถามจริง
✅ ตอบทีเดียวด้วย map แล้วได้ครบทั้งสองช่อง
```

สิ่งที่ได้: จัดการหลายคำถามที่ค้างพร้อมกันในครั้งเดียว

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ส่วน | ตัวอย่าง | หน้าที่ |
|---|---|---|
| คำถามที่ค้าง | แต่ละอันมี `id` ของตัวเอง | ระบุว่าคำตอบเป็นของคำถามไหน |
| `resume` | `{ [id]: คำตอบ, ... }` | ส่งคำตอบทุกข้อพร้อมกันในครั้งเดียว |

## ข้อควรจำ

- ลำดับของ `interrupt()` ใน node เดียวต้องคงที่ทุกครั้งที่ node ทำงานซ้ำ
- อย่าวน `interrupt()` ใน `while` ข้างใน node เดียว ใช้ edge วนกลับแทน
