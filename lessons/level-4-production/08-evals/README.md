# บทที่ 4-08: ประเมินคุณภาพด้วยชุดทดสอบ (eval)

## แนวคิด
การทดสอบด้วยโมเดลปลอมบอกว่า **โค้ดถูก** แต่ไม่บอกว่า **โมเดลตอบดีไหม** นั่นคืองานของ **eval**: เตรียมชุดคำถามพร้อมคำตอบที่คาดหวัง รันกับโมเดลจริง แล้วให้คะแนน

```ts
type Case = { input: string; expected: string };
const result = await runEval(askMyAgent, cases, containsScorer);  // { passed, total, rate, failures }
```
ตัวให้คะแนน (scorer) มีสองแบบหลัก:
- **กฎ (rule):** เช็กตรง ๆ เช่นคำตอบ "มีคำว่า" ที่คาดหวัง ถูก เร็ว แต่แข็ง
- **โมเดลเป็นกรรมการ (LLM-as-judge):** ให้โมเดลอีกตัวอ่านคำตอบแล้วตอบ `PASS` หรือ `FAIL` ยืดหยุ่น แต่ต้องตรวจสอบความน่าเชื่อถือของกรรมการเอง

ตอน CI ใช้กรรมการปลอมได้ (เหมือนบทที่แล้ว) และรัน eval กับโมเดลจริงเป็นระยะ เช่นก่อนปล่อยเวอร์ชัน

## ดูตัวอย่าง
`evals.ts` ขาด 3 จุด: scorer แบบกฎ, ตัวรันชุดทดสอบ, และ scorer แบบกรรมการ
