# บทที่ 4-10 skills (โหลดความรู้ตามต้องการ)

## แนวคิด

ถ้าใส่คู่มือทุกเรื่องลงใน system prompt ตั้งแต่ต้น prompt จะยาวและแพง รูปแบบ **skills** ให้ agent ตัวเดียวคุมทุกอย่าง แต่ **โหลดความรู้เฉพาะเรื่องเมื่อจำเป็น**:

1. system prompt บอกแค่ **รายชื่อและคำอธิบายสั้น** ของแต่ละ skill
2. agent มี tool `load_skill(name)` ที่คืนเนื้อหาเต็มของ skill นั้น
3. เมื่อผู้ใช้ถามเรื่อง SQL agent เรียก `load_skill("sql")` เนื้อหาเข้าสู่บทสนทนาเฉพาะตอนนั้น

```
prompt: "skills ที่มี: sql — เขียน query, refund — นโยบายคืนเงิน (ใช้ load_skill เพื่ออ่านรายละเอียด)"
agent → load_skill("sql") → ได้คู่มือ SQL → ตอบ
```
ต่างจาก subagents (บท 4-09): ไม่มี agent ย่อย ทุกอย่างอยู่ใน context เดียว จึงเหมาะกับงานที่ผู้ใช้คุยต่อเนื่องและความรู้ขยายได้เรื่อย ๆ (เสียค่า token เพิ่มเมื่อโหลดหลาย skill)

## 1. ลองเติมช่องเดียว

เปิด [`skills.ts`](./skills.ts) แล้วเติมข้อ 1: คืนเนื้อหา skill ตามชื่อ หรือข้อความชัดเจนเมื่อไม่พบ รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-10
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีคลัง skill สองเรื่อง, tool โหลด skill และข้อความรายการ skill สำหรับ prompt ให้แล้ว ขาดแค่ฟังก์ชันที่ค้น skill

โค้ดตามแนวทาง:

```ts
return skills[name] ? skills[name].content : `ไม่พบ skill: ${name}`;
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
โมเดลจริงตอบ: ตามนโยบายคืนเงิน **ลูกค้าสามารถขอคืนเงินได้ภายใน 7 วัน** นับจากวันที่ซื้อ และต้อง**แนบใบเสร็จ**มาด้วยค่ะ

ถ้าต้องการให้ช่วยตรวจสอบรายการสั่งซื้อหรือคำนวณวันหมดเขตคืนเงินของออเดอร์ใดออเดอร์หนึ่ง บอกเลขคำสั่งซื้อมาได้เลยค่ะ
✅ รายการ skill มีชื่อและคำอธิบายสั้น แต่ไม่มีเนื้อหาเต็ม
✅ load_skill: คืนเนื้อหาเต็มเมื่อมี และข้อความชัดเจนเมื่อไม่มี
✅ prompt รอบแรกไม่มีเนื้อหาเต็ม
✅ โหลด skill แล้วเนื้อหาเต็มเข้ามารอบถัดไป โดย skill ที่ไม่ได้โหลดไม่เข้ามา
✅ โมเดลจริงโหลด skill แล้วตอบว่า 7 วัน
```

สิ่งที่ได้: ทำให้ agent โหลดความรู้ตามต้องการแทนการยัดทุกอย่างลง prompt

## 3. ส่วนประกอบที่ใช้ในบทนี้

| ส่วน | หน้าที่ |
|---|---|
| รายการใน system prompt | ชื่อกับคำอธิบายสั้นของแต่ละ skill |
| tool `loadSkill` | โหลดเนื้อหาเต็มของ skill เมื่อ agent ต้องใช้ |
| ชื่อที่ไม่มีอยู่ | ตอบ `ไม่พบ skill: ...` แทนการโยน error |

## ข้อควรจำ

- ชื่อและคำอธิบายสั้นของ skill ต้องพอให้ agent ตัดสินใจได้ว่าจะโหลดอันไหน
- ตั้ง skill ที่ไม่มีอยู่ให้ตอบข้อความชัดเจน แทนการโยน error
