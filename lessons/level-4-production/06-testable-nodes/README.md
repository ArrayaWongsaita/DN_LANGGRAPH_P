# บทที่ 4-06 ออกแบบ node ให้ทดสอบง่าย

## แนวคิด

ส่วนที่เป็นของปลอมในบทเรียน (เช่นบทนี้) **ไม่ใช้ key และไม่เรียกเครือข่าย** เพราะโค้ดถูกเขียนให้ทดสอบได้ หลักการมีสามข้อ:

1. **ส่งโมเดลเข้ามา (dependency injection)** อย่า `import` โมเดลตายตัวใน node ทำเป็น factory: `makeSummarizeNode(llm)` ตอนทดสอบส่งโมเดลปลอม ตอนใช้จริงส่งตัวจริง
2. **แยกตรรกะล้วน ๆ ออกจาก node** ฟังก์ชันที่ไม่เรียกโมเดล (เช่นทำความสะอาดข้อความ) ทดสอบตรง ๆ ได้ ไม่ต้องรัน graph
3. **ทดสอบสองชั้น** ชั้น node เดี่ยว (เรียกฟังก์ชัน node ด้วย State ที่เตรียมไว้) และชั้น graph ทั้งเส้น (เช็กการต่อสาย)

```ts
const node = makeSummarizeNode(fakeLLM);      // ชั้น node
await node({ text: "..." });                   // ได้ { summary }
await buildGraph(fakeLLM).invoke({ text });    // ชั้น graph
```
เมื่อมีหลายขั้นที่ล้มได้ ทดสอบทีละชั้นจะรู้ทันทีว่าพังตรงไหน

## 1. ลองเติมช่องเดียว

เปิด [`testable.ts`](./testable.ts) แล้วเติมข้อ 1: ต่อ node `summarize` (สร้างจาก `makeSummarizeNode(model)`) เข้ากับ pipeline แล้ว `compile` รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-06
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มี node ทำความสะอาด, factory `makeSummarizeNode` ที่รับโมเดลเข้ามา และโมเดลปลอมที่ใช้ทดสอบให้แล้ว ขาดแค่การต่อสาย `START → clean → summarize → END`

โค้ดตามแนวทาง:

```ts
return builder
  .addNode("summarize", makeSummarizeNode(model))
  .addEdge(START, "clean")
  .addEdge("clean", "summarize")
  .addEdge("summarize", END)
  .compile();
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
โมเดลจริงสรุป: สรุปสั้น ๆ: **LangGraph** เป็นไลบรารีสำหรับสร้าง **AI agent/workflow** โดยมองการทำงานเป็น **graph** ประกอบด้วย **node** (ขั้นตอน/เครื่องมือ/agent) และ **edge** (เส้นทาง/เงื่อนไข) ช่วยให
✅ ชั้นตรรกะล้วน: cleanText ไม่ต้องใช้โมเดลเลย
✅ ชั้น node เดี่ยว: ส่ง State เข้าตรง ๆ ได้ { summary }
✅ ชั้น graph: ทำความสะอาดก่อน แล้วโมเดลเห็นข้อความที่สะอาดแล้ว
✅ graph เดียวกันใช้กับโมเดลจริงได้
```

สิ่งที่ได้: เขียนโค้ดที่ทดสอบได้โดยไม่ต้องมีโมเดลจริง

## 3. ส่วนประกอบที่ใช้ในบทนี้

| หลักการ | ทำอย่างไรในบทนี้ |
|---|---|
| ส่งโมเดลเข้ามา | `makeSummarizeNode(model)` ไม่ import โมเดลตายตัว |
| ใช้โมเดลปลอมตอนทดสอบ | ตรวจ `calls` ว่าโมเดลได้รับอะไร ไม่ใช่แค่ผลลัพธ์ |
| แยกส่วนที่เป็นโค้ดธรรมดา | `clean` ทดสอบได้โดยไม่ต้องมีโมเดล |

## ข้อควรจำ

- ถ้าต้องมีของจริงถึงจะทดสอบได้ แปลว่าส่งของเข้ามาไม่ได้ ให้ออกแบบใหม่
- ตรวจ **สิ่งที่โมเดลได้รับ** (`calls`) ไม่ใช่แค่ผลลัพธ์
