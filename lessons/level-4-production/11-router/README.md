# บทที่ 4-11 router (แยกคำถามไปหลายแหล่งความรู้แบบขนาน)

## แนวคิด

**router** เหมาะเมื่อมีหลายแหล่งความรู้ (เช่นเอกสาร HR, เอกสารไอที, คู่มือผลิตภัณฑ์) และคำถามหนึ่งข้ออาจเกี่ยวกับหลายแหล่ง:

```
คำถาม → classify (เลือกแหล่งที่เกี่ยวข้อง ได้หลายแหล่ง)
          ├→ ถาม hr ──┐
          └→ ถาม it ──┴→ synthesize (รวมคำตอบเป็นข้อความเดียว)
```
- ขั้น **classify** ให้โมเดลคืนรายชื่อแหล่งแบบมีโครงสร้าง (บท 2-14)
- ขั้นกระจายใช้ `Send` (บท 3-03) หนึ่งงานต่อหนึ่งแหล่ง รันขนานกัน
- ขั้น **synthesize** รวมผลทั้งหมด (ผลของแต่ละแหล่งเก็บด้วย reducer แบบต่อท้ายอาร์เรย์)
- ต่างจาก subagents (บท 4-09): router ตัดสินใจ **ครั้งเดียวต้นทาง** แล้วขนาน ไม่มีการเรียกซ้อนหลายชั้น และถ้า classify ไม่เจอแหล่งไหนเลยควรมี **ทางสำรอง**

## 1. ลองเติมช่องเดียว

เปิด [`router.ts`](./router.ts) แล้วเติมข้อ 1: กระจายคำถามด้วย `Send` ต่อหนึ่งแหล่ง โดยมี `general` เป็นทางสำรอง รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-11
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์ต่อ graph, node `classify`, `ask` และขั้นรวมคำตอบให้แล้ว ขาดแค่ตัวกระจายงาน

โค้ดตามแนวทาง:

```ts
const sources = state.sources.length > 0 ? state.sources : ["general"];
return sources.map((source) => new Send("ask", { source, question: state.question }));
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
  sources: [ 'hr', 'it' ],
  final: 'รวมคำตอบเป็นคำตอบเดียวได้ดังนี้:
' +
    '
' +
    '**สรุป:** ทั้งจำนวนวันลาป่วยและสิทธิ์ใช้ VPN ทำงานที่บ้านต้องอ้างอ'
✅ สองแหล่ง: ถามทั้งสองและเก็บคำตอบครบ
✅ ขั้นรวมเห็นคำตอบของทุกแหล่ง
✅ แหล่งเดียว: ถามแค่แหล่งนั้น (เรียกโมเดล 3 ครั้ง)
✅ classify ไม่เลือกแหล่งไหน: ใช้ general เป็นทางสำรอง ไม่ล่ม
✅ โมเดลจริง: เลือกอย่างน้อยหนึ่งแหล่ง ได้คำตอบรวม
```

สิ่งที่ได้: สร้างระบบที่ถามหลายแหล่งพร้อมกันแล้วรวมคำตอบ

## 3. ส่วนประกอบที่ใช้ในบทนี้

| กรณี | แหล่งที่ใช้ |
|---|---|
| `classify` เลือกแหล่งได้หนึ่งหรือหลายแหล่ง | `Send("ask", ...)` หนึ่งอันต่อแหล่ง ทำงานขนานกัน |
| ไม่มีแหล่งไหนตรง (รายการว่าง) | ใช้ `["general"]` เป็นทางสำรอง |

## ข้อควรจำ

- จำกัดแหล่งที่ classify เลือกได้ให้อยู่ในรายชื่อที่มีจริงเสมอ
- ทุกการกระจายต้องมีทางสำรองเมื่อไม่มีแหล่งไหนตรง
