# บทที่ 4-11: router (แยกคำถามไปหลายแหล่งความรู้แบบขนาน)

## แนวคิด
**router** เหมาะเมื่อมีหลายแหล่งความรู้ (เช่นเอกสาร HR, เอกสารไอที, คู่มือผลิตภัณฑ์) และคำถามหนึ่งข้ออาจเกี่ยวกับหลายแหล่ง:

```
คำถาม → classify (เลือกแหล่งที่เกี่ยวข้อง ได้หลายแหล่ง)
          ├→ ถาม hr ──┐
          └→ ถาม it ──┴→ synthesize (รวมคำตอบเป็นข้อความเดียว)
```
- ขั้น **classify** ให้โมเดลคืนรายชื่อแหล่งแบบมีโครงสร้าง (บท 2-14)
- ขั้นกระจายใช้ `Send` (บท 3-03) หนึ่งงานต่อหนึ่งแหล่ง รันขนานกัน
- ขั้น **synthesize** รวมผลทั้งหมด (ผลของแต่ละแหล่งเก็บด้วย reducer แบบต่อท้ายอาร์เรย์)
- ต่างจาก subagents (บท 4-09): router ตัดสินใจ **ครั้งเดียวต้นทาง** แล้วขนาน ไม่มีการเรียกซ้อนหลายชั้น และถ้า classify ไม่เจอแหล่งไหนเลยควรมี **ทางสำรอง**

## ดูตัวอย่าง
`router.ts` ต่อ graph ไว้แล้ว ขาดตัวกระจายงาน (รวมทางสำรอง) และ prompt ของขั้นรวมคำตอบ

## คุณทำได้แล้ว
- สร้างระบบที่ถามหลายแหล่งพร้อมกันแล้วรวมคำตอบ

## ข้อควรจำ
- จำกัดแหล่งที่ classify เลือกได้ให้อยู่ในรายชื่อที่มีจริงเสมอ
- ทุกการกระจายต้องมีทางสำรองเมื่อไม่มีแหล่งไหนตรง
