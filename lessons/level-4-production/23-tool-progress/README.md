# บทที่ 4-23 tool ที่รายงานความคืบหน้า (stream mode `tools`)

## แนวคิด

tool ที่ทำงานนาน (ค้นหลายแหล่ง ประมวลผลไฟล์) ทำให้ผู้ใช้เห็นหน้าจอนิ่ง ๆ LangGraph แก้ได้สองทาง: `config.writer` (บท 2-23) หรือแบบใหม่: เขียน tool เป็น **async generator** แล้ว `yield` ความคืบหน้าทีละชิ้น ค่าที่ `return` คือผลลัพธ์สุดท้ายของ tool:

```ts
tool(async function* ({ n }) {
  for (let i = 1; i <= n; i++) yield `ขั้น ${i}`;   // ความคืบหน้า
  return `เสร็จ ${n} ขั้น`;                          // ผลลัพธ์ที่โมเดลเห็น
}, { name: "slow", ... })
```
ฝั่งผู้เรียกใช้ stream mode `"tools"` จะได้เหตุการณ์วงจรของ tool:

- `on_tool_start` (ชื่อ, อินพุต) → `on_tool_event` (ทุก `yield`: อยู่ใน `data`) → `on_tool_end` (ผลลัพธ์) หรือ `on_tool_error`

เหมาะกับการทำแถบความคืบหน้าหรือแสดง "กำลังค้นหาแหล่งที่ 2/3..." โดยไม่ต้องเปลี่ยนตัว agent

## 1. ลองเติมช่องเดียว

เปิด [`progress.ts`](./progress.ts) แล้วเติมข้อ 1: เขียน tool แบบ generator ที่ `yield` ความคืบหน้าแล้ว `return` ผลสุดท้าย รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 4-23
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีโค้ดอ่านสตรีมโหมด `tools` และเก็บความคืบหน้าให้แล้ว ขาดแค่ตัวฟังก์ชัน generator ใน tool

โค้ดตามแนวทาง:

```ts
for (let i = 1; i <= n; i++) yield `ขั้น ${i}`;
return `เสร็จ ${n} ขั้น`;
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
  progress: [ 'ขั้น 1', 'ขั้น 2', 'ขั้น 3' ],
  realProgress: [ 'ขั้น 1', 'ขั้น 2', 'ขั้น 3' ]
✅ ได้ความคืบหน้าครบตามลำดับ
✅ ไม่เรียก tool: ไม่มีความคืบหน้า
✅ โมเดลเห็นเฉพาะค่าที่ return ไม่เห็นค่าที่ yield
✅ โมเดลจริง: ได้ความคืบหน้าเรียงตั้งแต่ขั้น 1
```

สิ่งที่ได้: รายงานความคืบหน้าของ tool แบบเรียลไทม์

## 3. ส่วนประกอบที่ใช้ในบทนี้

| คำสั่ง | ไปที่ไหน |
|---|---|
| `yield ขั้น i` | สตรีมโหมด `tools` ให้ผู้ใช้เห็นความคืบหน้า |
| `return เสร็จ n ขั้น` | ส่งให้โมเดลเป็นผลของ tool |

## ข้อควรจำ

- ค่าที่ `yield` ไม่ถูกส่งให้โมเดล เฉพาะค่า `return` เท่านั้น
- ข้อมูลความคืบหน้าควรสั้นและไม่มีความลับ (ผู้ใช้เห็น)
