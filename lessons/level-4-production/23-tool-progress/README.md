# บทที่ 4-23: tool ที่รายงานความคืบหน้า (stream mode `tools`)

## แนวคิด
tool ที่ทำงานนาน (ค้นหลายแหล่ง ประมวลผลไฟล์) ทำให้ผู้ใช้เห็นหน้าจอนิ่ง ๆ LangGraph แก้ได้สองทาง: `config.writer` (บท 2-23) หรือแบบใหม่: เขียน tool เป็น **async generator** แล้ว `yield` ความคืบหน้าทีละชิ้น ค่าที่ `return` คือผลลัพธ์สุดท้ายของ tool:

```ts
tool(async function* ({ n }) {
  for (let i = 1; i <= n; i++) yield `ขั้น ${i}`;   // ความคืบหน้า
  return `เสร็จ ${n} ขั้น`;                          // ผลลัพธ์ที่โมเดลเห็น
}, { name: "slow", ... })
```
ฝั่งผู้เรียกใช้ stream mode `"tools"` จะได้เหตุการณ์วงจรของ tool:

- `on_tool_start` (ชื่อ, อินพุต) → `on_tool_event` (ทุก `yield`: อยู่ใน `data`) → `on_tool_end` (ผลลัพธ์) หรือ `on_tool_error`

เหมาะกับการทำแถบความคืบหน้าหรือแสดง "กำลังค้นหาแหล่งที่ 2/3..." โดยไม่ต้องเปลี่ยนตัว agent

## ดูตัวอย่าง
`progress.ts` ขาดตัว tool แบบ generator และฟังก์ชันที่เก็บความคืบหน้าจากสตรีม

## คุณทำได้แล้ว
- รายงานความคืบหน้าของ tool แบบเรียลไทม์

## ข้อควรจำ
- ค่าที่ `yield` ไม่ถูกส่งให้โมเดล เฉพาะค่า `return` เท่านั้น
- ข้อมูลความคืบหน้าควรสั้นและไม่มีความลับ (ผู้ใช้เห็น)

## ลองเล่นต่อ
