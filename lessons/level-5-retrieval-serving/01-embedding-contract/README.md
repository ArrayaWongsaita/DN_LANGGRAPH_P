# บทที่ 5-01 embedding จริงและข้อตกลงที่ต้องรักษา

## แนวคิด

ใน Level 4 คุณใช้ embedding ปลอมที่นับคำ ในระดับนี้เราใช้ embedding **จริง** ซึ่งจับ "ความหมาย" ได้ เช่น "ลืมพาสเวิร์ด" ใกล้ "ลืมรหัสผ่าน" ทั้งที่ไม่มีคำซ้ำกันเลย ตัวทำ embedding มาจาก `getEmbeddings()` ใน `src/embeddings.ts` ตั้งค่าที่ `.env` (ดู `.env.example`: `GOOGLE_API_KEY` ที่ขอฟรีได้ และ `EMBEDDING_DIMENSIONS`) ส่วนตรวจของบทที่ไม่เกี่ยวกับ embedding ใช้ embedding ปลอม จึงไม่ต้องมี key

ข้อตกลงที่ต้องรักษาเสมอ ไม่งั้นการค้นหาพังแบบเงียบ ๆ:
1. **โมเดลเดียวกันทั้งตอนเก็บและตอนค้นหา** เวกเตอร์จากคนละโมเดลเทียบกันไม่ได้
2. **จำนวนมิติ (dimension) ต้องตรงกับตารางฐานข้อมูล** (`vector(768)` รับได้เฉพาะ 768 ช่อง) ถ้าไม่ตรงจะได้ error ตอน insert หรือแย่กว่านั้นคือผลที่ผิดโดยไม่รู้ตัว
3. **ส่งทีละกลุ่ม (batch)** ผู้ให้บริการจำกัดจำนวนข้อความต่อคำขอ และโควตาฟรีมีเพดาน การส่งข้อความหมื่นอันในคำขอเดียวจะล้มเหลว ส่งทีละกลุ่มตามลำดับ ลำดับของเวกเตอร์ต้องตรงกับลำดับของข้อความ

## 1. ลองเติมช่องเดียว

เปิด [`batch.ts`](./batch.ts) แล้วเติมข้อ 1: เติมส่วนหลักของบท (embedding จริงและข้อตกลงที่ต้องรักษา) รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้เรียกโมเดลจริง ตั้ง provider และ API key ใน `.env` ตาม [บท 1-02](../../level-1-basics/02-llm-config/README.md) ก่อนรัน

```sh
pnpm lesson 5-01
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีส่วนอื่นของบทนี้เขียนไว้ให้แล้ว ขาดแค่ข้อ 1

โค้ดตามแนวทาง:

```ts
const out: number[][] = [];
for (const group of chunked(texts, batchSize)) out.push(...(await embeddings.embedDocuments(group)));
return out;
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
0.765 ลืมรหัสผ่านให้รีเซ็ตที่พอร์ทัล IT
0.608 สินค้าคืนเงินได้ภายใน 7 วัน
0.579 ลาป่วยได้ปีละ 30 วัน
✅ chunked: แบ่งเป็นกลุ่ม กลุ่มสุดท้ายอาจสั้นกว่า รายการว่างได้อาร์เรย์ว่าง
✅ chunked: ขนาดกลุ่มต้องมากกว่า 0
✅ embedInBatches: ส่งทีละกลุ่ม ผลเรียงตามข้อความเดิม
✅ embedInBatches: ส่งตามลำดับ ไม่ส่งซ้อนกัน
✅ embedInBatches: ไม่มีข้อความ = ไม่เรียก embedding เลย
✅ assertDimensions: ผ่านเมื่อมิติถูก และบอกตัวแรกที่ผิดพร้อมตัวเลข
✅ embedding จริง: เวกเตอร์มิติถูก และเอกสารรหัสผ่านได้คะแนนสูงสุด
```

สิ่งที่ได้: ใช้ embedding จริงอย่างปลอดภัย: ส่งเป็นกลุ่ม ตรวจมิติ และรักษาลำดับ

## ข้อควรจำ

- ถ้าเปลี่ยนโมเดลหรือจำนวนมิติ ต้อง embed เอกสารทั้งหมดใหม่
- embedding ที่ตอบเร็วและฟรีมีโควตา เก็บผลไว้ใช้ซ้ำแทนการเรียกซ้ำ (บท 5-06)
