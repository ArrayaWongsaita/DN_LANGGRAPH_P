# บทที่ 5-04: ผสมการค้นด้วยคำและด้วยความหมาย (hybrid search)

## แนวคิด
การค้นด้วยเวกเตอร์เก่งเรื่อง "ความหมาย" แต่พลาดเรื่อง **คำเฉพาะ** เช่นรหัสสินค้า `AX-4421` ชื่อคน หรือคำย่อ ส่วนการค้นด้วยคำ (keyword) แม่นกับคำเฉพาะแต่ไม่เข้าใจความหมาย ใช้ **ทั้งสองแล้วรวมผล** (hybrid) จึงดีกว่าอย่างใดอย่างหนึ่ง

คะแนนของสองระบบไม่อยู่บนสเกลเดียวกัน (cosine 0-1 กับจำนวนคำที่ตรง) จึงไม่ควรเอามาบวกกันตรง ๆ วิธีที่นิยมคือ **Reciprocal Rank Fusion (RRF)** ใช้เฉพาะ "ลำดับ" ของแต่ละรายการ:

    คะแนนรวมของเอกสาร = ผลรวมของ 1 / (k + อันดับ)   ต่อทุกรายการที่เอกสารนั้นปรากฏ
    (อันดับนับจาก 1, ค่า k = 60 เป็นค่ามาตรฐาน)

เอกสารที่อยู่ในทั้งสองรายการจึงได้คะแนนสูง แม้ไม่ใช่อันดับหนึ่งของรายการใดเลย

## ดูตัวอย่าง
`hybrid.ts` ขาด 3 ส่วน: จัดอันดับด้วยคำ, การรวมผลด้วย RRF และฟังก์ชันที่ประกอบสองอย่างเข้าด้วยกัน (ส่วนอันดับจากเวกเตอร์รับเข้ามาเป็นรายการ id ที่เรียงแล้ว มาจากบท 5-02 หรือ 5-03)

## คุณทำได้แล้ว

## ข้อควรจำ
- RRF ใช้ได้กับกี่รายการก็ได้ (เช่นเพิ่มการค้นจาก metadata)
- ตัดคำภาษาไทยไม่มีช่องว่าง การค้นด้วยคำแบบง่ายนี้จึงเหมาะกับคำที่คั่นด้วยช่องว่างหรือรหัส ของจริงควรใช้การค้นข้อความเต็มของฐานข้อมูลที่รองรับภาษาไทย
