# บทที่ 5-04 ผสมการค้นด้วยคำและด้วยความหมาย (hybrid search)

## แนวคิด

การค้นด้วยเวกเตอร์เก่งเรื่อง "ความหมาย" แต่พลาดเรื่อง **คำเฉพาะ** เช่นรหัสสินค้า `AX-4421` ชื่อคน หรือคำย่อ ส่วนการค้นด้วยคำ (keyword) แม่นกับคำเฉพาะแต่ไม่เข้าใจความหมาย ใช้ **ทั้งสองแล้วรวมผล** (hybrid) จึงดีกว่าอย่างใดอย่างหนึ่ง

คะแนนของสองระบบไม่อยู่บนสเกลเดียวกัน (cosine 0-1 กับจำนวนคำที่ตรง) จึงไม่ควรเอามาบวกกันตรง ๆ วิธีที่นิยมคือ **Reciprocal Rank Fusion (RRF)** ใช้เฉพาะ "ลำดับ" ของแต่ละรายการ:

    คะแนนรวมของเอกสาร = ผลรวมของ 1 / (k + อันดับ)   ต่อทุกรายการที่เอกสารนั้นปรากฏ
    (อันดับนับจาก 1, ค่า k = 60 เป็นค่ามาตรฐาน)

เอกสารที่อยู่ในทั้งสองรายการจึงได้คะแนนสูง แม้ไม่ใช่อันดับหนึ่งของรายการใดเลย

## 1. ลองเติมช่องเดียว

เปิด [`hybrid.ts`](./hybrid.ts) แล้วเติมข้อ 1: เติมส่วนหลักของบท (ผสมการค้นด้วยคำและด้วยความหมาย (hybrid search)) รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ไม่เรียกโมเดลจริง รันได้โดยไม่ต้องมี API key

```sh
pnpm lesson 5-04
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มีส่วนอื่นของบทนี้เขียนไว้ให้แล้ว ขาดแค่ข้อ 1

โค้ดตามแนวทาง:

```ts
const score = new Map<string, number>();
const firstSeen = new Map<string, number>();
let order = 0;
for (const ranking of rankings) {
  ranking.forEach((id, i) => {
    score.set(id, (score.get(id) ?? 0) + 1 / (k + i + 1));
    if (!firstSeen.has(id)) firstSeen.set(id, order++);
  });
}
return [...score.keys()].sort((a, b) => score.get(b)! - score.get(a)! || firstSeen.get(a)! - firstSeen.get(b)!);
```

## 2. ผลที่ได้

ผลที่รันจากเฉลย

```text
ค้นด้วยคำอย่างเดียว: [ 'a' ] → ผสม: [ 'a', 'b', 'c' ]
✅ keywordRank: นับคำที่ตรง ตัดอันที่ไม่ตรงเลย ไม่สนตัวพิมพ์
✅ keywordRank: ตรงมากคำกว่ามาก่อน เท่ากันคงลำดับเดิม
✅ RRF: อยู่ในสองรายการชนะเป็นที่หนึ่งของรายการเดียว
✅ RRF: คำนวณตามสูตรจริง (k=1 และ k ใหญ่)
✅ RRF: คะแนนเท่ากันให้ตัวที่ปรากฏก่อนมาก่อน และรายการว่างได้ว่าง
✅ hybridSearch: เอกสารที่เจอแค่ด้วยคำ (รหัสสินค้า) ยังขึ้นมาแม้เวกเตอร์ไม่เจอ
✅ hybridSearch: จำกัดด้วย topN และเอกสารที่ทั้งสองระบบเห็นตรงกันมาก่อน
```

สิ่งที่ได้: รวมผลค้นหาจากหลายระบบโดยไม่ต้องปรับสเกลคะแนน

## ข้อควรจำ

- RRF ใช้ได้กับกี่รายการก็ได้ (เช่นเพิ่มการค้นจาก metadata)
- ตัดคำภาษาไทยไม่มีช่องว่าง การค้นด้วยคำแบบง่ายนี้จึงเหมาะกับคำที่คั่นด้วยช่องว่างหรือรหัส ของจริงควรใช้การค้นข้อความเต็มของฐานข้อมูลที่รองรับภาษาไทย
