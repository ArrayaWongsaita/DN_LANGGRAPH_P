# บทที่ 5-02 เก็บและค้นเวกเตอร์ด้วย pgvector (SQL ตรง ๆ)

## แนวคิด

**pgvector** เป็นส่วนเสริมของ Postgres ที่เพิ่มชนิดข้อมูล `vector(N)` และตัวดำเนินการวัดระยะ ฐานข้อมูลในโปรเจกต์นี้ (`docker compose up -d --wait`) เปิดใช้ไว้ให้แล้ว หลักการ:

```sql
CREATE TABLE course_chunks (id text PRIMARY KEY, source text, text text, embedding vector(768));
-- ค้นหาใกล้ที่สุด: <=> คือระยะ cosine (ยิ่งน้อยยิ่งใกล้)
SELECT source, text, 1 - (embedding <=> $1::vector) AS score
FROM course_chunks ORDER BY embedding <=> $1::vector LIMIT $2;
```
- เวกเตอร์ส่งเป็นสตริงรูป `[0.1,0.2,...]` แล้วแปลงด้วย `::vector`
- **ใส่ค่าด้วยพารามิเตอร์ (`$1`, `$2`) เสมอ ห้ามต่อสตริงเข้า SQL** เพื่อกัน SQL injection และให้ฐานข้อมูลเก็บแผนคำสั่งไว้ใช้ซ้ำ
- ต้อง `ORDER BY` ด้วยระยะ (ไม่ใช่ด้วยคะแนนที่ตั้งชื่อใหม่) เพื่อให้ดัชนี (`hnsw`) ช่วยให้เร็ว
- `score = 1 - ระยะ` ทำให้ยิ่งมากยิ่งคล้าย ตรงกับที่คุณคุ้นจากบท 4-18

ส่วนตรวจใช้ฐานข้อมูลปลอมที่จดว่าได้รับ SQL และพารามิเตอร์อะไร ส่วนที่เปิด Docker ใช้ Postgres จริงในสคริปต์เดียวกัน

## 1. ลองเติมช่องเดียว

เปิด [`pgvector.ts`](./pgvector.ts) แล้วเติมข้อ 1: เติมส่วนหลักของบท (เก็บและค้นเวกเตอร์ด้วย pgvector (SQL ตรง ๆ)) รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ใช้ Postgres: เปิดฐานข้อมูลด้วย `docker compose up -d --wait` และตั้ง `DATABASE_URL` ใน `.env` ก่อนรัน

```sh
pnpm lesson 5-02
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

`pgvector.ts` มีคำสั่งสร้างตารางและ insert ให้แล้ว ส่วนอื่นของบทนี้เขียนไว้ให้แล้ว ขาดแค่ข้อ 1

โค้ดตามแนวทาง:

```ts
return "SELECT source, text, 1 - (embedding <=> $1::vector) AS score FROM course_chunks ORDER BY embedding <=> $1::vector LIMIT $2";
```

## 2. ผลที่ได้

ตัวอย่างผลที่รันจากเฉลย ข้อความจากโมเดลเปลี่ยนได้ทุกรอบ

```text
0.717 it.md ลืมรหัสผ่านให้รีเซ็ตที่พอร์ทัล IT และต้องเปิด VPN เมื่อทำงานนอกออฟฟิศ
0.596 shop.md สินค้าคืนเงินได้ภายใน 7 วัน การจัดส่งภายใน 3 วัน
0.570 hr.md พนักงานลาป่วยได้ปีละ 30 วัน ต้องแจ้งหัวหน้า และเงินเดือนจ่ายสิ้นเดือน
✅ toVectorLiteral: รูป [a,b,c] ที่ pgvector อ่านได้
✅ toVectorLiteral: ค่าที่ไม่ใช่ตัวเลขจำกัดถูกปฏิเสธ
✅ searchSql: เรียงตามระยะ cosine จากน้อยไปมาก จำกัดจำนวน และใช้พารามิเตอร์
✅ searchChunks: ส่งเวกเตอร์และ k เป็นพารามิเตอร์ ไม่ต่อสตริงเข้า SQL
✅ searchChunks: แปลงแถวเป็น Hit และ score เป็นตัวเลขแม้ฐานข้อมูลส่งเป็นสตริง
✅ searchChunks: ไม่พบแถวเลยได้อาร์เรย์ว่าง
✅ upsertChunk (โค้ดที่ให้ไว้) ใช้ toVectorLiteral ของคุณและพารามิเตอร์ครบ
✅ ฐานข้อมูลจริง: ถามว่า 'ลืมพาสเวิร์ด' เจอเอกสาร it.md ก่อน และคะแนนเรียงมากไปน้อย
```

สิ่งที่ได้: ใช้ pgvector ตรง ๆ และเข้าใจว่าไลบรารีระดับสูงทำอะไรให้ข้างใต้
