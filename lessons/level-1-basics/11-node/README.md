# บทที่ 11: node (ขั้นตอนหนึ่งขั้นของ graph)

## แนวคิด
**node** คือขั้นตอนหนึ่งขั้นใน graph และมันก็แค่ **ฟังก์ชันธรรมดา**:

```
state ปัจจุบัน ──► node ──► update (เฉพาะ field ที่อยากเปลี่ยน)
```

```ts
const clean = (state) => ({ text: state.text.trim() });
```
กติกาสำคัญ 3 ข้อ:
1. node **รับ state** ทั้งก้อนเข้ามา อ่านค่าที่ต้องใช้
2. node **คืน update** เป็น object ที่มีเฉพาะ field ที่อยากเปลี่ยน field อื่นคงเดิม LangGraph เป็นคนเอา update ไปรวมเข้า state ให้
3. **อย่าแก้ state ตรง ๆ** (เช่น `state.text = ...`) ให้คืน object ใหม่เสมอ

node จะเป็น `async` ก็ได้ (บทหน้าจะมี node ที่เรียก LLM)

## ดูตัวอย่าง
เปิด `textGraph.ts`: มี 2 node คือ `clean` (ตัดช่องว่าง) กับ `measure` (นับความยาว) ส่วนการต่อเข้าเป็น graph ให้มาแล้ว: `START → clean → measure → END` ท้ายไฟล์รัน graph แล้วตรวจผลให้

## คุณทำได้แล้ว
- เขียน node ที่อ่าน state แล้วคืน update
- เข้าใจว่า node คืนแค่ส่วนที่เปลี่ยน ไม่ต้องคืนทั้ง state

## ข้อควรจำ
- node = ฟังก์ชัน `(state) => update`
- คืนเฉพาะ field ที่เปลี่ยน
- ไม่แก้ state เดิมตรง ๆ
