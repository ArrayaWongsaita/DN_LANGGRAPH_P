# บทที่ 02: ตั้งค่า LLM (config) แล้ว export ให้บทอื่นใช้

## แนวคิด
ใน LangChain ทุกเจ้า (Groq, Google Gemini, DeepSeek, OpenCode Go ฯลฯ) มี **chat model** ที่ใช้งานเหมือนกัน คือ `.invoke(...)` ต่างกันแค่ตอน **สร้าง** (ใช้คลาสไหน ใส่ key และ URL อะไร)

ดังนั้นเราสร้าง chat model ไว้ที่เดียว คือไฟล์ `llm.ts` ของบทนี้ แล้ว `export const llm` ให้บทอื่น `import { llm }` ไปใช้ จะเปลี่ยนเจ้า LLM ก็แก้ที่ไฟล์เดียวนี้

```
บท 01: env.ts  ── export env ──►  บท 02: llm.ts ── export llm ──►  บท 03, 04, ... import { llm }
(ตรวจ .env)                       (สร้าง chat model)                (เรียกใช้)
```

> **กล่องเล็ก: ทำไมคอมเมนต์ตัวเลือกที่ไม่ใช้ไว้**
> ในไฟล์มีตัวเลือกครบทุกเจ้าให้ แต่ `export const llm` มีได้ชื่อเดียว จึงเปิดไว้ **เจ้าเดียว** ที่เหลือคอมเมนต์ (`//`) ไว้ เปลี่ยนเจ้าทีหลังก็แค่สลับว่าบล็อกไหนเปิด

## ดูตัวอย่าง
เปิด `llm.ts`:
- ด้านบน `import { env }` จากบท 01 (ค่าที่คุณตรวจไว้แล้ว)
- ตรงกลางคือตัวเลือก A, B, C, D ถูกคอมเมนต์ไว้ทั้งหมด แต่ละบล็อกมี `import` ของเจ้านั้นอยู่ในบล็อกเลย
- ด้านล่างเป็นส่วนเรียก `llm` จริงเพื่อดูผล (ไม่ต้องแก้)

## โจทย์
ช่อง `todo(1)` อยู่บรรทัด `export const llm: BaseChatModel = todo(1);`
1. เลือกเจ้า LLM ที่คุณมี key (ตั้งไว้ใน `.env` ในบท 01 แล้ว)
2. **ลบ** บรรทัด `todo(1)` ทิ้ง
3. ที่บล็อกของเจ้านั้น **เอา `//` ออก** ทั้ง `import` และ `export const llm`

แล้วรัน (ใช้ LLM จริง):

    pnpm lesson 02

ถ้าได้คำตอบสั้น ๆ กลับมาพร้อม `✅ ผ่าน` แปลว่า `llm` ใช้งานได้ ข้อควรรู้: โควตาฟรีของ Google จำกัดประมาณ 15 ครั้งต่อนาที ให้รันทีละบทและอย่ารันรัว ๆ ถ้าเจอ error: **401** = key ผิดหรือไม่ได้ตั้ง (ตรวจ `.env`), **404** = ชื่อโมเดลผิดหรือบัญชีไม่มีสิทธิ์ (ตั้ง `LLM_MODEL` ใน `.env`), **429** = เรียกถี่เกินโควตา รอแล้วลองใหม่

> บท 03 เป็นต้นไปจะ `import { llm }` จากไฟล์นี้ ถ้าบทนี้ยังไม่ผ่าน บทถัดไปจะรันไม่ได้

## คุณทำได้แล้ว
- สร้าง chat model ของเจ้า LLM ที่เลือกเอง
- ใช้ `env` ที่ตรวจแล้วจากบท 01
- `export` ตัวแปรให้บทอื่น import ไปใช้

## ข้อควรจำ
- ทุกเจ้าหน้าตาการใช้งานเหมือนกัน ต่างกันแค่ตอนสร้าง
- เปิดไว้เจ้าเดียว ที่เหลือคอมเมนต์ไว้
- ห้ามเขียน key ลงในไฟล์นี้ ให้ใช้ `env.XXX` เสมอ
