# บทที่ 21: conditional edge (แยกทาง)

## เรียนอะไร
conditional edge ให้ graph เลือกทางตามค่าใน state: router ดู state แล้วคืนชื่อ node ที่จะไปต่อ

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `route.ts`
2. เปิด `route.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/21-conditional-edge` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
