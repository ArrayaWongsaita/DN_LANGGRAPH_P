# บทที่ 14: พารามิเตอร์และการใช้ token

## เรียนอะไร
temperature คุมความสุ่มของคำตอบ (ต่ำ = นิ่ง สูง = หลากหลาย) และ token คือหน่วยที่ใช้นับโควตา อ่านได้จาก usage_metadata ของคำตอบ

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว และรัน `npm run lesson 14` กับ LLM จริงแล้วเห็นผลลัพธ์

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `usage.ts`
2. เปิด `usage.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/14-params-and-usage` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
