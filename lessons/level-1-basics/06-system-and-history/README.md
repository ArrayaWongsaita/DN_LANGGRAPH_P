# บทที่ 1-06 จัดข้อความระบบและประวัติก่อนส่งคำถามใหม่

มาลีบอกว่าชอบแมว แล้วถามว่า “ฉันชื่ออะไร และชอบอะไร” ต่อจาก [บท 1-05](../05-message-object/README.md) ที่ดูข้อความชนิด `ai` บทนี้จัดคำสั่งและประวัติเป็นอาร์เรย์ เพื่อเห็นเลยว่าโมเดลจะได้รับข้อมูลอะไรบ้าง

## 1. เรียงคำสั่ง ประวัติ และคำถาม

เปิด [`history.ts`](./history.ts) แล้วเติมข้อ 1 สร้าง `messages` โดยใส่ `system` ไว้หน้า ตามด้วยสมาชิกของ `history` แล้วปิดท้ายด้วย `question` รันจากโฟลเดอร์หลักของโปรเจกต์ สคริปต์พิมพ์ชุดข้อความให้ตรวจในเครื่องโดยไม่ใช้ API key

```sh
pnpm lesson 1-06
```

```ts
const system = new SystemMessage("ตอบสั้น ๆ เป็นภาษาไทย");
const history = [new HumanMessage("ฉันชื่อมาลี ชอบแมว"), new AIMessage("ยินดีที่ได้รู้จักค่ะ")];
const question = new HumanMessage("ฉันชื่ออะไร และชอบอะไร");
const messages = [system, ...history, question];
```

ผลจากชุดข้อความที่กำหนดไว้ เมื่อมีประวัติ โมเดลจะได้รับชื่อและสิ่งที่มาลีชอบพร้อมคำถามรอบใหม่ เมื่อประวัติว่าง เหลือเพียงคำสั่งและคำถาม

```text
มีประวัติ [
  [ 'system', 'ตอบสั้น ๆ เป็นภาษาไทย' ],
  [ 'human', 'ฉันชื่อมาลี ชอบแมว' ],
  [ 'ai', 'ยินดีที่ได้รู้จักค่ะ' ],
  [ 'human', 'ฉันชื่ออะไร และชอบอะไร' ]
]
ประวัติว่าง [
  [ 'system', 'ตอบสั้น ๆ เป็นภาษาไทย' ],
  [ 'human', 'ฉันชื่ออะไร และชอบอะไร' ]
]
✅ ส่งคำสั่ง ประวัติ และคำถามตามลำดับ
```

## 2. ความหมายของชนิดข้อความ

| คลาส | ข้อความที่ใส่ในตัวอย่าง |
|---|---|
| `SystemMessage` | คำสั่งที่แอปกำหนด เช่น รูปแบบคำตอบ บทนี้วางไว้ต้นรายการ |
| `HumanMessage` | ข้อความของผู้ใช้ ทั้งรอบเก่าและคำถามใหม่ |
| `AIMessage` | คำตอบของโมเดลจากรอบก่อน |

`history` ใช้อาร์เรย์ว่าง `[]` ได้ เก็บข้อความเก่าเรียงตามเวลา `...history` กระจายสมาชิกให้เป็นข้อความแต่ละรายการในอาร์เรย์ เมื่อเรียก `llm.invoke(messages)` โมเดลจะได้รับข้อความที่อยู่ในอาร์เรย์ของการเรียกครั้งนั้น

## 3. ใช้คำถามเดิมแล้วเปลี่ยนประวัติ

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

ใน [playground](./playground.ts) ลองเก็บ `system` และ `question` เดิม แล้วใส่ `history` สองแบบคืออาร์เรย์เดิมและ `[]` เทียบว่ารายการใดมีข้อความ `ฉันชื่อมาลี ชอบแมว` ถ้าจะดูคำตอบจริง ให้ import `llm` ตาม [บท 1-03](../03-first-llm-call/README.md) และเรียก `await llm.invoke(messages)` กับทั้งสองรายการ ขั้นนี้ใช้ API key ใน `.env` และอินเทอร์เน็ต คำตอบเปลี่ยนได้ในแต่ละรอบ

ดู [เฉลย `history.ts`](./solution/history.ts) และรัน playground ด้วย `pnpm play 1-06` แล้วไป [บท 1-07 สร้างข้อความจากแม่แบบ](../07-prompt-templates/README.md)
