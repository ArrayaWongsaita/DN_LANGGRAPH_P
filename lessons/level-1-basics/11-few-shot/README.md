# บทที่ 11: few-shot (ตัวอย่างนำทาง)

## เรียนอะไร
few-shot คือการใส่ตัวอย่างถาม-ตอบไว้ก่อนคำถามจริง เพื่อให้ LLM ตอบตามรูปแบบเดียวกัน

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `fewShot.ts`
2. เปิด `fewShot.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/11-few-shot` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
