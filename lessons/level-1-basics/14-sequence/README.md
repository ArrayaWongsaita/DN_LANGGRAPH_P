# บทที่ 14: ต่อหลาย node เรียงกัน (sequence)

## แนวคิด
พลังจริงของ graph คือการ **ต่อหลายขั้นตอนเรียงกัน** โดยให้ผลของขั้นก่อนหน้าเป็นวัตถุดิบของขั้นถัดไป และตัวกลางที่ส่งต่อข้อมูลก็คือ **State** ที่คุณเรียนไปแล้ว:

```
topic ──► [writeDraft] ──► draft ──► [improve] ──► final
              เขียนร่าง                 ปรับปรุงร่าง
```
- node `writeDraft` อ่าน `topic` แล้วเขียน `draft`
- node `improve` อ่าน `draft` (ที่ขั้นแรกเขียนไว้) แล้วเขียน `final`
- ไม่ต้องส่งอะไรต่อกันเอง แค่เขียนลง state แล้วขั้นถัดไปอ่านจาก state

เทคนิคนี้เรียกว่า **prompt chaining**: แบ่งงานใหญ่เป็นขั้นเล็ก ๆ ให้ LLM ทำทีละขั้น มักได้ผลดีกว่าสั่งทีเดียวยาว ๆ

## ดูตัวอย่าง
เปิด `draftGraph.ts`: node `writeDraft` ให้มาแล้ว (ดูเป็นต้นแบบ) คุณต้องเขียน node `improve` และต่อ edge ให้ครบ

## โจทย์
เติมช่อง `// 👉 ข้อ N` (ตอนนี้เป็น `todo(N)`) ให้ครบ แล้วรัน:

    pnpm lesson 1-14

ถ้ายังเติมไม่ครบจะเห็น `ยังไม่ได้ทำข้อ N` บอกว่าช่องไหนค้างอยู่ เติมครบแล้วจะเห็นผลที่พิมพ์ออกมา และบรรทัด `✅` ทุกข้อ ถ้ามี `❌` ให้ดูคำใบ้ในวงเล็บท้ายบรรทัด

เปรียบเทียบร่างกับฉบับปรับปรุงที่พิมพ์ออกมา

## คุณทำได้แล้ว
- ต่อ node หลายตัวเรียงกันโดยส่งข้อมูลผ่าน State
- ใช้ผลของ LLM ขั้นหนึ่งเป็นข้อมูลเข้าของอีกขั้น

## ข้อควรจำ
- ขั้นถัดไปอ่านสิ่งที่ขั้นก่อนหน้าเขียนไว้ใน state
- ทุก node ที่เรียก LLM คือหนึ่งการเรียก (ใช้เวลาและโควตา)
- ลำดับ edge = ลำดับการทำงาน

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 1-14` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
