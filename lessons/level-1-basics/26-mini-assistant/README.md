# บทที่ 26: โปรเจกต์เล็ก: ผู้ช่วยตอบคำถาม

## เรียนอะไร
ประกอบทุกอย่างที่เรียนมาเป็นผู้ช่วยเล็ก ๆ: classify แยกคำถามสั้น/ยาว -> respond เรียก LLM พร้อม system prompt ตามประเภท -> format ต่อท้ายลายเซ็น แล้วรันคุยจริงในเทอร์มินัลได้

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว และรัน `npm run lesson 26` กับ LLM จริงแล้วเห็นผลลัพธ์

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `assistant.ts`
2. เปิด `assistant.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/26-mini-assistant` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
