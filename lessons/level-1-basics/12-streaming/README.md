# บทที่ 12: streaming

## เรียนอะไร
stream ทำให้ได้คำตอบทีละชิ้นขณะ LLM กำลังพิมพ์ (เหมือน ChatGPT) แทนที่จะรอจนจบ

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว และรัน `npm run lesson 12` กับ LLM จริงแล้วเห็นผลลัพธ์

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `streamText.ts`
2. เปิด `streamText.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/12-streaming` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
