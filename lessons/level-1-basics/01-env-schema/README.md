# บทที่ 1-01 ตรวจค่า `.env` ด้วย Zod

ตอนเรียก API ใน [บท 0-01](../../level-0-fetch/01-first-fetch/README.md) โปรแกรมอ่าน key จาก environment บทนี้ให้ Zod ตรวจและจัดรูปค่าตั้งต้นก่อนส่งให้บทที่สร้าง chat model

## 1. ลองอ่านชื่อโมเดลจาก `.env`

เปิด [`env.ts`](./env.ts) แล้วเติมข้อ 1 ให้ `envSchema.safeParse` ตรวจ `process.env` รันจากโฟลเดอร์หลักของโปรเจกต์ที่ติดตั้งแพ็กเกจด้วย `pnpm install` แล้ว ถ้ายังไม่มี `.env` ให้คัดลอกด้วย `cp .env.example .env` แล้วใส่ API key ของคุณในตัวแปรที่ตรงกับบริการที่เลือก ดูชื่อตัวแปรใน [`.env.example`](../../../.env.example) บทนี้อ่านค่าในเครื่องและยังไม่ส่งคำขอไปที่ API

```sh
pnpm lesson 1-01
```

`envSchema` ในไฟล์กำหนดช่องสำหรับชื่อโมเดลและ API key รูปแบบของแต่ละช่องคือ `z.string().trim().default("")`

```ts
const result = envSchema.safeParse(process.env);
```

ลองตั้ง `LLM_MODEL="  demo-model  "` เพื่อดูการตัดช่องว่าง ชื่อนี้ใช้ทดลองอ่านค่าในบทนี้ได้ ก่อนเรียก API ให้คืนชื่อโมเดลที่ใช้จริงหรือปล่อยค่าว่าง

```text
LLM_MODEL demo-model
✅ พบ API key อย่างน้อยหนึ่งตัว
✅ ตัดช่องว่างหัวท้ายของ LLM_MODEL แล้ว
```

## 2. ค่าที่ schema รับ

| ส่วนของโค้ด | ค่าที่รับและสิ่งที่เกิดขึ้น |
|---|---|
| `z.string()` | รับข้อความ โดย `process.env` ให้ค่าที่ตั้งไว้เป็นข้อความ |
| `.trim()` | ตัดช่องว่างหัวและท้าย เช่น `"  demo-model  "` กลายเป็น `"demo-model"` |
| `.default("")` | ให้ `""` เมื่อไม่มีตัวแปรนั้นใน environment |
| `z.object(...)` | ดึงช่องที่ประกาศใน schema และข้ามตัวแปรอื่น |
| `envSchema.safeParse(...)` | คืน `{ success: true, data }` เมื่อผ่าน หรือ `{ success: false, error }` เมื่อข้อมูลผิดรูปแบบ |

ไฟล์โหลด `.env` เข้า `process.env` ให้แล้ว ค่าที่กำหนดใน environment อยู่ก่อนมีผลก่อนค่าจากไฟล์ เมื่ออ่านผ่าน โปรแกรม `export` ค่า `env` ให้บทอื่นใช้ และพิมพ์เพียงสถานะว่าพบ key หรือไม่ เก็บ `.env` ไว้ในเครื่องและใช้ `.env.example` เมื่อต้องแชร์ชื่อของตัวแปร

## 3. เปลี่ยนค่าเดียวแล้วเทียบผล

เก็บ API key ไว้เหมือนเดิม ลองรันด้วย `LLM_MODEL="  demo-model  "` แล้วเปลี่ยนเป็น `LLM_MODEL=` รอบแรกพิมพ์ `LLM_MODEL demo-model` รอบหลังพิมพ์ `LLM_MODEL (ใช้โมเดลเริ่มต้น)` ถ้าไม่มี key ที่มีข้อความเลย โปรแกรมหยุดด้วย `ยังไม่ได้ตั้ง API key ใน .env` การพบ key หมายถึงพบข้อความหนึ่งค่า ส่วนการตรวจว่า key ใช้เรียกได้จะเกิดขึ้นในบท 1-03

ดู [เฉลย `env.ts`](./solution/env.ts) แล้วไป [บท 1-02 สร้าง chat model](../02-llm-config/README.md)
