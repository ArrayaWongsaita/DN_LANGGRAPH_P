# บทที่ 15: จัดการ error และ retry

## เรียนอะไร
การเรียก LLM อาจล้มชั่วคราว (เครือข่าย, 429) จึงลองใหม่ได้ แต่ error ที่ลองกี่ครั้งก็ไม่หาย (เช่น 401 key ผิด) ต้องไม่ลองซ้ำ

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `retry.ts`
2. เปิด `retry.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/15-error-handling-retry` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
