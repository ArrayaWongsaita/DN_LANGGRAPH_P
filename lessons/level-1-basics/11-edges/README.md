# บทที่ 11: edge, START และ END

## แนวคิด
node คือขั้นตอน ส่วน **edge** คือเส้นที่บอกว่า "ทำขั้นนี้เสร็จแล้วไปขั้นไหนต่อ" graph ต้องมีจุดเริ่มและจุดจบ LangGraph ให้ค่าพิเศษมาสองตัว:

- `START` จุดเริ่มต้นของ graph (ไม่ใช่ node จริง แค่ตัวบอกว่าเริ่มที่ไหน)
- `END` จุดจบ

```
START ──► first ──► second ──► END
```
เขียนเป็นโค้ดด้วย `graph.addEdge(จาก, ไป)`:

```ts
graph.addEdge(START, "first");
graph.addEdge("first", "second");
graph.addEdge("second", END);
```
หลังต่อเสร็จเรียก `.compile()` เพื่อให้ LangGraph ตรวจความถูกต้องของ graph และได้ตัวที่เรียก `.invoke(...)` ได้

**ถ้าต่อไม่ครบ** `compile()` จะ error เช่น `Node "second" is not reachable` แปลว่ามี node ที่ไม่มีเส้นเข้าถึง ให้ตรวจว่าทุก node มีเส้นเข้า และมีทางออกไปสู่ `END`

## ดูตัวอย่าง
เปิด `pipeline.ts`: node `first` กับ `second` ต่อชื่อตัวเองลงใน `trace` เพื่อให้เห็นลำดับการเดิน คุณต้องต่อเส้นเชื่อม 3 เส้น แล้วท้ายไฟล์จะรัน graph และพิมพ์เส้นทางที่เดินผ่าน

## โจทย์
เติมช่อง `// 👉 ข้อ N` (ตอนนี้เป็น `todo(N)`) ให้ครบ แล้วรัน:

    pnpm lesson 11

ถ้ายังเติมไม่ครบจะเห็น `ยังไม่ได้ทำข้อ N` บอกว่าช่องไหนค้างอยู่ เติมครบแล้วจะเห็นผลที่พิมพ์ออกมา และบรรทัด `✅` ทุกข้อ ถ้ามี `❌` ให้ดูคำใบ้ในวงเล็บท้ายบรรทัด

เติมครบแล้วลองสลับลำดับเส้นดูว่าผลเปลี่ยนอย่างไร (อย่าลืมเปลี่ยนกลับ) ไม่ใช้ LLM จึงไม่ต้องมี key

## คุณทำได้แล้ว
- ต่อ node เป็น graph ด้วย `addEdge`
- ใช้ `START` และ `END` ถูกที่
- อ่านข้อความ "not reachable" ออกว่าต่อเส้นไม่ครบ

## ข้อควรจำ
- ทุก graph ต้องเริ่มที่ `START` และจบที่ `END`
- ลำดับที่ต่อ edge คือลำดับที่ทำงานจริง
- `.compile()` ตรวจ graph ให้ ถ้าผิดจะ error ก่อนรันเสมอ
