# บทที่ 01: รันบทเรียนแรก

> ถ้าคุณผ่าน Level 0 มาแล้ว (บท 0-01 สอนวงจรแดง→เขียวและการอ่านผลที่แดงแบบสั้น ๆ) บทนี้เป็นการทบทวน ข้ามไปบท 02 ได้

## แนวคิด
คอร์สนี้สอนสร้างแอปที่ใช้ LLM ด้วย **LangGraph** แบบทีละก้าวเล็ก ๆ ทุกบทมีหน้าตาเหมือนกัน:

```
01-first-lesson/
  README.md        <- ไฟล์นี้ อธิบายแนวคิดของบท
  greet.ts         <- โค้ดของบท: มีช่องว่างให้คุณเติม (ค้นหา "👉 ข้อ")
  greet.test.ts    <- ตัวตรวจ: บอกว่าคุณเติมถูกไหม (ไม่ต้องแก้)
  solution/        <- เฉลย ดูเมื่อติดจริง ๆ เท่านั้น
```

คุณ **เขียนโค้ด** ในไฟล์ `greet.ts` ส่วน `greet.test.ts` เป็นแค่ "กรรมการ" ที่ตรวจงานให้ ตอนเริ่มบท กรรมการจะให้ **สีแดง** (ยังไม่ผ่าน) นี่คือเรื่องปกติ ไม่ใช่ว่าคุณทำผิด เป้าหมายคือเติมช่องไปเรื่อย ๆ จนกรรมการให้ **สีเขียว**

## ลองดูสีแดงก่อน
รันคำสั่งนี้ในเทอร์มินัล (ที่โฟลเดอร์โปรเจกต์):

    pnpm test:lesson 01

คุณจะเห็นผลประมาณนี้:

```
 × greet ต้องทักทายด้วยคำว่า สวัสดี ตามด้วยชื่อ
 FAIL  ... > greet ต้องทักทายด้วยคำว่า สวัสดี ตามด้วยชื่อ
Error: ยังไม่ได้ทำข้อ 1
 ❯ greet lessons/level-1-basics/01-first-lesson/greet.ts:7:10
```

## วิธีอ่านผลที่เป็นสีแดง
1. **บรรทัดที่ขึ้นต้นด้วย `×`** คือชื่อข้อที่ยังไม่ผ่าน (ชื่อบอกว่าโค้ดควรทำอะไร)
2. **บรรทัด `Error: ...`** คือสาเหตุ ตอนนี้ขึ้นว่า `ยังไม่ได้ทำข้อ 1` แปลว่าช่อง "👉 ข้อ 1" ยังว่างอยู่
3. **บรรทัด `❯ greet ...greet.ts:7:10`** คือตำแหน่งในไฟล์ของคุณ (ไฟล์ `greet.ts` บรรทัด 7) ให้เปิดไปดูตรงนั้น
4. ถ้าเติมแล้วยังแดง จะเห็น `expected ... received ...` แปลว่า "ควรได้ค่านี้ แต่โค้ดคุณคืนค่านั้น" ให้เทียบสองค่านี้

## โจทย์
เปิด `greet.ts` ตรงช่อง `// 👉 ข้อ 1` แล้วแทนที่ `return todo(1);` ด้วยโค้ดที่คืนข้อความ `สวัสดี ` ตามด้วยชื่อ

แนวทาง: ใช้ template string ที่ใช้เครื่องหมาย ` (backtick) และแทรกตัวแปรด้วย `${name}`

บันทึกไฟล์ แล้วรัน `pnpm test:lesson 01` อีกครั้ง ถ้าเป็นสีเขียวทั้งสองข้อ คุณผ่านบทนี้แล้ว

ถ้าติดจริง ๆ ค่อยเปิด `solution/greet.ts` ดู (แต่ลองเองก่อนนะ)

## คุณทำได้แล้ว
- รู้ว่าบทเรียนหนึ่งบทมีอะไรบ้าง และรันตัวตรวจของบทด้วย `pnpm test:lesson NN`
- อ่านผลสีแดงเป็น: รู้ว่าข้อไหนไม่ผ่าน เพราะอะไร และเปิดไฟล์ไหนบรรทัดไหน
- เติมช่องในโค้ดแล้วเปลี่ยนแดงเป็นเขียวได้

## ข้อควรจำ
- สีแดงตอนเริ่มบทเป็นเรื่องปกติ ไม่ใช่ความผิดของคุณ
- แก้ไฟล์ที่ไม่ใช่ `.test.ts` เท่านั้น (ตัวตรวจไม่ต้องแตะ)
- `solution/` มีไว้ดูตอนติดจริง ๆ ไม่ใช่ทางลัด
