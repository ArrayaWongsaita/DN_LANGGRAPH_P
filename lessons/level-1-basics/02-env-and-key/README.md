# บทที่ 02: ตั้งค่า API key ใน .env

## แนวคิด
เวลาเรียก LLM เราต้องบอกผู้ให้บริการว่า "ใครเป็นคนเรียก" ด้วย **API key** (เหมือนรหัสผ่านของแอปคุณ) ข้อควรระวัง: **ห้ามเขียน key ลงในโค้ด** เพราะถ้าเผลอเอาโค้ดขึ้น GitHub คนอื่นจะเอา key ไปใช้ได้ (และคุณต้องจ่ายเงินแทน)

วิธีมาตรฐานคือเก็บ key ไว้ในไฟล์ `.env` ซึ่งไม่ถูกอัปโหลด (เราตั้ง `.gitignore` ไว้แล้ว) แล้วให้โปรแกรมอ่านจาก **environment variable**:

```
.env  (ไฟล์ลับในเครื่องคุณ)         โปรแกรม
GROQ_API_KEY=gsk_xxxxx   ──────►   process.env.GROQ_API_KEY
```

ในคอร์สนี้ไฟล์ `src/llm.ts` ทำหน้าที่โหลด `.env` และเลือกว่าจะใช้ provider ไหน คุณจึงเปลี่ยนเจ้า LLM หรือโมเดลได้ที่ `.env` ที่เดียว (ตัวแปร `LLM_PROVIDER`, `LLM_MODEL`)

## ตั้งค่าก่อนเริ่ม (ทำครั้งเดียว)
1. คัดลอกไฟล์ตัวอย่าง: `cp .env.example .env`
2. สมัครบัญชี provider ที่ใช้ (ค่าเริ่มต้นของคอร์สคือ Groq) แล้วสร้าง API key ของคุณเอง
3. เปิด `.env` ใส่ key หลัง `GROQ_API_KEY=` (ไม่ต้องมีเครื่องหมายคำพูด ไม่ต้องมีช่องว่าง)

## ดูตัวอย่าง
เปิด `readKey.ts` มีสองฟังก์ชันเล็ก ๆ:
- `readKey(env, keyVar)` อ่านค่าตัวแปรจาก `env` (ในโปรแกรมจริงส่ง `process.env` เข้าไป) ถ้าไม่มีหรือว่างให้คืน `undefined`
- `maskKey(key)` ซ่อน key ก่อนพิมพ์ เพราะการพิมพ์ key เต็มลงจอเสี่ยงหลุดตอนแชร์หน้าจอ

## โจทย์
เติม 2 ช่อง `// 👉 ข้อ N` ใน `readKey.ts` แล้วรัน:

    pnpm test:lesson 02

เมื่อเขียวแล้วลองตรวจการตั้งค่าของคุณจริง (ยังไม่เรียก LLM):

    pnpm lesson 02

ถ้าขึ้นว่า `พบแล้ว (gsk_...)` แปลว่าพร้อมแล้ว ถ้าขึ้น `ยังไม่ได้ตั้ง` ให้กลับไปทำขั้น "ตั้งค่าก่อนเริ่ม"

## คุณทำได้แล้ว
- เก็บ API key ไว้ใน `.env` และรู้ว่าทำไมห้ามใส่ในโค้ด
- อ่านค่า environment variable และซ่อนค่าลับก่อนพิมพ์
- ตรวจได้ว่าเครื่องคุณตั้งค่า provider ครบแล้ว

## ข้อควรจำ
- `.env` ห้ามอัปโหลดขึ้น git และห้ามส่งให้ใคร
- key แต่ละคนใช้ของตัวเอง (มีโควตาและข้อจำกัดต่อบัญชี)
- เปลี่ยน provider/โมเดล = แก้ `.env` อย่างเดียว ไม่ต้องแก้บทเรียน
