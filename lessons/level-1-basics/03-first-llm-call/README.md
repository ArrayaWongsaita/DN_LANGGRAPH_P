# บทที่ 03: เรียก LLM ครั้งแรก

## เรียนอะไร
ส่งคำถามให้ LLM และรับคำตอบเป็นข้อความ ผ่าน `getLLM()` จาก `src/llm.ts` (จุดเดียวที่รู้ว่าใช้ provider ไหน)

## ผลลัพธ์ที่คาดหวัง
test เขียว (ใช้ LLM ปลอม ไม่ต้องมี key) และรัน `npm run lesson 03` แล้วได้คำตอบจริงจาก LLM

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ตัวอย่างของบท (ไฟล์ `.ts` ที่ไม่ใช่ `.test.ts`)
2. เปิดไฟล์ `.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/03-first-llm-call` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
