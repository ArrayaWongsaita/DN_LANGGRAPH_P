# บทที่ 1-03 ส่งคำถามแรกด้วย `llm.invoke()`

ขอให้โมเดลทักทายคนที่เพิ่งเริ่มเรียน LangGraph หนึ่งประโยค คราวนี้ใช้ `llm` จาก [บท 1-02](../02-llm-config/README.md) ส่งคำถามด้วย LangChain และอ่านคำตอบจากออบเจ็กต์ที่ได้

## 1. ส่งคำถามแล้วอ่าน `.text`

เปิด [`firstCall.ts`](./firstCall.ts) แล้วเติมข้อ 1 ให้ `llm.invoke` รับ `question` และรอคำตอบด้วย `await` รันจากโฟลเดอร์หลักของโปรเจกต์หลังทำบท 1-02 เสร็จ บทนี้ต้องมี API key ที่ใช้ได้และเชื่อมต่ออินเทอร์เน็ต

```sh
pnpm lesson 1-03
```

ไฟล์ import `llm` ให้แล้ว ส่วนที่ส่งคำถามและแสดงคำตอบมีดังนี้

```ts
const question = "ทักทายคนที่เพิ่งเริ่มเรียน LangGraph หนึ่งประโยค";
const reply = await llm.invoke(question);
console.log("คำตอบ", reply.text);
```

ตัวอย่างผลลัพธ์ ประโยคในบรรทัดคำตอบเปลี่ยนได้ตามโมเดลและรอบที่เรียก

```text
คำถาม ทักทายคนที่เพิ่งเริ่มเรียน LangGraph หนึ่งประโยค
คำตอบ สวัสดีและยินดีต้อนรับสู่การเรียนรู้ LangGraph!
✅ ได้ข้อความจาก chat model
✅ อ่านคำตอบด้วย reply.text
```

## 2. ค่าที่ส่งและผลที่ได้

`question` เป็น `string` ที่ใส่เนื้อหาและคำสั่งในข้อความเดียวได้ `invoke` ต้องรับข้อมูลเข้าหนึ่งค่า บทนี้ส่งข้อความเดียว ส่วนอาร์เรย์ของข้อความหลายบทบาทจะใช้ใน [บท 1-06](../06-system-and-history/README.md) เมื่อ `await` เสร็จจะได้ `AIMessage` และอ่านส่วนที่เป็นข้อความล้วนด้วย `reply.text`

## 3. เปลี่ยนภาษาคำทักทาย

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

ลองส่งคำถามเดิมสองรอบ โดยเติม `ตอบเป็นภาษาไทย` ในรอบแรกและ `ตอบเป็นภาษาอังกฤษ` ในรอบหลัง เทียบข้อความจาก `reply.text` เช่น `สวัสดี ยินดีต้อนรับสู่ LangGraph!` กับ `Welcome to LangGraph!` โมเดลเลือกประโยคเอง จึงพิจารณาภาษาและความยาวควบคู่กับเนื้อหา

ดู [เฉลย `firstCall.ts`](./solution/firstCall.ts) หรือลองคำถามอื่นใน [playground](./playground.ts) ด้วย `pnpm play 1-03` แล้วไป [บท 1-04 เปรียบเทียบ `temperature`](../04-temperature/README.md)
