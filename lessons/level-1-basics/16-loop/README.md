# บทที่ 16: loop (วนซ้ำจนกว่าจะพอ)

## แนวคิด
บางงานทำครั้งเดียวไม่จบ เช่น "ปรับปรุงงานไปเรื่อย ๆ จนดีพอ" ใน graph เราทำ **loop** ได้ด้วย conditional edge ที่ชี้ **กลับไปที่ node เดิม**:

```
START ──► refine ──?──► END
             ▲      │
             └──────┘   (ถ้ายังไม่ดีพอ วนกลับ)
```
router (ที่เรียนในบท conditional edge: ฟังก์ชันที่คืนชื่อ node ถัดไป) ครั้งนี้เลือกระหว่าง "วนกลับ" กับ "จบ"

**กฎเหล็กของ loop: ต้องมีเงื่อนไขหยุดเสมอ** และควรมีสองชั้น:
1. หยุดเมื่อ **ได้ผลที่ต้องการ** (ที่นี่: LLM ตอบ `OK`)
2. หยุดเมื่อ **ครบจำนวนรอบสูงสุด** (กัน LLM ไม่เคยตอบ OK แล้ววนไม่จบ เสียเงินเปล่า)

ถ้าไม่มีชั้นที่ 2 และ LLM ดื้อ graph จะวนจนชน limit ของ LangGraph (เราจะเจอในบทที่ 18)

## ดูตัวอย่าง
เปิด `refineLoop.ts`: node `refine` เรียก LLM แล้วเพิ่ม `rounds` ทีละ 1 ให้มาแล้ว สิ่งที่ต้องเขียนคือ router `shouldContinue` และการต่อ edge ก่อนรัน graph ไฟล์จะตรวจ router ให้ก่อน (ยังไม่เรียก LLM)

## โจทย์
เติมช่อง `// 👉 ข้อ N` (ตอนนี้เป็น `todo(N)`) ให้ครบ แล้วรัน:

    pnpm lesson 16

ถ้ายังเติมไม่ครบจะเห็น `ยังไม่ได้ทำข้อ N` บอกว่าช่องไหนค้างอยู่ เติมครบแล้วจะเห็นผลที่พิมพ์ออกมา และบรรทัด `✅` ทุกข้อ ถ้ามี `❌` ให้ดูคำใบ้ในวงเล็บท้ายบรรทัด

ดูว่า LLM ใช้กี่รอบจึงตอบ OK

## คุณทำได้แล้ว
- สร้าง loop ใน graph ด้วย conditional edge ที่วนกลับ node เดิม
- ออกแบบเงื่อนไขหยุดสองชั้น: ได้ผล และ ครบรอบ

## ข้อควรจำ
- loop ทุกอันต้องมีทางออก และควรมี "จำนวนรอบสูงสุด" เป็นตาข่ายนิรภัย
- เก็บตัวนับ (`rounds`) ไว้ใน State
- router เป็นฟังก์ชันธรรมดา ทดสอบแยกได้ง่าย
