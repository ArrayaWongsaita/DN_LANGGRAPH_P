# บทที่ 1-08 อ่านคำตอบทีละชิ้นด้วย `stream()`

สมมติว่าแชตเริ่มตอบว่า “ไปเที่ยว ” แล้วจึงเติม “เชียงใหม่กัน” [บท 1-03](../03-first-llm-call/README.md) ใช้ `invoke` เพื่อรอคำตอบครบ บทนี้ใช้ `stream` เพื่ออ่านและแสดงชิ้นที่ได้รับทันที

## 1. เปิด stream แล้วอ่านสองชิ้น

เปิด [`streaming.ts`](./streaming.ts) แล้วเติมข้อ 1 ให้ `model.stream` รับ `question` และรอ stream ด้วย `await` รันจากโฟลเดอร์หลักของโปรเจกต์ ตัวอย่างใช้ `FakeStreamingChatModel` ใน LangChain ที่ตั้งชิ้นข้อความไว้แล้ว จึงใช้ได้โดยไม่ต้องมี API key

```sh
pnpm lesson 1-08
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

`model` กับ `question` อยู่ในไฟล์แล้ว ส่วนที่เปิด stream และพิมพ์ข้อความทีละชิ้นมีดังนี้

```ts
const stream = await model.stream(question);
for await (const chunk of stream) {
  process.stdout.write(chunk.text);
}
```

ผลที่เห็นจากโมเดลจำลอง สคริปต์แสดงแต่ละ `chunk.text` ต่อกันบนบรรทัดเดียว และพิมพ์อาร์เรย์แยกให้เห็นขอบเขตของชิ้น

```text
ไปเที่ยว เชียงใหม่กัน
ชิ้นข้อความ [ 'ไปเที่ยว ', 'เชียงใหม่กัน' ]
✅ อ่านสองชิ้นตามลำดับ
```

## 2. ส่วนที่ส่งเข้าและอ่านกลับ

- `stream(question)` รับข้อความ `string` แบบเดียวกับตัวอย่าง `invoke` หรืออาร์เรย์ข้อความจาก [บท 1-06](../06-system-and-history/README.md) แล้วคืน stream ที่อ่านด้วย `for await...of`
- `chunk.text` เป็นข้อความในชิ้นนั้น โมเดลจริงอาจส่งชิ้นที่มีข้อความว่างหรือแบ่งคำที่ตำแหน่งต่างกัน
- `process.stdout.write` พิมพ์ต่อบนบรรทัดเดิม โปรแกรมจึงขึ้นบรรทัดใหม่หลังอ่าน stream จบด้วย `process.stdout.write("\n")`

## 3. เปลี่ยนจุดแบ่งแล้วเทียบผล

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

ใน [playground](./playground.ts) คงคำถามและข้อความเต็มเดิมไว้ ลองส่ง `"ไปเที่ยว เชียงใหม่กัน"` เป็น `AIMessageChunk` ชิ้นเดียว บรรทัดคำตอบเหมือนเดิม แต่อาร์เรย์เหลือ `[ 'ไปเที่ยว เชียงใหม่กัน' ]` เทียบกับสองชิ้นในตัวอย่างแรก ถ้าจะลองคำตอบจริง ใช้ `llm` ที่ตั้งใน [บท 1-02](../02-llm-config/README.md) เป็น `model` และเตรียม API key กับอินเทอร์เน็ต
