# บทที่ 01: test แรก

## เรียนอะไร
เขียน test ง่าย ๆ ด้วย `test`, `expect`, `toBe`

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ตัวอย่างของบท (ไฟล์ `.ts` ที่ไม่ใช่ `.test.ts`)
2. เปิดไฟล์ `.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/01-first-test` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
