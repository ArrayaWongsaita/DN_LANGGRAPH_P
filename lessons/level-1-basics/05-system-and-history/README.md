# บทที่ 05: system prompt และประวัติการคุย

## แนวคิด
ถ้าคุณถาม LLM ว่า "ฉันชื่ออะไร" ทั้งที่เพิ่งบอกชื่อไปเมื่อกี้ มันจะตอบไม่ได้ เพราะ **LLM ไม่มีความจำ** ทุกครั้งที่เรียก `invoke` คือการเริ่มใหม่หมด สิ่งที่ดูเหมือน "ความจำ" ในแชตบอทจริง ๆ คือการ **ส่งบทสนทนาทั้งหมดไปให้ใหม่ทุกครั้ง**

```
[ SystemMessage  "ตอบสั้น ๆ"          ]  ← คำสั่งตั้งต้น กำหนดบทบาท/สไตล์
[ HumanMessage   "ฉันชื่อมาลี"        ]  ┐
[ AIMessage      "ยินดีที่รู้จัก"      ]  ┘ ประวัติ (history)
[ HumanMessage   "ฉันชื่ออะไร"        ]  ← คำถามใหม่
         │
         ▼  llm.invoke([...ทั้งหมดนี้])
```

- **system message** คือคำสั่งที่บอก LLM ว่าให้ทำตัวอย่างไร ต้องอยู่ต้นรายการ
- **ลำดับสำคัญมาก** LLM อ่านจากบนลงล่าง

บทต่อ ๆ ไป (Level 2) เราจะให้ LangGraph เก็บและส่งประวัติให้อัตโนมัติ แต่ตอนนี้ลองทำเองครั้งเดียวเพื่อให้เห็นกลไกจริง

## ดูตัวอย่าง
`askWithHistory.ts` รับคำสั่งตั้งต้น ประวัติ (array ของ message) และคำถามใหม่ ต้องประกอบเป็นรายการเดียวตามลำดับที่ถูกต้อง แล้วส่งให้ LLM

## โจทย์
เติม 2 ช่องแล้วรัน:

    pnpm test:lesson 05

แล้วลอง `pnpm lesson 05` เทียบคำตอบ "มีประวัติ" กับ "ไม่มีประวัติ" ว่าต่างกันอย่างไร

## คุณทำได้แล้ว
- ใช้ `SystemMessage` กำหนดบทบาทให้ LLM
- ส่งประวัติการคุยไปให้ LLM เพื่อให้มัน "จำ" ได้
- รู้ว่าความจำของแชตบอทคือการส่งข้อความเก่าไปด้วยทุกครั้ง

## ข้อควรจำ
- LLM ไม่มีความจำในตัว
- ลำดับ: system → ประวัติ → คำถามใหม่
- ประวัติยาวขึ้น = ใช้ token และเงินมากขึ้น (เราจะจัดการในบทหลัง ๆ)
