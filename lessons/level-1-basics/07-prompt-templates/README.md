# บทที่ 1-07 สร้างข้อความด้วย `ChatPromptTemplate`

ถ้าจะขอแปลประโยคเดิมเป็นหลายภาษา คำสั่งเกือบทั้งหมดใช้ซ้ำได้ จากชุดข้อความ `system` และ `human` ใน [บท 1-06](../06-system-and-history/README.md) บทนี้ทำให้ส่วนที่เปลี่ยนได้เป็นช่อง `{language}` และ `{text}`

## 1. เติมค่าลงในแม่แบบ

เปิด [`translate.ts`](./translate.ts) แล้วเติมข้อ 1 ให้ `prompt.formatMessages` รับ `input` และรอผลด้วย `await` รันจากโฟลเดอร์หลักของโปรเจกต์ การประกอบข้อความทำในเครื่องและใช้ได้โดยไม่ต้องมี API key

```sh
pnpm lesson 1-07
```

```ts
const prompt = ChatPromptTemplate.fromMessages([
  ["system", "แปลข้อความของผู้ใช้เป็นภาษา{language}"],
  ["human", "{text}"],
]);
const input = { language: "อังกฤษ", text: "วันนี้อากาศดีจัง" };
const messages = await prompt.formatMessages(input);
```

เมื่อรันจะเห็นข้อความที่พร้อมส่งให้โมเดล ค่าของ `language` ไปอยู่ในคำสั่งระบบ ค่าของ `text` ไปอยู่ในข้อความผู้ใช้

```text
system แปลข้อความของผู้ใช้เป็นภาษาอังกฤษ
human วันนี้อากาศดีจัง
✅ เติม language ในข้อความ system
✅ เติม text ในข้อความ human
```

## 2. แม่แบบรับค่าอะไร

แต่ละคู่ใน `fromMessages` ประกอบด้วยบทบาท เช่น `"system"`, `"human"` หรือ `"ai"` และข้อความแม่แบบ `formatMessages(input)` รับออบเจ็กต์ที่มีค่าครบทุกชื่อในปีกกา บทนี้ใช้ `language` กับ `text` เป็นข้อความทั้งคู่และไม่มีค่าเริ่มต้น ถ้าลืมส่งช่องใด การประกอบข้อความจะหยุดและแจ้งชื่อช่องที่ขาด

## 3. ใช้แม่แบบเดิมแล้วเปลี่ยนภาษา

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

เก็บ `text` เป็น `"วันนี้อากาศดีจัง"` เปลี่ยน `language` จาก `"อังกฤษ"` เป็น `"ญี่ปุ่น"` ผลจาก `system` จะเปลี่ยนจาก `แปลข้อความของผู้ใช้เป็นภาษาอังกฤษ` เป็น `แปลข้อความของผู้ใช้เป็นภาษาญี่ปุ่น` ส่วนข้อความ `human` ยังเป็นประโยคเดิม ถ้าต้องการคำแปลจริง ให้ส่ง `messages` เข้า `await llm.invoke(messages)` ด้วย `llm` จาก [บท 1-02](../02-llm-config/README.md) ขั้นนี้ต้องมี API key และอินเทอร์เน็ต หรือจะใช้ `await prompt.pipe(llm).invoke(input)` เพื่อประกอบแม่แบบแล้วส่งให้โมเดลในคำสั่งเดียวก็ได้
