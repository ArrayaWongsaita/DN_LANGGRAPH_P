# บทที่ 07: prompt template (แม่แบบข้อความ)

## แนวคิด
บทที่แล้วเราประกอบข้อความด้วยมือ ถ้าต้องต่อสตริงหลายที่จะรกและพลาดง่าย LangChain มีเครื่องมือมาตรฐานชื่อ **`ChatPromptTemplate`**: เขียนแม่แบบครั้งเดียว เว้นช่องไว้ด้วย `{ชื่อช่อง}` แล้วเติมค่าตอนใช้

```ts
const prompt = ChatPromptTemplate.fromMessages([
  ["system", "แปลเป็นภาษา{language}"],
  ["human", "{text}"],
]);
//                        เติมค่า
// prompt.invoke({ language: "อังกฤษ", text: "สวัสดี" })  ──►  [SystemMessage, HumanMessage]
```

ของอีกอย่างที่ LangChain ให้มาคือ **`.pipe(...)`** ใช้ต่อสิ่งที่ทำงานต่อกันได้ให้เป็นสายเดียว (เรียกว่า chain):

```
{language, text} ──► prompt ──► llm ──► AIMessage
                  prompt.pipe(llm)
```
ทุกอย่างที่ต่อด้วย `.pipe` ใช้ `.invoke(...)` ได้เหมือนกัน หลักการนี้ (สิ่งที่ invoke ได้ต่อกันได้) คือแนวคิดเดียวกับที่ LangGraph ใช้ต่อไป

## ดูตัวอย่าง
เปิด `translate.ts`: ข้อ 1 สร้างแม่แบบ (`prompt`) ข้อ 2 เอาแม่แบบไปต่อกับ `llm` เป็น chain แล้วเรียกด้วยค่าของช่อง ท้ายไฟล์ใช้แม่แบบเดียวกันแปลเป็นภาษาญี่ปุ่นอีกรอบให้ดูว่าใช้ซ้ำได้

## โจทย์
เติมช่อง `// 👉 ข้อ N` (ตอนนี้เป็น `todo(N)`) ให้ครบ แล้วรัน:

    pnpm lesson 1-07

ถ้ายังเติมไม่ครบจะเห็น `ยังไม่ได้ทำข้อ N` บอกว่าช่องไหนค้างอยู่ เติมครบแล้วจะเห็นผลที่พิมพ์ออกมา และบรรทัด `✅` ทุกข้อ ถ้ามี `❌` ให้ดูคำใบ้ในวงเล็บท้ายบรรทัด

ข้อ 1 ให้แทน `todo(1)` ด้วย `ChatPromptTemplate.fromMessages([...])` ลองเปลี่ยนภาษาปลายทางหรือข้อความดูได้เลย

## เทียบกับตอนใช้ fetch
ตอน `fetch` เราต่อสตริงเอง (`` `แปลเป็น${language}: ${text}` ``) ซึ่งพลาดง่ายเมื่อข้อความยาวขึ้น (ลืมช่อง สะกดชื่อตัวแปรผิด) `ChatPromptTemplate` ตรวจให้ว่าส่งค่าครบทุกช่อง และต่อกับ LLM ด้วย `.pipe` ได้ทันที

## คุณทำได้แล้ว
- สร้างแม่แบบข้อความที่เติมค่าได้ด้วย `ChatPromptTemplate`
- ต่อแม่แบบเข้ากับ LLM ด้วย `.pipe`
- ใช้แม่แบบเดียวซ้ำกับข้อมูลหลายชุด

## ข้อควรจำ
- ช่องในแม่แบบเขียนเป็น `{ชื่อ}` และต้องส่งค่าครบทุกช่องตอน invoke
- `prompt.pipe(llm)` คือสายที่เรียกด้วยค่าของช่อง
- ชื่อช่องต้องตรงกับ key ของ object ที่ส่งเข้า invoke

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 1-07` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
