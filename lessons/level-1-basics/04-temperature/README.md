# บทที่ 04: temperature (ปรับความสุ่มของคำตอบ)

## แนวคิด
ถามคำถามเดิมซ้ำ ๆ LLM ไม่จำเป็นต้องตอบเหมือนเดิมทุกครั้ง เพราะมันเลือกคำถัดไปจากความน่าจะเป็น ปุ่มที่คุมความสุ่มตรงนี้เรียกว่า **temperature**:

```
temperature ต่ำ (0)      ──►  เลือกคำที่น่าจะเป็นที่สุดเสมอ  ──►  นิ่ง คาดเดาได้
temperature สูง (1–2)    ──►  เปิดโอกาสให้คำที่น่าจะเป็นรอง ๆ ──►  หลากหลาย สร้างสรรค์
```

| งาน | ควรใช้ |
|---|---|
| ดึงข้อมูล, จัดประเภท, แปล, ตอบจากเอกสาร (บท 07, 09, 20) | ต่ำ (0 ถึง 0.3) |
| เขียนเรื่อง, ตั้งชื่อ, ระดมความคิด | สูง (0.8 ขึ้นไป) |

temperature ตั้ง **ตอนสร้าง chat model** (คนละเรื่องกับ `llm.invoke(...)` ที่ส่งคำถาม) เราจึงต้องสร้าง model ใหม่เมื่ออยากได้ค่าใหม่ บทนี้เลยสร้าง model ของตัวเองในไฟล์ แทนที่จะใช้ `llm` จากบท 02 (ส่วนบทอื่นยังใช้ `llm` ตัวเดียวเพื่อให้โค้ดเรียบง่าย)

> **กล่องเล็ก: อย่าคาดหวังว่า 0 = ซ้ำกันเป๊ะ**
> ค่าต่ำช่วยให้นิ่งขึ้น แต่ไม่รับประกันว่าตอบเหมือนเดิมทุกตัวอักษร บางโมเดลหรือบางเจ้า (เช่น โมเดลที่ "คิด" ก่อนตอบ) ยังตอบต่างกันได้แม้ตั้ง 0 และช่วงค่าที่ใช้ได้ต่างกันตามเจ้า (ส่วนใหญ่ 0 ถึง 2) บทนี้จึงให้ดูจากผลที่พิมพ์ออกมา ไม่ได้ตัดสินว่าผ่านจากความซ้ำ

## ดูตัวอย่าง
เปิด `temperature.ts`: ลูปนอกวนค่า temperature สองค่า (0 กับ 1.5) แต่ละรอบสร้าง model ใหม่ (ข้อ 1) แล้วถามคำถามเดิม 3 ครั้ง (ข้อ 2) ตอนท้ายพิมพ์จำนวนคำตอบที่ไม่ซ้ำกันของแต่ละค่า

ไฟล์ตัวอย่างใช้ Groq ถ้าคุณเลือกเจ้าอื่นในบท 02 ให้เปลี่ยน `import` กับบรรทัด `new ...` ตามบล็อกของเจ้านั้น (ทุกเจ้ารับ `temperature` ตอนสร้างเหมือนกัน)

## โจทย์
เติม 2 ช่อง (`todo(1)`, `todo(2)`) ใน `temperature.ts` แล้วรัน:

    pnpm lesson 1-04

ถ้ายังเติมไม่ครบจะเห็น `ยังไม่ได้ทำข้อ N` เติมครบแล้วจะเห็นคำตอบ 3 ครั้งของแต่ละค่า และบรรทัด `✅` ทุกข้อ ลองรันซ้ำสองสามรอบ แล้วลองเปลี่ยนค่า (เช่น 0.7) หรือคำถามดู (ทุกรอบใช้ 6 คำขอ ถ้าใช้ Google ที่จำกัดต่อนาทีอย่ารันรัว ๆ)

## คุณทำได้แล้ว
- รู้ว่า temperature คุมความสุ่มของคำตอบ และตั้งตอนสร้าง model
- เลือกค่าให้เหมาะกับงาน (นิ่งสำหรับดึงข้อมูล หลากหลายสำหรับงานสร้างสรรค์)
- รู้ว่าค่าต่ำไม่ได้การันตีว่าตอบซ้ำเป๊ะ

## ข้อควรจำ
- temperature อยู่ที่ตัวสร้าง model ไม่ใช่ที่ตอนเรียก `invoke`
- งานที่ต้องการผลซ้ำได้ (ดึงข้อมูล จัดประเภท) ใช้ค่าต่ำ
- ถ้าเปลี่ยนเจ้า LLM ช่วงค่าที่แนะนำอาจต่างกัน ดูเอกสารของเจ้านั้น

## ลองเล่นต่อ
อยากทดลองเองโดยไม่มีส่วนตรวจคำตอบ: `pnpm play 1-04` จะรันไฟล์ `playground.ts` ในโฟลเดอร์บทนี้ (สร้างให้แล้ว มีแต่ import ที่ใช้ เขียนโค้ดต่อเองได้เลย) ในหัวไฟล์มีไอเดียให้ลองทำ ใช้ `--watch` ให้รันซ้ำทุกครั้งที่บันทึก และ `--reset` เพื่อเริ่มใหม่
