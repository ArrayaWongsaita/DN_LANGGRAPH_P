# บทที่ 09: structured output (ให้ LLM ตอบเป็นข้อมูลที่โปรแกรมใช้ต่อได้)

## แนวคิด
โดยปกติ LLM ตอบเป็น **ข้อความอิสระ** เช่น "คุณสมชายอายุ 42 ปีค่ะ" คนอ่านเข้าใจ แต่โปรแกรมเอาไปใช้ต่อยาก (ต้องมานั่งตัดคำเอง และพังง่ายถ้า LLM เปลี่ยนวิธีพูด)

ถ้าเราอยากได้ข้อมูลเป็นโครงสร้าง เช่น `{ name: "สมชาย", age: 42 }` เราใช้ **structured output**: บอก LLM ว่า "ตอบตามรูปร่างนี้" แล้วได้ object กลับมาตรง ๆ

```
ข้อความ ──► LLM (ตอบตามรูปร่างที่กำหนด) ──► { name, age }
```

### รูปร่างข้อมูลบอกด้วย zod
`zod` คือไลบรารีที่ใช้อธิบายรูปร่างข้อมูล (เจอกันมาแล้วในบทที่ 02):

```ts
const personSchema = z.object({ name: z.string(), age: z.number() });
// อ่านว่า: object ที่มี name เป็นข้อความ และ age เป็นตัวเลข
```
สิ่งที่ LangChain ให้เราใช้: `llm.withStructuredOutput(schema, { method: "functionCalling" })` คืน "ตัวเรียกตัวใหม่" ที่หน้าตาเหมือน LLM เดิม (เรียกด้วย `.invoke(...)` ได้เหมือนกัน) แต่ผลลัพธ์เป็น object ตาม schema แทนข้อความ

## ดูตัวอย่าง
เปิด `structuredOutput.ts` จะเห็นว่า:
- `personSchema` กำหนดรูปร่างที่เราอยากได้ (ให้มาแล้ว)
- ข้อ 1 ทำให้ `llm` ตอบเป็นโครงสร้างตาม schema ข้อ 2 เรียกด้วยข้อความต้นฉบับแล้วได้ `{ name, age }` กลับมา
- `async/await`: การเรียก LLM ใช้เวลา จึงเป็นงาน "รอผล" เราใส่ `await` เพื่อรอผลก่อนใช้

## โจทย์
เติมช่อง `// 👉 ข้อ N` (ตอนนี้เป็น `todo(N)`) ให้ครบ แล้วรัน:

    pnpm lesson 1-09

ถ้ายังเติมไม่ครบจะเห็น `ยังไม่ได้ทำข้อ N` บอกว่าช่องไหนค้างอยู่ เติมครบแล้วจะเห็นผลที่พิมพ์ออกมา และบรรทัด `✅` ทุกข้อ ถ้ามี `❌` ให้ดูคำใบ้ในวงเล็บท้ายบรรทัด

## เทียบกับตอนใช้ fetch (บท 0-04)
ใน 0-04 คุณต้องขอ JSON ในคำสั่ง ลอกรั้วโค้ด `JSON.parse` และตรวจด้วย zod เอง 3 ขั้น ตอนนี้ `.withStructuredOutput(personSchema)` ทำให้ทั้งหมดในบรรทัดเดียว (และใช้กลไกที่เหมาะกับโมเดลแต่ละตัวให้ เช่น tool calling) แต่หลักการยังเหมือนเดิม: ข้อมูลจาก LLM ควรผ่าน schema เสมอ

## คุณทำได้แล้ว
- ทำให้ LLM ตอบเป็น object ที่มีรูปร่างตามที่กำหนดด้วย `withStructuredOutput`
- อ่าน schema ของ zod ออกว่าข้อมูลควรหน้าตาแบบไหน

## ข้อควรจำ
- `withStructuredOutput(schema, ...)` คืนตัวเรียกใหม่ ไม่ได้แก้ LLM เดิม
- `{ method: "functionCalling" }` บอกให้ใช้ tool calling ซึ่งทุกเจ้าในบท 02 รองรับ (บางเจ้า เช่น DeepSeek ไม่รับวิธีเริ่มต้นแบบ JSON schema)
- ผลลัพธ์เป็น object ที่ใช้ `.name` `.age` ได้เลย ไม่ต้อง parse เอง
- ไม่ใช่ทุกโมเดลรองรับ structured output เท่ากัน ถ้าเปลี่ยนโมเดลแล้วพัง ลองรัน `pnpm check:llm`

## บทถัดไป
ต่อไปเราจะหยุดคุยกับ LLM ทีละครั้ง และเริ่มต่อขั้นตอนหลายขั้นเข้าด้วยกันเป็น graph
