# บทที่ 23: reducer (กติกาการรวมค่า)

## เรียนอะไร
reducer บอกว่าเมื่อมีค่าใหม่เขียนเข้า field เดิม ให้รวมกันยังไง (เช่น ต่อท้าย array, บวกเลข) ถ้าไม่มี reducer ค่าใหม่จะทับค่าเก่า และถ้า node ขนานกันเขียน field ที่ไม่มี reducer พร้อมกันจะ error

## ผลลัพธ์ที่คาดหวัง
ทั้ง 3 ข้อขึ้นสีเขียว

## วิธีทำ
1. อ่านตัวอย่างในไฟล์ `reducers.ts`
2. เปิด `reducers.test.ts` แล้วเปลี่ยน `test.todo` เป็น `test` ทีละข้อ
3. รัน `npm test -- lessons/level-1-basics/23-reducers` ถ้าติดจริง ๆ ค่อยดูโฟลเดอร์ `solution/`
