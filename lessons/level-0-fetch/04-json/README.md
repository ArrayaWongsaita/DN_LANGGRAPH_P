# บทที่ 0-04 ตรวจข้อมูล JSON ที่โมเดลตอบ

สมมติว่าแอปให้โมเดลดึงชื่อกับอายุจากข้อความ แล้วนำอายุไปคำนวณต่อ เราอ่านคำตอบจาก `choices[0].message.content` ตาม [บท 0-01](../01-first-fetch/README.md) ข้อความอย่าง `{"name":"มาลี","age":"42"}` อ่านเป็น JSON ได้ แต่อายุที่ได้ยังเป็นสตริง บทนี้ใช้ Zod ตรวจชนิดก่อนนำข้อมูลไปใช้

## 1. ตรวจคำตอบหลังอ่าน JSON

เปิด [`parsePerson.ts`](./parsePerson.ts) แล้วเติมข้อ 1 ให้ใช้ `personSchema` ตรวจ `data` และคืนข้อมูลที่ตรวจผ่าน รันจากโฟลเดอร์หลักของโปรเจกต์ บทนี้ใช้ `Response` ตัวอย่างที่มีรูปร่างเดียวกับคำตอบจาก `fetch` จึงรันได้โดยไม่ต้องมี API key

```sh
pnpm lesson 0-04
```

ในไฟล์ `parsePerson(raw)` ตัดช่องว่างและลอกรั้วโค้ดที่ครอบคำตอบไว้ก่อน จากนั้นใช้ `JSON.parse` อ่านข้อมูล ส่วนที่ตรวจชนิดย่อเหลือบรรทัดเดียว

```ts
const personSchema = z.object({ name: z.string(), age: z.number() });
const data: unknown = JSON.parse('{"name":"มาลี","age":42}');
const person = personSchema.parse(data);
```

## 2. ดูว่าแต่ละคำตอบผ่านหรือพลาดตรงไหน

```text
[JSON ตรง ๆ] {"name":"มาลี","age":42}
[JSON ในรั้วโค้ด] {"name":"มาลี","age":42}
[อายุเป็นข้อความ] ข้อมูลไม่ตรงกับ schema ที่ฟิลด์ age
[ข้อความธรรมดา] อ่านคำตอบเป็น JSON ไม่ได้
✅ อ่าน JSON ได้ทั้งแบบตรง ๆ และแบบมีรั้ว
✅ จับชนิดข้อมูลที่ผิดตรงฟิลด์ age
✅ แยกข้อความที่อ่านเป็น JSON ไม่ได้
```

`JSON.parse` ตรวจไวยากรณ์ JSON ก่อน ส่วน `personSchema.parse` ตรวจว่าค่าที่อ่านมาเป็นออบเจ็กต์ที่มีฟิลด์ตามแบบที่ต้องการ

## 3. ค่าที่ schema รับ

| ส่วน | ค่าที่รับ | ตัวอย่าง |
|---|---|---|
| ข้อความดิบ | สตริง JSON ตรง ๆ หรือสตริง JSON ที่ห่อด้วยรั้วสามแบ็กทิกแบบมีหรือไม่มีคำว่า `json` | ไฟล์ลอกรั้วเมื่อครอบคำตอบทั้งก้อน |
| `name` | สตริง | `"มาลี"` |
| `age` | ตัวเลข JSON | `42` ผ่าน ส่วน `"42"` และ `null` ทำให้เกิด `ZodError` |

`name` และ `age` ต้องมีทั้งคู่ `z.number()` ในตัวอย่างนี้ตรวจชนิดตัวเลข จึงยังรับทศนิยมและค่าติดลบได้ หากงานต้องใช้จำนวนเต็มที่ไม่ติดลบ ให้ลองเพิ่ม `.int().nonnegative()`

## 4. เปลี่ยนเฉพาะค่าของ `age`

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

เก็บ `name` และรูปแบบ JSON เดิม แล้วเปลี่ยนค่าที่ส่งให้ `parsePerson`

| ค่า `age` ใน JSON | ผลที่ได้ |
|---|---|
| `42` | ได้ `{"name":"มาลี","age":42}` |
| `"42"` | ได้ `ZodError` ที่ฟิลด์ `age` |
| ละฟิลด์ `age` | ได้ `ZodError` ที่ฟิลด์ `age` |

ลองเปลี่ยนค่าหรือเพิ่มข้อกำหนดของอายุใน [`playground.ts`](./playground.ts) ด้วย `pnpm play 0-04` ถ้าอยากทดลองกับโมเดลจริง ให้นำคำขอจากบท 0-01 มาใช้ ขอให้ตอบเป็น JSON ที่มี `name` และ `age` แล้วส่ง `message.content` เข้า `parsePerson` การทดลองส่วนนี้ใช้ API key จาก `.env`
