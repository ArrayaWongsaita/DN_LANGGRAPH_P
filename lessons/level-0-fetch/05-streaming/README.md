# บทที่ 0-05 อ่านคำตอบทีละส่วนด้วย SSE

ถ้าแอปรอ `response.json()` แบบ [บท 0-01](../01-first-fetch/README.md) ผู้ใช้จะเห็นคำตอบเมื่ออ่าน body เสร็จ ในบทเสริมนี้เราขอให้เซิร์ฟเวอร์ทยอยส่ง event แบบ SSE แล้วแสดงแต่ละชิ้นทันทีที่อ่านบรรทัดครบ

## 1. ต่อข้อมูลจนได้บรรทัดครบ

เปิด [`streamText.ts`](./streamText.ts) แล้วเติมข้อ 1 ให้ถอดรหัสข้อมูลชุดใหม่ ต่อท้าย `buffer` แยกบรรทัด และเก็บส่วนท้ายไว้รอข้อมูลชุดถัดไป รันจากโฟลเดอร์หลักของโปรเจกต์ โหมดปกติใช้ `Response` ที่มี stream ตัวอย่าง จึงรันได้โดยไม่ต้องมี API key

```sh
pnpm lesson 0-05
```

ในไฟล์ `value` มาจาก `await reader.read()` ส่วน `decoder` และ `buffer` อยู่ก่อนลูป โค้ดในข้อ 1 ทำสามขั้นตอนนี้

```ts
buffer += decoder.decode(value, { stream: true });
const lines = buffer.split("\n");
buffer = lines.pop() ?? "";
```

การอ่านหนึ่งครั้งอาจจบกลางบรรทัดหรือกลางตัวอักษรภาษาไทย `stream: true` ให้ `TextDecoder` เก็บไบต์ของตัวอักษรที่ยังมาไม่ครบ ส่วน `buffer` เก็บข้อความของบรรทัดที่ยังมาไม่ครบ

## 2. ดูชิ้นข้อความตามลำดับ

```text
สวัสดีครับ
[ 'สวัสดี', 'ครับ' ]
✅ เก็บชิ้นข้อความจาก SSE ตามลำดับ
```

สคริปต์ตัวอย่างแบ่งข้อมูลกลางตัวอักษรตัวแรกของ `สวัสดี` เมื่อบรรทัดมาครบ สคริปต์แยกค่าจาก `choices[0].delta.content` ออกมา พิมพ์ต่อกัน และเก็บชิ้นข้อความไว้ในอาร์เรย์ให้ดูตอนจบ

## 3. ค่าในคำขอและเนื้อหา SSE

| ส่วน | ค่าที่ใช้ | สิ่งที่เกิดขึ้น |
|---|---|---|
| `stream` ใน body ของคำขอ | `true` เพื่อขอ SSE หรือ `false` เพื่อขอ JSON แบบปกติ | โหมด SSE อ่านผ่าน `response.body` |
| `stream` ใน `decoder.decode` | `true` สำหรับชุดข้อมูลที่ยังมีโอกาสตามมา | รอไบต์ถัดไปเมื่อตัวอักษรยังมาไม่ครบ |
| `data:` | ในบทนี้แต่ละบรรทัดมี JSON หนึ่งก้อนหรือ `[DONE]` | อ่าน JSON เมื่อได้บรรทัดครบ หยุดเมื่อเจอ `[DONE]` |
| `choices[0].delta.content` | สตริง อาจว่างหรือไม่มีฟิลด์นี้ในบาง event | พิมพ์เฉพาะชิ้นข้อความที่มีเนื้อหา |

## 4. เปลี่ยนตำแหน่งที่ชุดข้อมูลถูกแบ่ง

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

ใช้ SSE ข้อความเดิมและเปลี่ยนเพียงตำแหน่งที่ป้อนข้อมูลแต่ละครั้ง

| ตำแหน่งแบ่ง | สิ่งที่ต้องรออ่านเพิ่ม | ข้อความสุดท้าย |
|---|---|---|
| หลังจบบรรทัดของ `สวัสดี` | รอ event ของ `ครับ` | `สวัสดีครับ` |
| กลางตัวอักษรแรกของ `สวัสดี` | รอทั้งไบต์ที่ทำให้ตัวอักษรครบและท้ายบรรทัด | `สวัสดีครับ` |

ลองขยับตำแหน่งแบ่งใน [`playground.ts`](./playground.ts) ด้วย `pnpm play 0-05` ถ้าต้องการอ่าน SSE จากโมเดลจริง ให้ตั้ง provider และ API key ใน `.env` ตาม [บท 0-01](../01-first-fetch/README.md) แล้วรันคำสั่งนี้หลังเติมข้อ 1 ข้อความและจำนวนชิ้นขึ้นกับโมเดล

```sh
LESSON_LIVE=1 pnpm lesson 0-05
```
