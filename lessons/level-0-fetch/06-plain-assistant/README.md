# บทที่ 0-06 ประกอบผู้ช่วยด้วย `if` และ `while`

เมื่อมีคนทักทาย แอปส่งข้อความต้อนรับสำเร็จรูปได้ทันทีหลังจัดประเภท เมื่อมีคนถามคำถาม แอปให้โมเดลร่างคำตอบและลองปรับปรุงได้ตามจำนวนรอบที่กำหนด บทนี้นำ `fetch` จาก [บท 0-01](../01-first-fetch/README.md) และการตรวจสถานะจาก [บท 0-02](../02-errors/README.md) มาประกอบเป็นผู้ช่วยตัวเล็ก

## 1. เลือกทางตอบแล้วจำกัดจำนวนรอบ

เปิด [`assistant.ts`](./assistant.ts) แล้วเติมข้อ 1 ถึง 3 เพื่อจัดประเภท เลือกคำตอบสำเร็จรูป และปรับปรุงคำตอบตามลำดับ บทนี้เรียกโมเดลผ่านเครือข่าย ให้ตั้ง provider และ API key ใน `.env` ตาม [บท 0-01](../01-first-fetch/README.md) แล้วรันจากโฟลเดอร์หลัก

```sh
pnpm lesson 0-06
```

ในไฟล์ `ask(prompt)` ส่งคำขอด้วย `fetch` และคืนข้อความตอบ ส่วน `question`, `greeting` และ `maxRounds` มีค่าให้แล้ว โค้ดส่วนที่กำหนดเส้นทางมีหน้าตาแบบนี้

```ts
const raw = await ask(`จัดประเภทข้อความนี้ ตอบคำเดียวว่า greeting หรือ question\nข้อความ: ${question}`);
const category = raw.trim().toLowerCase() === "greeting" ? "greeting" : "question";
let answer: string;
let rounds = 0;

if (category === "greeting") {
  answer = greeting;
} else {
  answer = await ask(question);

  while (rounds < maxRounds) {
    rounds += 1;
    const improved = await ask(`ปรับปรุงคำตอบต่อไปนี้และส่งเฉพาะคำตอบที่ดีขึ้น ถ้าดีอยู่แล้วให้ตอบคำว่า OK เพียงคำเดียว\nคำตอบ: ${answer}`);
    if (improved.trim() === "OK") break;
    answer = improved;
  }
}
```

## 2. อ่านจำนวนครั้งที่เรียกโมเดล

ตัวอย่างนี้แสดงเส้นทางที่โมเดลปรับคำตอบหนึ่งครั้งแล้วตอบ `OK` ในรอบถัดไป ข้อความและจำนวนรอบของคำถามจริงอาจต่างกัน

```text
[greeting | ปรับปรุง 0 รอบ | เรียก 1 ครั้ง] สวัสดีครับ
สวัสดีค่ะ มีอะไรให้ช่วยไหมคะ
[question | ปรับปรุง 2 รอบ | เรียก 4 ครั้ง] ทำไมท้องฟ้าถึงเป็นสีฟ้า
เพราะโมเลกุลในอากาศกระเจิงแสงสีฟ้าได้มากกว่าแสงสีแดง
✅ คำทักทายใช้คำตอบสำเร็จรูปหลังจัดประเภทหนึ่งครั้ง
✅ คำถามมีร่างแรกและเรียกปรับปรุงตามจำนวนรอบ
✅ ส่งคำตอบล่าสุดกลับไปให้ผู้ใช้
```

คำขอแรกใช้จัดประเภททั้งสองเส้นทาง สำหรับ `question` มีคำขอร่างแรกอีกหนึ่งครั้ง จากนั้นเพิ่มหนึ่งครั้งต่อรอบปรับปรุง รวมรอบที่ได้รับ `OK`

## 3. ค่าที่กำหนดทิศทางของผู้ช่วย

| ค่า | รูปแบบหรือค่าเริ่มต้นในบท | ผลที่เกิดขึ้น |
|---|---|---|
| `category` | `"greeting"` หรือ `"question"` | ตัดช่องว่างและแปลงเป็นตัวพิมพ์เล็ก ถ้าได้ `"greeting"` ใช้ข้อความต้อนรับ กรณีอื่นเข้าทางคำถาม |
| `greeting` | สตริง `"สวัสดีค่ะ มีอะไรให้ช่วยไหมคะ"` | ส่งกลับทันทีเมื่อจัดประเภทเป็นคำทักทาย |
| `maxRounds` | จำนวนเต็มตั้งแต่ `0` ขึ้นไป ตัวอย่างใช้ `3` | จำกัดการปรับปรุงหลังได้ร่างแรก |
| คำตอบจากรอบปรับปรุง | `"OK"` หลังตัดช่องว่าง หรือข้อความคำตอบฉบับใหม่ | `"OK"` หยุดลูปและเก็บคำตอบเดิม ข้อความอื่นแทนที่คำตอบเดิม |

## 4. เปลี่ยนจำนวนรอบสูงสุด

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

ใช้คำถามเดิมและสมมติว่าโมเดลส่งฉบับปรับปรุงมาในรอบแรก จากนั้นตอบ `OK` เมื่อถูกขอให้ปรับอีกครั้ง

| `maxRounds` | คำตอบที่ส่งกลับ | จำนวนครั้งที่เรียกโมเดล |
|---|---|---|
| `0` | ร่างแรก | 2 ครั้ง |
| `1` | ฉบับปรับปรุงจากรอบแรก | 3 ครั้ง |
| `3` | ฉบับปรับปรุงจากรอบแรก เมื่อเจอ `OK` ในรอบที่สอง | 4 ครั้ง |

ลองเปลี่ยน `maxRounds` ใน [`playground.ts`](./playground.ts) ด้วย `pnpm play 0-06` ใช้ API key เดิมเมื่อต้องการเรียกโมเดลจริง หรือใช้คำตอบจำลองตามตารางเพื่อเปรียบเทียบจำนวนครั้งที่เรียกอย่างคงที่
