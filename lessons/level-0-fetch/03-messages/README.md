# บทที่ 0-03 ส่งประวัติการคุยใน `messages`

มาลีบอกชื่อและสิ่งที่ชอบไปในรอบแรก พอถามว่า «ฉันชื่ออะไร และชอบอะไร» ในรอบต่อมา แอปต้องส่งข้อความรอบแรกไปด้วย บทนี้ต่อยอดจาก [บท 0-01](../01-first-fetch/README.md) โดยเพิ่มข้อความใน body ของคำขอเดิม

## 1. ประกอบคำขอรอบที่สอง

เปิด [`chat.ts`](./chat.ts) แล้วเติมข้อ 1 ให้ `messages` เรียงคำกำกับ ประวัติ และคำถามล่าสุด รันจากโฟลเดอร์หลักของโปรเจกต์ โหมดปกติใช้คำตอบจำลอง จึงรันได้โดยไม่ต้องมี API key

```sh
pnpm lesson 0-03
```

ในไฟล์ข้อ 1 มี **แนวทาง** เป็นโค้ดที่คอมเมนต์ไว้ เอา `//` ออกแล้วแทนที่ `todo(1)` ได้เลย แต่ลองอ่านก่อนว่าแต่ละบรรทัดทำอะไร

ในไฟล์มี `system` สำหรับกำหนดให้ตอบภาษาไทย `history` ที่เก็บข้อความของมาลีและคำตอบรอบแรก และ `followUp` ที่เก็บคำถามล่าสุด

```ts
const messages: Message[] = [system, ...history, followUp];
```

`...history` กระจายสมาชิกออกมาทีละข้อความ ลำดับสุดท้ายจึงเป็น `system`, `user`, `assistant`, `user`

## 2. ดูคำถามเดิมเมื่อส่งประวัติและเมื่อละประวัติ

โหมดปกติพิมพ์ลำดับ role ของแต่ละคำขอ แล้วแสดงคำตอบจำลองตามข้อมูลที่มีในคำขอนั้น

```text
[มีประวัติ] system → user → assistant → user
คุณชื่อมาลี และชอบแมว
[ไม่มีประวัติ] system → user
ฉันยังไม่มีข้อมูลชื่อและสิ่งที่คุณชอบ
✅ ส่ง system ประวัติทั้งสองข้อความ และคำถามล่าสุดตามลำดับ
✅ ทั้งสองคำขอได้คำตอบ
```

โค้ดเก็บบทสนทนารอบแรกไว้ใน `history` คำขอรอบต่อมาจะมีข้อมูลรอบแรกเมื่อใส่รายการนี้ใน `messages`

## 3. ค่าในแต่ละข้อความ

| ฟิลด์ | ค่าที่ใช้ในบทนี้ | ตัวอย่าง |
|---|---|---|
| `role` | `"system"` สำหรับกำกับการตอบ | วางข้อความกำกับเป็นรายการแรก |
| `role` | `"user"` สำหรับข้อความผู้ใช้ | ข้อความบอกชื่อในประวัติ และคำถามล่าสุด |
| `role` | `"assistant"` สำหรับคำตอบที่ได้ก่อนหน้า | วางคำตอบรอบแรกหลังข้อความที่ถาม |
| `content` | สตริง | `"ฉันชื่อมาลี ชอบแมว"` |

`messages` เป็นอาร์เรย์เรียงจากข้อความเก่าไปใหม่หลัง `system` ในตัวอย่างนี้

## 4. เปลี่ยนเฉพาะประวัติ

ก่อนทดลอง ให้นำโค้ดจากเฉลยตั้งแต่หลัง import ถึงก่อนส่วนตรวจคำตอบไปใส่ใน `playground.ts`

| ค่าที่ส่ง | สิ่งที่ปรากฏในคำขอ | ผลจากตัวอย่าง |
|---|---|---|
| `[system, ...history, followUp]` | มีข้อมูลชื่อและสิ่งที่ชอบ | คุณชื่อมาลี และชอบแมว |
| `[system, followUp]` | มีคำถามล่าสุดอย่างเดียวหลังคำกำกับ | ฉันยังไม่มีข้อมูลชื่อและสิ่งที่คุณชอบ |

ลองประกอบอาร์เรย์สองแบบใน [`playground.ts`](./playground.ts) ด้วย `pnpm play 0-03` ถ้าต้องการเปรียบเทียบกับโมเดลจริง ให้ตั้ง provider และ API key ใน `.env` ตาม [บท 0-01](../01-first-fetch/README.md) แล้วรันคำสั่งด้านล่างหลังเติมข้อ 1 สคริปต์จะส่งคำขอทั้งสองแบบผ่าน `fetch` และถ้อยคำที่ได้จะขึ้นกับโมเดล

```sh
LESSON_LIVE=1 pnpm lesson 0-03
```
